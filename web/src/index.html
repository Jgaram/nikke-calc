게임의 «전투 기록» 창을 이렇게 찍어 주세요. 스쿼드 다섯 개가 전부 들어오고, 왼쪽 파란 SQUAD 딱지가 잘리지 않으면 됩니다.

  • 꼭 있어야 하는 것 — 파란 SQUAD 딱지, 총딜 숫자, 니케 카드 5장, 그게 5줄.
  • 있어도 되는 것 — 창틀, 어두운 배경, 위아래 여백. 넓게 잘라도 됩니다.
  • 크기는 상관없습니다 — 파란 딱지 크기로 배율을 알아냅니다. 휴대폰 세로 캡처도, PC 전체 화면도 됩니다.
  • 하지 말 것 — 왼쪽 파란 딱지를 잘라내는 것. 그게 기준점이라 잘리면 판독이 흔들립니다. 마지막 줄이 반쯤 잘리면 그 줄은 버립니다.
