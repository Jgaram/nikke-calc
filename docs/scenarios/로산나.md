## 스킬 간 상호작용

- **`벤데타`(bonus_damage)는 `아살토`가 아니라 `은신` 상태에 의존**
  - 경로: `은신`(battle_start 5s / hit_count:120 10s) → `self_state:은신` → `벤데타` 발동
  - 시점: `burst_cast` 프레임에 은신이 활성이어야 함
  - 위험: 은신 재부여 주기 2.2s ≪ 지속 10s → 실전 상시 유지. 다만 **t<2.2s 구간은 스킬2 은신(5s)에만 의존**하므로 `first_burst_time`을 5s 밖으로 미루면 1회차 추가 딜이 사라진다

- **`벤데타`(추가 대미지)는 보류되지 않고 `burst_cast` 시점에 즉시 계산된다**
  - `bonus_damage` + `burst_cast`는 **3버스트 캐릭터만** `_pending_burst_dmg`로 보류한다(유저 확정).
    풀버스트가 B3 발동 직후 시작하므로 B3의 추가 대미지만 풀버스트 버프를 받기 때문이다.
  - 로산나는 **B1** → `벤데타`는 `아살토`와 같은 프레임(t=3.000 등)에 계산된다.
    **풀버스트 버프를 받지 않고**, 같은 clause 뒤에 오는 `벤데타 2`의 29%도 받지 않는다
    (`GAMEPLAY.md §효과 실행 순서` 규칙과 자연히 일치)
  - 수치 영향(수냉 적·180s): 보류 상태 65.5M → 29% 제거 51.2M → 보류 해제까지 반영 **38.3M**
  - `아살토`(`damage`)는 원래부터 즉시 계산 + 배열 순서상 앞이라 영향 없음

- **`광기` 스택 → `atk_pct`**
  - 경로: `hit_count:500` → +1중첩 → 최대 10중첩 = `atk_pct` 226.1%
  - 스택 부여 시 지속 30s 갱신(`GAMEPLAY.md §버프 스택` 일반 규칙). 공급 주기 9.3s ≪ 30s → 만료 없이 누적
  - 10중첩 도달까지 5000히트 ≈ **93초** → 짧은 sim에서는 램프 구간이 지배적

- **적 코드가 딜의 두 축을 동시에 켠다**
  - 수냉 적: `온 더 렘 3`(⑦ 우월 코드 +20%) + `벤데타 2`(⑥ 받는 대미지 +29%) 동시 유효
  - 그 외 코드: 둘 다 소실 → 로산나 딜이 크게 떨어진다. 보고서·비교 시 적 코드 명시 필수

## 유저 확인 사항

- Q1: **은신 해제** — 원문 "직접 피격 시 해제". 계산기는 아군 피격을 모델링하지 않으므로 은신은 **지속시간 만료로만 해제**되는가?
  **A: 만료로만 해제.**
- Q2: **`타겟 등장 시`** — `battle_start` 1회로 처리하는가?
  **A: 예** (Q3으로 갈음). `event:target_spawn`은 notify 호출처가 없어 영구 무발동이므로 `battle_start` 사용.
- Q3: **`대상이 타겟이라면`** (스킬2 `광기`) — 항상 참인가?
  **A: 보스전이므로 보스는 언제나 타겟 → 항상 참.** condition 비움.
- Q4: **`수냉 코드 타겟이라면`** (`벤데타 2`) — `target_code:수냉`으로 파싱하는가?
  **A: 예.**
- Q5: **효과 실행 순서** — `벤데타 2`의 29%가 이번 버스트 딜에도 적용되는가?
  **A: 적용 안 됨.** 대미지 블록이 받는 대미지 블록보다 원문에서 먼저 서술되어 있기 때문.
  → 일반 규칙으로 `GAMEPLAY.md §효과 실행 순서`에 승격됨.
- Q6: **`우선적으로 화력형 적 2기`** — 단일 보스에서 1회 적중인가?
  **A: 예.** target을 `"target"`으로 파싱. → `GAMEPLAY.md §condition`에 승격됨.
- Q7: **`니케/아군 전투불능 시`** — 보스 sim 영구 무발동으로 두는가?
  **A: 예.** 네거티브 체크 항목.
- Q8: **`이로운 효과 해제`** — 파싱만 하고 딜 기여 없음인가?
  **A: 예.**
- Q9: **`광기 [10 중첩]`** — 최대 10중첩, 1회당 +1인가?
  **A: 예.**

## 애장품 단계별 차이

| 단계 | 갈리는 슬롯 | 3단계 대비 없는 것 | 효과 수 |
|---|---|---|---|
| 0 | 전 슬롯 기본 | `광기`(hit_count 경로) · `카포 디 카피 2` · `벤데타 2`(받는 대미지) · `온 더 렘 3` | 8 |
| 1 | 스킬2 애장품 | `벤데타 2`(받는 대미지) · `온 더 렘 3` | 10 |
| 2 | +스킬3 애장품 | `온 더 렘 3` | 11 |
| 3 | +스킬1 애장품 | — | 12 |

**스킬3의 이름이 판본 간 한 칸씩 밀린다** (`PARSING-CHARS.md §캐릭터별 예외`). 애장품 2단계는 주
대미지에 `[아살토 : ...]` 이름이 붙지만 기본 판본에는 그 이름이 없다:

| 실제 효과 | 기본 판본 이름 | 애장품 2단계 이름 |
|---|---|---|
| 주 대미지 (`damage` 1310.4%) | `벤데타` | `아살토` |
| 추가 대미지 (`bonus_damage` 561.6%) | `벤데타 2` | `벤데타` |
| 받는 대미지 (`received_dmg_pct` 29.0) | **없음** | `벤데타 2` |

같은 이름이 판본마다 다른 효과를 가리키지만 **판본은 공존하지 않고** 다른 슬롯이 이 이름들을
참조하지 않아 안전하다. `self_state:은신` 조건은 양쪽 판본 모두 추가 대미지 항목에 그대로 붙어 있어
판본이 갈려도 §스킬 간 상호작용의 `은신` 의존 구조는 바뀌지 않는다.

### 단계별로 죽는 메카닉

- **0단계 — `광기`(`atk_pct` 22.61 ×10중첩)가 영구 무발동.** 기본 스킬2에는 `일반 공격 500회` 경로가
  없고 `니케 누군가 전투불능 시`만 있다. 보스 sim에서 아군 전투불능은 모델링되지 않으므로
  (기존 §유저 확인 사항 Q7 · 네거티브 항목) 로산나의 주 스케일링 축이 통째로 빠진다.
  0→1단계 본인 딜이 **+139%**로 뛰는 이유가 이것이다 — 로산나 애장품 1단계의 실질이 `광기` 공급이다.
- **0·1단계 — `벤데타 2`(`received_dmg_pct` 29.0) 없음.** 스쿼드 전체 딜 버프라 1→2단계에서
  로산나 외 전원이 함께 오른다(스쿼드 총딜 +27%).
- **0~2단계 — `온 더 렘 3`(`element_bonus_pct` 20.0) 없음.** 본인 한정이라 2→3단계는 로산나만 +9.2%.
