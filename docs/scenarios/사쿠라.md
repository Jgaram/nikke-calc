## 스킬 간 상호작용

- **스킬1 `벚꽃차` 스택 → 스킬3③의 게이트** ← 이 캐릭터의 유일한 스킬 간 의존
  - 경로: `on_attack_count:3`으로 스택 누적 → `self_stack_above:벚꽃차:10` → `앵화난만 3`
  - 시점: 스킬3 발동 **그 순간**의 스택을 읽는다. 스택 부여가 지속시간도 갱신하므로
    (`GAMEPLAY.md` §버프 스택) 4.2초 주기 공급이 15초 지속을 계속 밀어 **한 번 찬 뒤로는 안 빠진다.**
  - 실측: 최대 중첩 t=**41.95**, 첫 통과 버스트 t=**52.00**(3회차).
  - **딜은 바뀌지 않는다** — `intercept_dmg_pct`가 🚫라 기여가 0이다. 검증은 L2 발동 목록으로 한다.
- **스킬3 ①②의 실행 순서**: 원문 한 블록 안에 ①(30초·전투 중 1회) → ②(10초)가 이 순서로
  적혀 있고 배열도 그대로다. 둘 다 buff 부여라 순서가 값을 바꾸지 않는다.
- **스킬2②가 이 스쿼드의 사이클을 하한까지 내린다.**
  리틀 머메이드 7.48s(`full_burst_end`) + 사쿠라 4.84s(`full_burst_start`)가 겹쳐
  간격이 **12.25초 균일**이 된다 — 표준 12.55초보다 짧고, 이건 「10초 풀버스트 + 2초 게이지 충전
  + 0.25초 단계 전환」으로 **쿨 여유가 0이 된 하한**이다(`GAMEPLAY.md` §사이클 주기의 구성).
  더 줄지 않으므로 쿨감을 더 넣어도 이 스쿼드는 안 빨라진다.

## 유저 확인 사항

- Q: 「적 발사체 공격 시 해당 발사체에 가하는 대미지 N% ▲」는 `intercept_dmg_pct`(저지 부위)인가?
  A: *(자체 판단 · 근거 문서)* **아니다.** `PARSING.md` §stat 로스터가 둘을 갈라 둔다 —
     `intercept_dmg_pct`=「저지 부위 공격 대미지」, `projectile_dmg_pct`=「발사체에 가하는 대미지」.
     사쿠라가 **한 캐릭터 안에 둘 다** 가진 첫 사례다.
- Q: `projectile_dmg_pct`를 저지 부위처럼 🚫로 내릴 것인가?
  A: **❌ 미구현 유지** (유저 결정, 2026-09-20). 지금은 기여 0이지만 발사체 모델이 들어올 여지를 남긴다.
- Q: 「풀 버스트 타임 시작 시 [버스트 스킬 재사용 시간 N초 ▼]」는 지속형인가 즉시 차감인가?
  A: *(자체 판단)* **즉시 차감 `burst_cooldown_reduce`.** 선례가 둘로 갈려 있으나
     (솔린 : 프로스트 티켓 = 지속형 / 라피 : 레드 후드 `전황 파악`·목단 `여긴 내가 맡는다! 2`·
     리틀 머메이드 `버블 오더 2` = 즉시) 다수가 즉시이고, 솔린 시나리오 §해석 선언이 스스로
     「instant로 바꿔도 정상 상태 결과 동일, 다른 B1들은 전부 instant 쪽이라 표기만 어긋나 있다」고
     적어 두었다. 원문에 `[지속]`도 없다.
- Q: 「풍압 코드 적으로부터 받는 대미지 N% ▼」는 기본 적(코드 없음)에서 미발동인가?
  A: *(코드 확인)* **발동한다.** `_condition_ok`의 `target_code:` 분기가
     `if enemy_code and enemy_code != code: return False`라 **적 코드가 비어 있으면 통과**한다
     (`calculator/buff_manager.py`). 실측에서도 t=3.00에 붙는다. 다만 보스 공격 패턴이 없어
     받을 피해가 없으므로 **딜에는 어느 쪽이든 영향이 없다.**
- Q: SR이라 `post_reload_delay` 실측이 필요한가?
  A: **필요 없다** — `weapon_delays.json` `_exceptions`에 항목이 없어 무기군 기본값을 쓴다.
