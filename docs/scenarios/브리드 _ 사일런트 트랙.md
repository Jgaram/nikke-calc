## 스킬 간 상호작용

- **`received_dmg_pct` 두 줄의 위상이 다르다** *(⑥ 합산)*
  - 기동(15.12, `full_burst_start`, 10s)은 **사이클에 물려 있고**, 전도(12.12,
    `hit_count:10`, 10s)는 **사격 수에 물려 있다**(6.667s 주기, 재장전이 끼면 더 길어짐).
  - 둘이 겹치면 ⑥ = 27.24%. 전도만 있는 구간(풀버스트 종료 후 2.5s)에서는 12.12%.
  - 전도는 주기 6.667s < 지속 10s라 **자기 자신이 상시 유지**된다 — 재장전으로 주기가
    벌어져도 10s를 넘지 않는 한 끊기지 않는다.
- **`hit_count`는 사격 수다 — 펠릿이 아니다** *(SG 공통)*
  - SG 펠릿 10개가 히트 로그에는 10줄로 찍히지만 `hit_count`는 1로 센다.
    실측: 사이클 1의 일반공격 190히트 = 19발인데 전도 2는 3회(19÷5)만 발동했다.
  - 만약 펠릿으로 셌다면 전도 2가 사이클당 38회 터져 개인 딜이 10배가 된다.
- **풀 마스콘은 자신을 제외한다** *(대상 범위)*
  - `all_allies_excl_self`. 브리드가 지원형인데도 자기 버프가 하나도 없는 이유다.
  - 브리드의 개인 딜은 오직 무기·장비·우월 코드와 **다른 아군이 준 버프**에서만 나온다.
- **우월 코드(⑦)가 개인 딜의 절반을 정한다** *(적 설정 의존)*
  - 브리드(작열) vs 풍압 적 → ⑦ = 1 + 0.1 + `element_bonus`(장비 88.6 + 큐브 19.09)/100
    ≈ **2.18배**. 코드가 안 맞으면 1.1배다.
  - 실측 개인 딜 220.9M → 480.9M(+117.7%). **브리드를 코드 미설정 적으로 재면
    반 토막으로 과소평가된다.**

## 유저 확인 사항
- 초안 단계를 거치지 않아 신규 질문 없음. 아래는 파싱·코드에서 확인한 사실.
- **Q: `enemies_code:풍압` 대상만으로 코드 게이팅이 되나?**
  A: **안 된다 — `target_code:풍압` condition이 따로 있어야 한다 (2026-09-02 추가).**
  `enemies_code:코드` / `enemies_lowest_hp_code:코드:N`은 `__enemy__` 센티널만 돌려주고
  **단일 적 시뮬레이터에서는 코드 필터를 무시한다**(`docs/IMPL-STATUS.md`).
  그전에는 브리드 `기동`·`전도`와 이브 `임팩트 타입 엑소스파인 2`에 condition이 없어
  **어느 코드 적에게든 ⑥이 얹혔다** — 마르차나 : 마린 스터디 `고위험 대상`만 양쪽을 달고
  있어 로스터 안에서 관례가 갈려 있었다. 셋 다 마르차나 쪽으로 맞췄다.
  실측: 작열 적에서 기동·전도 **발동 0회**, 풍압 적에서 정상 발동. 코드 미설정은 통과한다
  (`target_code:`의 기존 규칙 — 빈 문자열이면 항상 통과).
  하네스 2스쿼드가 전부 풍압이라 baseline은 안 움직였다.
- Q: `hit_count`가 SG 펠릿을 세나 사격을 세나?
  A: **사격이다.** 사이클 1에서 일반공격 히트 190(=19발 × 펠릿 10)인데 전도 2는 3회 발동했다.
- Q: 전도 2의 `enemies_lowest_hp:1`이 단일 보스에서 의미가 있나?
  A: 없다 — 적이 하나뿐이라 언제나 그 적이다. 다중 적 모델이 생기면 의미를 갖는다.
- Q: 기동 2(636%)가 풀버스트 *안*에서 터지나?
  A: **그렇다.** `full_burst_start`(t=3.250)라 풀버스트 진입 프레임이다.
  `burst_cast`(3.100)인 풀 마스콘과 0.15s 차이가 나므로 혼동하지 않는다.
