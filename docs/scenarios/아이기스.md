## 유저 확인 사항
- Q: 「버스트 스킬 사용 시 **자신이 생존해 있을 때 한하여**」를 조건으로 남기는가
  A(자체 판단 · 선례 베이 `유 캔 두잇`): **남기지 않는다** — PARSING §4-1이 이 문형을 `passive`로 접고 앞의 트리거가 timing을 이미 정한다. 보스 공격 패턴에서 아이기스가 쓰러져도 아군에게 건 버프는 풀버스트 종료까지 남는다(베이와 같다)

  A(선례 퀸(마코토) `철・권・제・재!` · 유키코 `진홍의 꽃`): 효과마다 이름 있는 buff(`duration: -1`) + `full_burst_end` `remove_named_buff` 항목. 상태 이름을 읽는 조건이 없어 담체를 따로 두지 않는다
- Q: `[페르소나 - 팔라디온]`
  A(선례 퀸(마코토) `페르소나 - 요한나` · 유키코 `페르소나 - 코노하나사쿠야`): `persona_state` 마커 + 효과별 buff
- **Q: 퀸(마코토)와 한 스쿼드일 때 `라쿠카쟈` 이름 충돌**
  A(유저 결정 2026-09-24): **퀸 쪽 항목에 `remove_scope: "target"`을 붙여 자기 것만 지운다.** 고친 뒤 같은 편성에서 아이기스 `라쿠카쟈` expire 0회 · `S40_퀸유키코` 불변.
  경위: 퀸(마코토) 스킬2 `철・권・제・재! 해제 2`가 `remove_named_buff` → `라쿠카쟈`를 `remove_scope` 없이 쓴다 — 이름만 보고 전역 삭제라 첫 풀버스트 종료에 **아이기스의 영구 `라쿠카쟈`(방어력 21.12%)까지 지운다.** 방어력이라 기본 경로 딜 0. 실측 확인(`["리틀 머메이드", "아이기스", "퀸(마코토)", "스노우 화이트 : 헤비암즈"]`): 13.25에 아이기스 `라쿠카쟈` expire, 이후 재부여 없음. 제안: 퀸 쪽 항목에 `remove_scope: "target"`(target `self`)을 붙인다 — 등록 캐릭터 수정이라 유저에게 물었다
