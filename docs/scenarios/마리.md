  마리에게는 같은 크기라 둘을 각각 빼도 마리 딜이 같다(75,567,312).

## 유저 확인 사항

- **Q1: `정신 집중` 발동 주기.**
  **A(유저 확인 2026-09-23): 10초.** 원문 `■` 블록에 트리거 문구가 없고 CDN 쿨타임도 `null`이라

- **Q2: `post_reload_delay` 실측.**
  **A(유저 확인 2026-09-23): 기본값 0 유지** — `_exceptions`에 등록하지 않는다(`UP` 타입).
- **Q3: `정신 집중`의 첫 발동이 t=0인가 t=10인가.**
  **A(자체 판단): t=10.** `every:Ns`는 전역 격자이고 첫 발동이 `t = N`이다(`GAMEPLAY.md` §효과 실행 순서,
  코드 확인 2026-08-16). 애드미 `고양이 숨결`(첫 t=20)과 같은 규약이다. ⬜ 인게임에서 전투 시작과 동시에
  한 번 나가는지는 미확인 — 그렇다면 첫 풀버스트(3.25~13.25)가 팀 공격력 버프를 5초 더 받는다.
- **Q4: 「대상 코어 명중 시」는 마리 자신의 명중만 세는가.**
  **A(자체 판단): 자신만.** 스킬1 패시브의 주어는 마리이고 `core_hit`은 쏜 사람에게 notify된다.
  스쿼드 브로드캐스트 키(`part_hit_count` 계열)와 다른 축이다.
