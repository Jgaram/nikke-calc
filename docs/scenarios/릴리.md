## 단계 4 결과

- 기본 경로: `최고의 엔지니어! 3`(40%)이 버스트 8회 전부에서 켜진다 — 180초 로그에는 7회만 보이는데, 마지막(t=178.57)은 지연 resolve라 전투가 끝나기 전에 조회가 없어서다. 200초로 돌리면 8회가 찍힌다(파스칼 등록 때와 같은 로그 현상)
- **포지티브 — 엄폐물 파괴 경로**: 표준 스쿼드 + 보스 전체 압박(`coeff 50` · `all` · 45발 · 3초 간격 · 공격력 300,000) + 엄폐물 체력 100,000 + 릴리 버스트 엄폐컨(`own_full_burst` · `extend 5`) — 베이 변형 2와 같은 모양. 릴리 엄폐물이 부서진 채 맞은 버스트 6회(t=28.17~153.50)는 **40% 꺼짐 · 20%가 릴리 자신에게 · 부활(체력 39,000)**, 멀쩡한 첫·마지막 버스트는 **40%만**. 전투불능 0
- 같은 조건에서 **원문 순서(부활 먼저)**로 돌리면 20%는 0회, 40%는 8회 전부 켜진다 — 배열을 바꾼 근거
