# 아니스 : 스타 동작 시나리오

> 모드: 보강 (parsed_skills 반영)
> **역순 작성** — 등록·검증이 끝난 캐릭터의 시나리오를 뒤늦게 채운 문서다.
> 초안(파싱 전) 단계 없음. 수치·발동 시각은 전부 실측이다.

## 기본 정보
- 버스트 단계: B1
- 본인 쿨다운: 20s (스타 아니스)
- 무기 유형: RL (6발, 재장전 2.0s, 차지 1.0s, 계수 61.3%, 풀차지 250%, **풀차지 전용**, 코어 200%)
- 속성 코드: 전격 · 클래스: 방어형 · 기업: 테트라
- 애장품: **없음**
- 작성 사이클 수: 1 (매 사이클 버스트) — 단, **분기가 둘이라 스쿼드는 2개 필요**

## 핵심 전제 — 스쿼드에 다른 B1이 있느냐로 킷이 통째로 갈린다

스킬1의 `[스쿼드 구성 별 효과] [해당되는 효과만 적용]` 분기다. `battle_start`와
**`full_burst_end`마다 재평가**하며, 반대편 상태를 `remove_named_buff`로 지우고 자기 것을 켠다.

| 분기 | 조건 | 켜지는 상태 | 딸려오는 것 |
|---|---|---|---|
| **나만의 별** | `no_burst1_ally` (자신 외 B1 없음) | `atk_pct` +40.01% (self, 영구) | 스타 폴 3(아군 전체 버스트 쿨 −7.48s) · 스타더스트(`atk_caster_based_pct` 35.01%) · 스타 아니스(`atk_dmg_pct` 35.2%) |
| **모두의 별** | `has_burst1_ally` (자신 외 B1 있음) | `burst_stage_override:reenter1` (self, 영구) | 스타더스트 2(회복) · 스타 아니스 2(`hp_caster_based_pct` 15.02%) |

**나만의 별 = 자기 딜러 모드, 모두의 별 = 1버 재진입 인에이블러**다.
`docs/GAMEPLAY.md` §표준 테스트 스쿼드가 "아니스 : 스타를 B1 슬롯 대용으로 쓰지 말라"고
못박은 이유가 이 분기다 — 다른 B1이 끼는 순간 사이클 구조 자체가 바뀐다.

`모두의 별`의 실제 동작(실측): 아니스가 `stage:1`을 쓴 **직후** 스쿼드가 1단계로 재진입해
**다른 B1이 한 번 더** 버스트한다(`_check_reenter`). 즉 아니스가 재진입 슬롯을 가져가는 게
아니라, **아니스가 재진입을 열어 주고 동료가 그 슬롯을 쓴다.**

```
t=3.000  stage:1 사용   아니스 : 스타
t=3.500  reenter:1 사용  리틀 머메이드     ← 모두의 별이 연 슬롯
t=3.600  stage:2 사용   크라운
t=3.700  stage:3 사용   test_B3
t=3.750  full_burst 시작
```

## 검증 스쿼드
- **표준 A — 나만의 별 (B1 · 쿨 20s)**:
  `["아니스 : 스타", "크라운", "test_B3", "스노우 화이트 : 헤비암즈"]`
  - 자신 외 B1 없음 → `no_burst1_ally` 참.
- **표준 B — 모두의 별 (B1 2명)**:
  `["아니스 : 스타", "리틀 머메이드", "크라운", "test_B3", "스노우 화이트 : 헤비암즈"]`
  - 자신 외 B1(리틀 머메이드) 있음 → `has_burst1_ally` 참. 재진입 슬롯 검증용.
  - **두 스쿼드 모두 필수다.** 어느 한쪽만 돌리면 킷의 절반이 검증되지 않는다.

- **실전 조합 (하네스)** — 세 조합 모두 **다른 B1이 함께 있어 `모두의 별` 분기**다:

  | 스쿼드 | 멤버 | 같이 든 B1 | 적 |
  |---|---|---|---|
  | `S36_이사벨아르카나` | 이사벨 · **아니스 : 스타** · 신데렐라 · 아르카나 · 크라운 | 신데렐라 | 수냉 |
  | `S39_나가라피` | 크라운 · 나가 · **아니스 : 스타** · 라피 : 레드 후드 · 프리바티 | 라피 : 레드 후드(`전투 보조`) | 전격 |
  | `S40_브리드라피` | 브리드 : 사일런트 트랙 · 라피 : 레드 후드 · **아니스 : 스타** · 미하라 : 본딩 체인 · 프리바티 | 라피 : 레드 후드 | 풍압 |

  **실전에서 아니스 : 스타는 `나만의 별`(자기 딜러)이 아니라 `모두의 별`(재진입 인에이블러)로 쓰인다.**
  아래 표준 A는 분기 자체를 격리해 보기 위한 인공 편성이다.

실측 (180s, `--expected`):

| 스쿼드 | 스쿼드 총딜 | 아니스 딜 | 아니스 비중 |
|---|---|---|---|
| A (나만의 별) | 2,387,294,696 | **748,060,364** | 31.3% |
| B (모두의 별) | **2,793,138,497** | 516,871,655 | 18.5% |

**본인 딜은 A가 +44.7% 높은데 스쿼드 총딜은 B가 +17.0% 높다.** 아니스가 여는 재진입 슬롯을
리틀 머메이드가 채워 659M을 넣으면서 스쿼드 딜이 406M 늘어나는 쪽이 더 크기 때문이다.
이 캐릭터를 총딜로 평가할 때 **본인 지분만 보면 정확히 거꾸로 읽는다.**

## 스킬 간 상호작용

- **분기 상태 → 스킬2·3의 조건부 블록 (하나의 상태가 3개 효과를 가른다)**
  - `나만의 별` → 스타더스트(전체 공격력) + 스타 아니스(자기 공격 대미지)
  - `모두의 별` → 스타더스트 2(회복) + 스타 아니스 2(전체 최대 체력)
  - 시점: 상태는 `battle_start`/`full_burst_end`에 확정되고, 소비는 `burst_cast`·`full_burst_start`.
    **부여가 항상 소비보다 한 박자 앞서므로 순서 사고가 없다.**
  - `_has_self_state`는 `_active`의 `target_chars`를 보므로, `target: self`인 두 상태 모두 정상 판정된다.
- **`나만의 별` → 스타 폴 3(쿨감) → 사이클 단축 → 버스트 딜 밀도 상승**
  - 순환 강화. `full_burst_end`마다 재발동하므로 사이클마다 쿨감이 새로 들어온다.
  - 위험: `모두의 별` 분기에는 이 쿨감이 **없다**. B 스쿼드에서 아니스 사이클은 전적으로
    동료 B1의 쿨감에 얹혀 간다.
- **`모두의 별` → 재진입 슬롯 → 동료 B1의 추가 버스트**
  - 경로: `burst_stage_override:reenter1`(self) → `_check_reenter()`가 아니스의 캐스트 직후
    `reenter:1` 페이즈를 연다 → **다른 B1**이 그 슬롯을 쓴다.
  - 아니스 본인은 재진입에 참여하지 않는다(방금 썼으므로 쿨 중).
  - 위험: 다른 B1이 쿨 중이면 슬롯이 비어 이득이 0이다.
- **`슈팅 스타2`(차지 0.7초 고정) → 사이클당 사격 수 → `스타 폴 5` 발동 수**
  - 경로: 버스트 10초 동안 사격 간격 1.033s → 0.733s → 그 구간 사격이 늘고,
    `full_charge_only`라 늘어난 발마다 `스타 폴 5`가 따라붙는다.
  - `fixed_value: 0.7`이 없으면 `_fixed_charge_time()`이 base(1.0s)로 폴백해 **단축이 통째로
    사라진다.** 대조 실측(표준 A): 아니스 632,148,822 → **748,060,364 (+18.3%)**,
    스쿼드 총딜 2,271,383,154 → 2,387,294,696 (+5.1%).
- **`스타 폴 5`(풀차지 명중 추가 대미지) × `full_charge_only`**
  - 아니스는 RL 풀차지 전용이라 **모든 사격이 풀차지 트리거**(`full_charge_fire` + `full_charge_hit`)다.
    → 스타 폴 5가 매 발 터진다(사이클당 15회).
  - 위험: 톡톡이(논차지) 컨트롤을 주면 이 딜이 통째로 사라진다. 아니스에게는 톡톡이를 쓰지 않는다.

## 유저 확인 사항
- 초안 단계 없음. 아래는 파싱·코드·실측에서 확인한 사실.
- Q: `모두의 별`이면 아니스가 재진입 슬롯을 쓰나?
  A: **아니다.** 아니스는 `stage:1`을 정상으로 쓰고, 그 **직후** 열리는 `reenter:1`을 다른 B1이 쓴다.
- Q: 분기는 언제 재평가되나?
  A: `battle_start`와 **매 `full_burst_end`**. 스쿼드 구성이 안 바뀌면 결과도 안 바뀌지만,
  `스타 폴 3`(쿨감)은 재평가 때마다 다시 발동하므로 **사이클마다 쿨감이 들어온다.**
- Q: 버스트 중 차지 시간이 0.7초로 줄어드나?
  A: **줄어든다.** 실측 사격 간격이 비버스트 1.033s → 버스트 **0.733s**(= 0.7 차지 + 0.033 발사 후 딜레이).
  사이클당 사격 수가 11~13발 → **15발**로 늘고, 스타 폴 5도 같이 늘어난다.
