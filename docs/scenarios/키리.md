## 스킬 간 상호작용

- **한 스킬 안에서 트리거가 갈린다.** `곁눈질`은 `풀 차지 공격 **명중** 시`(`full_charge_hit`),
  `곁눈질 2`는 `풀 차지 공격 시`(발사, `full_charge_fire`)다. 계산기는 발사를 명중보다 먼저
  쏘므로 **② → ① 순서**다(레이 `선두 제압`과 같은 자리). 빗나감 모델이 없어 지금은 발동 횟수가
  같지만 키를 합치지 않는다.
- **`시전자 기준 공격력`은 키리의 *기본* 공격력을 읽는다** — 자기 버프가 복리되지 않는다
  (`GAMEPLAY.md` §값 산정, 마스트 `해풍`·길티 `빌려 갈게에….` 선례).
- **회복 → 크라운 → 팀 공격 대미지**의 우회 경로가 이 캐릭터 딜 기여의 대부분이다(위 표).
  회복량이 0이어도 성립하므로 **만피 여부와 무관**하다.
- **스킬3의 두 블록은 대상 범위가 다르다**(아군 전체 ↔ 방어형만). 서로를 읽지 않아 순서가
  결과를 바꾸지 않는다.
- **순환 없음**: 회복이 공격력을 올리고 공격력이 회복을 늘리지 않는다(`heal_hp_pct`의 기준은
  시전자 최대 체력이지 공격력이 아니다).

## 유저 확인 사항

- **Q1(단계 4 결정 대기): `곁눈질`(적 대상 `시전자 기준 공격력 ▼`)을 구현할 것인가.**
  로스터에 **적 공격력 감소 stat이 하나도 없다.** 마스트 `해풍` 선례를 따라
  `enemy_atk_down_flat`을 새로 여는 길과, 기여 0을 근거로 ❌로 두는 길이 갈린다
  (`projectile_dmg_pct`가 후자의 선례다 — 보유자 3명인데도 모델이 없어 ❌ 유지).
  **어느 쪽이든 딜 기여는 0**이고 보스 공격 패턴이 있을 때의 생존만 바뀐다.
- **Q2: `방어형 아군 2기`는 어떤 순서로 2기를 고르는가.**
  **A(자체 판단): 스쿼드 입력 순서로 앞 2명** — 원문에 정렬 기준(`가장 ~한`)이 없고,
  같은 모양인 `아군 N기에게`(`allies:N`)가 `squad_names[:n]`이다. 키 표기는
  `allies_class:방어형:2`로 두고 **단계 4에서 세 칸짜리를 읽도록 고친다**.
  현행은 인원수 칸이 무시돼 「방어형 전체」로 떨어진다(변형 1에서 3명 전원 수령 확인) —
  doclint 검사 A도 접두사만 보므로 못 잡는 자리다.
- **Q3: `[시전자의 최종 최대 체력 비례 N% 회복] [1초 간격]`은 기존 문형인가.**
  **A(자체 판단): 그렇다.** `heal_hp_pct` + `scaling: "max_hp"` + `tick_interval: 1.0`
  (`PARSING.md` §7-5·§7-10). 기준은 **시전자**의 최종 최대 체력이고 받는 쪽의 최대 체력은
  상한일 뿐이다(2026-09-15 로스터 전수 통일).
- **Q4: `post_reload_delay` 실측.**
  **A(유저 확인 2026-09-22): 기본값 0 유지.**

## 단계 4 검증 결과 (2026-09-23)

**이 배치에서 계산기 코드를 건드린 것은 키리뿐이다.** 두 수정 모두 유저 결정으로 들어갔다.

### Phase C — 계산기 수정 둘

1. **`allies_class:클래스:N` — 인원수 칸을 읽게 했다** (`_resolve_target_raw()`).
   종전에는 `split(":")[1]`만 읽어 세 번째 칸이 조용히 무시됐다. 두 칸(`allies_class:클래스`)은
   종전대로 전체다. 정렬 기준이 원문에 없으므로 **스쿼드 입력 순서 앞 N명**이고, 고정 속성
   기반이라 지연 resolve 대상이 아니다. **기존 두 칸 보유자(비스킷 `터그 놀이` 계열)는 무영향.**
2. **`enemy_atk_down_flat` — 적 대상 `atk_caster_based_pct`를 라우팅했다.**
   `bm.enemy_atk_down_flat(적 id, t)`가 `timeline._boss_attack`에서 보스 공격력을 정액으로 깎는다:
   `eff_atk = max(보스 공격력 + 감소량, 0)`. 감소량 = 시전자 **기본** 공격력 × N%
   (`_caster_based_atk_flat()` — 아군판과 환산이 같다). 짝인 `def_caster_based_pct` →
   `enemy_def_down_flat`과 달리 **`get_buffs()` 버프 사전에 자리를 두지 않는다** — 소비처가
   보스 공격 한 곳뿐이라서다. ⬜ 쫄몹이 쏜 발은 깎지 않는다(`DATA_VERIFY.md` §보스 → 니케 피해).
