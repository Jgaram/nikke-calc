## 스킬 간 상호작용

- **#10 `임전 : 신검합일 4` → #4 `거합`의 계수 ×2**
  - 경로: `dmg_scale_mag_pct`(target_effect `거합`, 100) → `_handle_damage_eff`가 `거합` 계수에 ×(1 + 100/100)
  - 시점: 본인 버스트 10초(3.200 ~ 13.200)에만. 거합은 발사마다라 그 10초의 모드 사격 15발 전부에 실린다
  - 크기: 이 효과를 빼면 본인 딜 **−15.19%**(총딜 −8.92%)
- **#4 `거합`은 무기 변경 모드 사격에도 발동한다** — 모드 사격도 일반 공격이다(GAMEPLAY §무기 메카닉, 「`weapon_hit:`이 아니라 `hit_count`·`on_attack`이 정상 누적」). 실측 272발 = 거합 272회
  - 위험: 모드 사격이 `on_attack`을 내지 않게 되면 본인 딜 **−30.39%**(총딜 −17.84%). 회귀 감시 항목
- **#11 모드 ↔ #6 탄환 충전**: `not_self_state:화무십일일홍 · 만개`로 모드 중 무발동. 무기 변경 중 탄환 충전 미적용(GAMEPLAY §무기 메카닉)과 방향이 같아 조건이 없어도 결과가 같다
  - **기본 스펙에서는 #6의 딜 기여가 ±0.00%다** — 실측 180초 내내 발사 간격이 0.667s를 넘는 구간이 없다(재장전 0회). 모드 종료 시 만탄 복구(GAMEPLAY §무기 메카닉)가 2사이클마다 탄창을 채우고, 오버로드 장탄으로 그 사이 ≈22발을 버틴다. 장탄 오버로드가 없는 육성에서만 갈린다
- **같은 `burst_cast` 프레임의 실행 순서 — 스킬2 `임전 : 신검합일` → 스킬3 (모드 · 버프 · 추가 대미지)**
  - 배열은 슬롯 순서(스킬1 → 2 → 3)이고 원문 `■` 블록 순서 = 실행 순서(GAMEPLAY §효과 실행 순서). #14는 B3 추가 대미지라 풀버스트 시작까지 보류되는데, 보류 딜은 **자기보다 뒤에 서술된** `burst_cast` 버프만 뺀다(`_later_burst_cast_buffs`) → #9 공격 대미지 ▲ 116%·#13 공격력 ▲ 120%가 **실린다**
  - 대안(스킬3이 먼저 — 유키코의 DILDORO 예외와 같은 꼴)이면 #9가 #14에서 빠져 본인 딜 **−13.81%**(총딜 −8.11%)
- **풀버스트 시작 프레임**: #5 크리티컬 대미지 ▲가 먼저 걸리고 보류된 #14가 계산된다(`timeline` `full_burst_start` notify → `_fire_pending_burst_dmg`). #14는 스킬 딜이라 일반 공격 크리 확률(#3·#8)은 안 받고 크리 대미지 ▲(#5)는 기대 크리에 섞여 실린다
- **#1·#7 마커는 서로 다른 이름이다** — 버스트 10초 동안 홍련 : 신살은 임전 상태 둘을 함께 든다. 「임전 상태인가」는 둘 중 하나라도 있으면 참이고, `임전 : 명경지수`가 영구라 이 캐릭터는 **전투 내내 임전 상태**다
- **#2 관통 특화는 모드에도 남는다** — 영구 버프라 모드 사격(`_fire`)도 `pierce_enabled`를 읽는다. 원문 기능 문구(「일반 공격이 넓은 폭의 관통 공격」)가 모드에서도 유지된다는 읽기와 같다

## 유저 확인 사항

- Q: `화무십일일홍 · 만개`의 변경 무기 유형·장탄·연사는? (원문에 없음 — PARSING §10-7)
  A: 변경 후 **999발**, **AR 유지**. 10초에 어림잡아 15발 정도 쏘며, CDN에 비슷하게 들어 있으면 CDN이 정확하니 그걸 쓴다(유저 확인 2026-11-01). → `weapon_type: AR` · `max_ammo: 999`. 연사는 CDN `weapon_change_fire_rate` 90rpm = 1.5/s(10초 15발)로 체감과 맞아 `fire_rate`를 적지 않고 CDN을 쓴다. 999발이라 10초(15발) 안에 재장전이 없어 종전 `-1`(무한) 판본과 딜이 같다(표준 본인 1,137,255,227 불변)
- (자체 판단) **`[일반 공격 폭 100% ▲]`** — 로스터 최초 문구. 기존 키 `pierce_range`(「관통 범위 N% 확장」)와 같은 축으로 보이지만 원문 표기가 달라 **신규 키 `normal_atk_width_pct`(❌)**로 옮겼다(PARSING Step 4 ②). 단일 보스 기본 경로 딜 영향 0
- (자체 판단) **`거합` 트리거** — 하위 효과 3이 자기 트리거(「일반 공격 시」)를 가져 clause 트리거(전투 시작) 대신 `on_attack` + `self_state:임전 : 명경지수`. 선례 길티 : 마이티 바니 `체인 인헨스 3`·`체인 릴리즈 3`(상태 하위 효과 3의 「풀 차지 공격 명중 시」 → `full_charge_hit` + `self_state:`). 「일반 공격 시」 = 발사(PARSING §4-1). 빗나감 모델이 없어 `hit_count:1`이었어도 ±0
- (자체 판단) **임전 마커** — 부모 세션이 정한 공용 규약(마리안 : 퀸 · 홍련 : 신살 · 라푼젤 : 생츄어리): `[임전 : X]` 상태마다 `engaged_state` 마커 buff(같은 이름·트리거·지속, `beneficial_irremovable`, `max_stack 1`, 값 없음). 선례 `persona_state`(퀸(마코토) · 유키코). 마커가 번호 없는 상태 이름을 갖고, 같은 clause의 하위 효과는 ` 2`부터(Step 7 §담체)
- (자체 판단) **`[거합 추가 대미지 배율이 100% 증가 상태로 변경]`** — `dmg_scale_mag_pct` 100 + `target_effect: 거합`. 선례 이브 `엑소스파인 Mk2`(「불안정 에너지 순차 공격 대미지 배율이 100% 증가 상태로 변경」)
- (자체 판단) **스킬3 둘째 clause**(조준선 최근접 적 추가 대미지) — timing 문구 없음 → 스킬3 기본 `burst_cast`. 대상 선례 라피 : 레드 후드 `계승되는 힘 4`
- (자체 판단) **모드 부속 버프 #12·13** — 원문이 `[10초 유지]`를 직접 달아 모드(10초)와 같은 수명이라 `event:state_end` 해제를 따로 두지 않았다. 이름은 스킬 키 이름(나유타 `고행 3`과 같은 규약 — 모드가 콜론 이름 `화무십일일홍 · 만개`를 가져갔다)
