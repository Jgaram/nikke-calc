## 스킬 간 상호작용

- **스킬3 분기 ↔ 부활 ↔ 스킬1 (동일 timing 실행 순서 — 이 캐릭터의 핵심 위험)**
  - 경로: `나노 입자 투여`(revive, burst_cast) → `event:나노 입자 투여` → `나노 입자 소모`(스킬1 buff) → 스킬3 `self_state:나노 입자 소모` 분기
  - 원문은 시전 순간에 분기 하나만 적용한다(「[해당되는 효과만 적용]」 · 두 번째 ■은 「나노 입자 소모 상태라면」). 계산기는 효과마다 그 자리에서 조건을 판정하므로, **부활이 먼저 돌면** ① 전투불능 수가 0으로 떨어져 `ally_down_count_below:2`가 참이 되고 ② 부활이 연 `나노 입자 소모` 때문에 `가든 오브 아르카디아 4`도 참이 된다 — 세 분기가 한 시전에 다 켜진다.
  - 해소: **배열 순서** `가든 오브 아르카디아 3` → `4` → `가든 오브 아르카디아` → `2` → `나노 입자 투여`. 부활을 맨 뒤에 둔다(릴리 `최고의 엔지니어!` 선례). `3`·`4`끼리의 순서는 결과를 바꾸지 않는다 — 부활 전에는 `나노 입자 소모`가 없다.
  - 위험: 단계 4에서 `event:나노 입자 투여`를 **동기 notify**로 구현하면 위 배열이 필요하고, 지연 통지라면 배열과 무관하다. 어느 쪽이든 체크리스트로 「한 시전에 분기 하나」를 본다.
- **부활 대상 버프 ↔ 부활**: `가든 오브 아르카디아`·`2`(공격력·방어력)는 **전투불능 상태의 아군**에게 가야 하므로 부활보다 앞에 둬 시전 직전 집합으로 고른다. ⬜ 전투불능 중 받은 버프가 부활 뒤에도 남는지(전투불능 시 버프 소멸 규칙 `bm.knock_down`과의 관계)는 단계 4에서 확인 — 안 남으면 부활 **뒤**에 두고 대상을 「방금 부활한 아군」으로 바꿔야 한다.
- **`디바인 라이트 3`(버스트 재사용 +40초) ↔ 버스트 쿨 시작**: 같은 `burst_cast` 안에서 부활 → 이벤트 → +40초가 일어난다. 버스트 쿨(20s)이 효과 처리 **뒤**에 세팅되면 +40초가 덮여 사라진다 — 단계 4 확인 항목.
- **`갓데스 블레싱` 재부여 게이트**: `셀레스티얼 헤이븐`(보호막)과 `갓데스 블레싱`이 같은 `not_self_state:갓데스 블레싱`을 쓰므로 담체(블레싱)를 뒤에 뒀다 — 앞이면 보호막이 영원히 안 나온다(PARSING Step 7 §담체).
- **풀버스트 진입 버프 ↔ 임전 상태**: `self_and_engaged_allies`는 부여 시점 스냅샷이다. 임전 쪽의 전투 시작 상태가 영구라(위 변형 1) 스냅샷/지연 판정의 차이는 기본 경로에서 드러나지 않는다.
- **순환 없음**: 부활 분기는 `max_trigger: 1` + `not_self_state:나노 입자 소모`(영구)로 두 겹 막혀 있다.

## 유저 확인 사항

- **Q1: RL `post_reload_delay` 실측값.**

- **Q2 (자체 판단): 「자신과 임전 상태인 아군 전체에게」의 대상 키.**
  신설 `self_and_engaged_allies` = 자신 ∪ `engaged_state` 마커 버프 보유 아군, 부여 시점 스냅샷.

- **Q3 (자체 판단): 「나노 입자 투여 사용 시」의 timing.**
  `event:나노 입자 투여`. 근거: 「[스킬명] 발동 시」 → `event:[이름]`(레드 후드 `와일드 투스 4` 「레드 울프 발동 시」). 담체가 instant라 구현은 단계 4.
- **Q4 (자체 판단): `[버스트 스킬 재사용 시간 40초 ▲] [해제 불가]`.**
  instant `burst_cooldown_reduce` `fixed_value: -40`. 근거: 유지 블록 없는 재사용 시간 증가 — 프리카 `앵콜 3`(`[버스트 스킬 재사용 시간 21초 ▲]` → −21). `[해제 불가]`는 instant에 담을 필드가 없어 note로만 남겼다.
- **Q5 (자체 판단): `[차지 종료 시 제거]`.**
  `duration: -1` + `full_charge_fire` 트리거 `remove_named_buff`(`셀레스티얼 헤이븐 해제`). 근거: `[마지막 탄환 공격 시 제거]`(신데렐라 : 크리스탈 웨이브 `변경 준비 해제`)·`[풀버스트 진입 시 제거]`(아비스타)와 같은 꼴. 「차지 종료」 전용 timing은 없다 — 풀 차지를 1초 넘게 든 차지는 풀 차지 발사로만 끝나므로(계산기에 홀드 중 버스트·재장전으로 차지가 끊기는 경로가 있으면 그때만 갈린다) 기존 ✅ 키로 옮겼다. 보호막이라 딜 0.
- **Q6 (자체 판단): 「풀 차지 시 자신이 풀 차지 상태일 때 한하여」.**
  timing `full_charge` + 신설 condition `during_full_charge`(런타임 재평가). 「~일 때 한하여」 + `[지속]`은 조건이 깨지면 꺼지는 상시형이다(프리카 `무대, 시작할게. 4`의 `self_state` 게이트와 같은 문형). polarity는 리버렐리오 면역 선례대로 `neutral`. 딜 0.
- **Q7 (자체 판단): 전투불능 수 조건 · 대상.**
  `ally_down_count_above:3` / `ally_down_count_below:2`(`enemy_count_above/below:N`의 아군판, `>=`·`<=`), 대상 `allies_down_all`(`allies_down_` 접두사 — 전투불능 제외 규칙의 예외 계열). `[전투 불능 아군 수량 별 효과] [해당되는 효과만 적용]` 메타 블록은 항목을 만들지 않는다(라피 : 레드 후드 `[스쿼드 구성 별 효과]` · 신데렐라 : 크리스탈 웨이브 선례).
- **Q8 (자체 판단): 「공용 보호막」.**
  `shared_shield_from_max_hp_pct` · 대상 `self`. 라푼젤 : 퓨어 그레이스 `생츄어리`와 같은 표기다(그쪽 Q2 — 「아군 공용 보호막」 계열). parsecheck가 「선례 없음」으로 띄우는 것은 퓨어 그레이스 쪽 두 clause가 값이 같아 값으로 clause를 못 짚기 때문이다.
