## 스킬 간 상호작용

- **카멜레온 은신술 2(자기 엄폐물 회복) → 파충류 애호가 · 2** *(자급)*
  - 경로: `burst_cast` → `cover_heal_pct`(self, `scaling: max_hp`) → `event:cover_healed`(티아에게) → 두 버프.
  - `event:cover_healed`는 **회복받은 엄폐물의 주인**에게 notify한다 — `_notify`가 caster 인덱스로 후보를 고르므로 티아 효과는 티아 엄폐물 회복에만 반응한다.
  - 시점: 같은 burst_cast 프레임. 순서 무관 — 두 버프는 이 프레임의 대미지·재진입 판정에 읽히지 않는다.
- **파충류 애호가(`burst_cooldown` buff) → 티아 버스트 빈도**
  - 쿨감은 두 자리에서 읽힌다(`timeline.BurstController`): ① `_cast_burst`가 **notify 전에** 활성값을 빼 `burst_ready_at`을 정하고, ② `full_burst_start`마다 `cd_now − _cd_applied_at_cast`만큼 더 당긴다.
  - 자급 1중첩은 ①에 못 들어가고(같은 프레임 notify 뒤) ②로만 들어간다 → 40 − 13 = **27s**.
  - 외부 공급으로 2중첩이 상시면 ①에서 26을 빼 **14s** → 매 사이클 사용 가능.
- **도마뱀의 보호 2 → 외부 보호막 트리거** *(교차 캐릭터)*
  - `all_allies_excl_self` 보호막 → 수령자별 `event:shield_applied` · `during_shield`. 표준 스쿼드에는 반응자가 없어 딜 불변.
- **카멜레온 은신술 3(라이프스틸) → `event:heal_received`**
  - `_apply_lifesteal`은 **티아 본인**에게만 notify한다 — 크라운 `로얄 에타이어 4`는 크라운이 회복받을 때라 반응하지 않는다.
- **동일 timing(burst_cast) 실행 순서**
  - 배열 순서: 카멜레온 은신술 2·3(스킬2) → 도마뱀의 보호 1·2·3(스킬3). `burst_reentry`는 notify가 끝난 뒤 `_try_use_stage`가 확인하므로 배열 순서와 무관하다. 딜을 내는 항목이 없어 순서가 결과를 바꾸지 않는다.
