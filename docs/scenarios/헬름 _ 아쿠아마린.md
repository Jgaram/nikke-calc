## 사이클 — 자기 쿨감이 바닥을 친다

`위드 어드마이어 2~4`는 전부 **누적형**(`count >= N`)이라 3사이클째부터 매 진입마다
**1.82 + 2.2 + 2.6 = 6.62s**를 all_allies에 뿌린다. 표준 템플릿의 리틀 머메이드
`버블 오더 2`(−7.48s)까지 더하면 스쿼드 전체 쿨이 사이클마다 14.1s씩 깎인다.

실측 풀버스트 시작: 3.25 → 15.500 → 27.750 → 40.000 → 52.250 → … **12.25s 등간격**(180s에 15회).

> **12.25s가 이 계산기의 사이클 하한이다** — 풀버스트 10s + 버스트 리젠 2.0s +
> 3단 전환 지연(0.1+0.1+0.05). 크라운 표준의 12.533s와 달리 **1사이클부터 이미 바닥**이라,
> 쿨감을 더 넣어도 사이클이 안 빨라진다. 헬름 : 아쿠아마린의 쿨감은 **B1/B3 쪽 쿨이
> 빡빡한 조합에서만** 값이 난다.

단계 진행 실측: 1사이클 위드 어드마이어 2만 → 2사이클 2·3 → **3사이클(t=27.750)부터 2·3·4 전부**.

## 스킬 간 상호작용

- **`full_burst_start_count` 누적 → 스쿼드 전체 쿨감** *(아군에게 가는 유일한 값)*
  - 1·2·3이 `count >= N`이라 3사이클째부터 **매 진입마다 6.62s**가 all_allies에 들어간다.
  - **표준 템플릿에서는 효과가 안 보인다** — 사이클이 이미 하한 12.25s라 더 빨라질 데가 없다.
    쿨 40s인 B1/B3이 병목인 조합에서 값이 난다(하네스 `S39_맥스웰츠바이`가 그렇다).
  - 리타 `리타 부스트 1~3`와 같은 클래스의 효과다 — 그쪽은 본인 쿨을 당겨 자기 사이클을
    가속하지만, 헬름 : 아쿠아마린은 자기 쿨(20s)이 이미 사이클의 두 배 안이라 **남에게만 쓰인다.**
- **`target_code:전격` 두 줄 + 우월 코드(⑦)가 같은 방향으로 겹친다** *(적 설정 의존)*
  - 헬름 : 아쿠아마린은 **철갑**이고 철갑 → 전격이 우월 코드다(`damage._SUPERIOR`).
  - 그래서 전격 적에서 ⑦ 2.18배 + `bonus_damage` 164.83 + ⑥ 최대 28.2%가 한꺼번에 붙는다.
    **하네스 2스쿼드가 전부 전격인 이유**다.
- **이지스 캐논 견제 사격 2(⑥)는 스쿼드 전체 딜에 곱해진다**
  - `received_dmg_pct`는 적이 받는 대미지라 **본인 딜만이 아니라 아군 전원의 딜**에 실린다.
    4초 주기 · 5초 지속 · 5중첩이라 t=20.000 이후 **28.2%가 상시 유지**된다.
  - 실질적으로는 이것이 헬름 : 아쿠아마린의 최대 스쿼드 기여다 — 쿨감(하한에 걸림)보다 크다.
- **`이지스 캐논 오버로드`는 풀버스트 밖에서 터진다**
  - `burst_cast`(t=3.100)라 풀버스트 진입(3.250) 0.15s 전이다. 풀버스트 진입 시 켜지는
    아군 버프를 못 받는다. `burst_dmg_pct` 계열은 받는다.

## 유저 확인 사항
- 초안 단계를 거치지 않아 신규 질문 없음. 아래는 파싱·코드에서 확인한 사실.
- **Q: 코드 미설정 적에서 `target_code:전격` 두 줄이 그대로 통과하는데 맞나?**
  A: **의도된 동작이다.** `target_code:[코드]`는 `state["enemy"]["code"]`와 비교하고
  **코드 미설정(빈 문자열)이면 항상 통과**한다(`docs/IMPL-STATUS.md`).
  그래서 표준 스쿼드(코드 미설정) 실측 124M에도 오버로드 2·견제 사격 2가 이미 들어 있고,
  전격을 켰을 때의 +117.7%는 **대부분 ⑦ 우월 코드**다.
  다른 코드(작열 등)를 명시하면 두 줄이 빠진다 — 그때가 진짜 하한이다.
- Q: `위드 어드마이어 2~4`가 "N번째에만"인가 "N번째부터 매번"인가?
  A: **N번째부터 매번**(`count >= N`). 실측 t=27.750부터 세 줄이 함께 발동한다.
- Q: 표준에서 쿨감이 총딜을 안 올리는 것 같은데 버그인가?
  A: **아니다 — 사이클이 이미 하한 12.25s다.** 풀버스트 10s + 버스트 리젠 2.0s +
  3단 전환 0.25s가 물리적 바닥이라 그 아래로는 안 내려간다. 쿨감이 남는 것은 낭비다.
- Q: `이지스 캐논 견제 사격`의 `every:4.0s`는 원문에 없는데?
  A: 원문이 `■ 무작위 적 1기에게 [최종 공격력 105.58% 대미지]`로 트리거가 없다.
  파싱 시 4초 주기를 부여한 **추정치**다. 실측 4.017 · 8.017 · 12.000으로 확인된다.
