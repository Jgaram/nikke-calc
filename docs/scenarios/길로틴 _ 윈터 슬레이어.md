## 스킬 간 상호작용

- **경험치 게이지 → 공격력 + 레벨 업**
  - 경로: `경험치 2·3`(gauge_charge) → 게이지 `경험치` → ① `경험치` buff 값(실시간), ② 10의 배수를 넘으면 `LV_UP`
  - 위험: 두 경로가 별개 풀이면 경험치 200까지 쌓여 공격력 +362%가 된다 — 게이지 하나로 묶은 이유
- **레벨 게이지 → 팀 버프·자기 게이트·DoT**
  - `용사의 숙명` 1·2는 duration −1이라 **시전자** 레벨 게이지를 실시간 추종(`_get_value()`가 `ab.caster` 게이지를 읽는다)
  - `용사의 자질`은 `gauge_above:용사 레벨:2` 런타임 재판정
  - `익스터미네이션 3`은 **등록 시점** 레벨 캡처 — 버스트 10초 사이에 레벨 업이 끼어도 그 DoT는 그대로
- **동일 timing `LV_UP` 실행 순서**: `용사 레벨 업`(충전) → 보상 2종 → `용사의 숙명` 1·2. 보상은 레벨을 읽지 않고,
  팀 버프는 실시간 추종이라 **순서가 값을 바꾸지 않는다.** `LV_UP` 자체는 `경험치 2·3`의 게이지 충전이 끝난 뒤 발생한다.
- **순환 강화**: 레벨 업 보상 탄환 충전 → 사격 시간 증가 → 경험치 누적 가속. 레벨 업 10회 한정이라 발산하지 않는다.

## 유저 확인 사항

- **Q1. 용사 레벨은 몇에서 시작하는가?** (2026-09-13)
  - **A: 레벨 1에서 시작한다** (유저 확인). `최대 11레벨까지 성장` + 경험치 100중첩 ÷ 10 = 레벨 업 최대 10회와 맞는다.
- **Q2. 경험치는 두 경로(비코어 6히트 · 코어 3히트)가 하나의 풀을 채우는가?** (2026-09-13)
  - **A: 하나의 풀이다** (유저 확인). 최대 100중첩 · 공격력 +181%.
- **Q3. `익스터미네이션 3`의 레벨은 언제 읽는가 / 첫 틱 위상은?** (2026-09-13)
  - **A: 버스트를 쓴 순간의 레벨로 고정이 맞다** (유저 확인).
  - 첫 틱 위상(type 1/2)은 **유저도 모른다** — 기본값 type 2(발동 +1초)로 두고 미확인으로 남긴다.
- **(자체 판단) 「코어가 아니라면」은 6번째 히트 자신을 본다.** `PARSING.md` 4-2 매핑(`not_core`) + GAMEPLAY
  §condition(`hit_count:N` 카운터는 condition과 무관하게 진행). 「비코어 명중을 6회 센다」로 읽어도 코어 확률이
  히트마다 독립이면 **기대 발동 수가 같다** — 히트당 `(1 − P_core)/6`. 코어 3회 경로와 합친 경험치 속도는 두 해석 모두
  히트당 `(1 + P_core)/6`.
- **(자체 판단) 「용사 레벨 업 시」는 레벨 업과 같은 timing이다.** 레벨 업은 instant라 `event:`가 뜨지 않고,
  두 문장이 가리키는 사건이 같다.
