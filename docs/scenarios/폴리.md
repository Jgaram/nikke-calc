## 스킬 간 상호작용

- **애장품 2단계는 1단계의 상태를 먹고, 3단계는 그 종료를 먹는다** — 세 단계가 한 사슬이다.
  - 경로: fav1 `폴리스 뱃지`(10초) → fav2 `폴리스 라인 3`(불굴, `self_state:폴리스 뱃지`) →
    fav2 `폴리스 라인 4`(`remove_named_buff`) → fav3 `도그 테라피 3`(`event:state_end:폴리스 뱃지`)
  - 시점: 뱃지가 10초뿐이고 폴리 첫 버스트가 t≈3.15s라 **1회차만 닿는다**(실측 각 1회).
  - **배열 순서 제약**: `폴리스 라인 4`(제거)가 `폴리스 라인 3`(불굴)보다 앞서면 같은 프레임에 뱃지가 사라져
    불굴 조건이 거짓이 된다. 질 `산성탄`(DoT → 제거)과 같은 클래스의 순서 제약이다.
- **`도그 테라피`와 `도그 테라피 2`는 같은 대상 집합에 걸린다** — `["self", "allies_lowest_hp_excl:2"]`.
  분배 멤버십과 방어 버프 수혜자가 항상 같아야 해서 `target`을 갈라 적지 않았다.
- **20초마다 집합이 다시 뽑힌다** — 자칼 `치얼업 자칼`(전투 시작 1회 고정)과 정반대다.
  `received_dmg_split_even` 구현 시 **재부여가 기존 분배 집합을 교체하는지 덧쌓는지**가 이 캐릭터에서 갈린다.

## 유저 확인 사항

- **Q1: `도그 테라피`의 발동 주기.** 원문 `■` 블록에 트리거가 없고 CDN 쿨타임도 `null`이다
  (`PARSING.md` §4-1). **A(자체 판단): `every:20.0s`.**
  근거는 **같은 슬롯의 애장품 3단계 원문이 「■ 20초 마다」로 시작**하고 첫 블록의 문구·값(11.75~23.51)이
  기본과 동일하다는 것 — 3단계는 회복 블록을 *추가만* 한 판본이다. 딜 0 효과라 주기가 달라도 총딜 불변.
- **Q2: `받는 대미지 균등 분배`의 집합 고정 시점.** **A(자체 판단): 부여 시점 고정.**
  대상 선정이 `■` 블록(부여 시점)에 있고 `[10초 유지]`가 각 효과에 붙는다. 자칼·율하와 같은 규격.
- **Q3: `폴리스 뱃지 상태 종료 시`가 명시적 제거도 포함하는가.** **A(자체 판단 · 코드 확인): 포함한다.**
  `remove_named_buff`도 `event:state_end`를 발생시킨다(`buff_manager` 1419행). 실측에서도
  `도그 테라피 3`이 뱃지 자연 만료(t=10) 전인 버스트 제거 시점에 1회 발동했다.
  → `IMPL-STATUS.md`의 `event:state_end` 행이 「만료 시」로만 적혀 있던 것을 이번에 정확히 고쳤다.
