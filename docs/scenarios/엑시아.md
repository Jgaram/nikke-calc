## 스킬 간 상호작용
- **`해킹 코드 수집`이 모든 조건의 열쇠다** — 애장품 1단계에서 풀 차지 명중마다 1중첩(5초 · 5중첩)이라 한 탄창 안에 5중첩이 찬다. 그 상태의 마지막 탄 명중에 `인베이젼`(대상 공격력·방어력 −13.77%)·`시크릿 코드`(전격 아군 시전자 기준 공격력 +5.8% ×5), 버스트에 `원사이드 프로토콜 3`(추가 대미지)·`4`(받는 대미지 +18.04%)
- **`해킹 코드 수집` 5초 유지와 재장전 틈** — 마지막 탄 명중 뒤 재장전 2.0초 + 첫 차지 1초 + 딜레이 ≈3.4초라 5초 안에 다음 풀 차지 명중이 와서 끊기지 않는다(탄창 ≈13발). 애장품 3단계 `인베이젼 3`(풀버스트 10초 재장전 0.1초 고정)은 풀버스트 안의 재장전을 사실상 지운다
- 버스트 시각에 5중첩이 서 있어야 `원사이드 프로토콜 3`·`4`가 나간다 — 버스트 직전 탄창 위상에 걸린다
- `시크릿 코드`의 수령처는 전격 코드 아군 — 표준에서는 엑시아 자신뿐
