## 스킬 간 상호작용

- **모드 토글 → 스킬2 둘 중 하나**
  - 경로: 마커 `바니 모드 : 스탠스`/`인게이지` → `체인 인헨스 1~3` / `체인 릴리즈 1~3`의 `self_state:`
  - 토글 네 항목의 **순서가 곧 판정**이다: `(인게이지 해제)[not 스탠스]` → `인게이지[스탠스]` → `스탠스[not 인게이지]` → `(스탠스 해제)[인게이지]`. 원문 두 분기를 토글 직전 상태로 판정한 것과 같다
    - 없음 → 스탠스 / 스탠스 → 인게이지 / 인게이지 → 스탠스 (세 경우 모두 손으로 추적)
  - `스탠스` 항목 조건이 원문(`스탠스가 아니라면`)과 다른 이유: 인게이지 분기에서 동기화 clause가 **같은 프레임에 자기 스탠스를 먼저 지운다** → `not 스탠스`면 스탠스가 다시 걸린다
- **모드 동기화 → 짝의 모드** (홀드 토글 시)
  - 동기화 clause는 **해제를 부여보다 앞**에 둔다. 뒤면 자신도 아직 옛 모드라 `allies_with_buff:`에 들어가 자기에게 다시 건다
  - 순환: 길티 인게이지 → (자기 스탠스 해제) → 신에게 인게이지 → 신의 동기화가 반응 → 신 스탠스 해제 → 스탠스인 아군 0명 → **종료**. 마커가 이미 있으면 갱신만 하고 이벤트를 다시 쏘지 않는다(`_activate()` max_stack 1 갱신 분기)
  - ⚠ **`remove_scope`가 없으면 동기화가 끊긴다.** 인게이지 → 스탠스 토글에서 `(인게이지 해제)`가 짝의 인게이지까지 지워, 뒤따르는 동기화가 「인게이지인 아군」을 못 찾고 짝은 **모드 없음**이 된다. 메모리 실측으로 재현했다 — 페어에서 두 캐릭터를 인게이지로 시작시키자 길티 딜 **−64%**(스킬2가 통째로 꺼짐)
- **마이티 스톰프 1발에 실리는 것**
  - `드디어 풀려났어…!` 차지 +1400%(1발) · `체인 인헨스 2` +40% · 무기 250% → ④ = 1690%
  - `드디어 풀려났어…! 2` 공격 대미지 +77.35%(10s)는 이후 풀버스트 일반 사격에도 실린다
  - 모드 사격도 `full_charge_hit`이라 `체인 인헨스 3`이 1회 더 붙는다(4.717s 확인)
- **발사 딜레이 → 모드 진입** — 직전 기본 사격의 0.38s 딜레이가 끝나야 모드 차지가 시작된다(29.95s). 엔진 기존 동작이며 이 캐릭터 고유가 아니다

## 인게이지 운용

**방무 버퍼(아군 전체 `armor_break_dmg_pct`)와 함께면 인게이지로 쓴다** — 유저 운용 확정(2026-09-17).
`data/char_defaults.json`의 `_rules`가 `with_member: ["플로라", "타키나"]`일 때 시퀀스 홀드를 붙인다.

```jsonc
"sequence": [ { "t": 0.0, "action": "hold", "until": 2.2 } ]
```

- 전투 시작 모드는 **언제나 스탠스**라 토글이 필요하다. 첫 풀차지(1.0s)를 1초 들고 있으면
  `charge_hold:1`이 **t=2.02s**에 떨어지고, 2.2s에 떼면서 그 발이 나간다. 비용은 첫 발 1.1초뿐이다.
- 시각이 전투 시작 기준이라 조합이 바뀌어도 같은 자리다 — 정책 대신 시퀀스를 쓴 이유다
  (`CONTROL.md` §명시 시퀀스의 "절대 시각" 주의는 **사이클에 매인 조작**에 대한 것이다).
- **홀드는 한 명만 든다.** 신 : 스위프트 바니와 함께면 동기화가 신도 끌고 오므로, 신 쪽 규칙에
  `without_member: ["길티 : 마이티 바니"]`가 붙어 있다. 둘 다 들면 두 번째 토글이 **둘 다 스탠스로**
  되돌린다.
- 왕복도 확인했다 — 길티가 41.8s에 한 번 더 홀드하면 둘 다 스탠스, 신이 102.18s에 홀드하면 둘 다
  인게이지. **모드 없음 구간은 한 프레임도 없다.**

## 유저 확인 사항

- Q: 기본 무기 `post_fire_delay`·`post_reload_delay` 실측값이 있는가?
  A: 없음 — 기본값(CDN 유도 0.38s / 0) 사용 (2026-09-17)
- Q: 마이티 스톰프의 발사 딜레이 실측값이 있는가?
  A: **딜레이 0초** (2026-09-17) → `weapon_delays.json` `_weapon_change`
- Q: 실사용에서 인게이지로 토글하는가? — **단계 3 보고의 잔여 질문**
  A: *(자체 판단 · 잠정)* 기본 경로는 스탠스 고정. 기본 적 방어력에서 스탠스가 길티 8.9%·신 24.6% 앞선다(위 해석 선언)
- Q: 「자신에게 적용 시」가 아군이 걸어 준 모드에도 반응하는가?
  A: *(자체 판단)* 반응한다 — 원문이 출처를 가리지 않는다. 결과는 어느 쪽이든 같다(한쪽만 반응해도 대상이 0명에서 끝난다)
- Q: 로그의 `바니 모드 : 스탠스` 만료/재활성(버스트마다 1회)은 무엇인가?
  A: *(코드 확인)* **표시만이다.** 마커의 `not_self_state:마이티 스톰프`가 영구 버프라 런타임 재평가 대상이 되어, 모드 중 조건 거짓 구간을 `buff_event_handler`가 만료로 적는다. `self_state:` 판정(`_has_self_state`)은 `_active`를 직접 보므로 상태는 끊기지 않는다 — 4.717s 모드 사격에 `체인 인헨스 3`이 붙은 것이 증거다
