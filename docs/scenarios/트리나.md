## 검증 스쿼드

- **표준**: `["리틀 머메이드", "트리나", "test_B3", "스노우 화이트 : 헤비암즈"]`
  - 전격 AR 아군 0명 → 피스풀 트리 4종 + 머덜리 포레스트 3·4 **무발동이 정상**(네거티브 검증).
  - AoE 버스트 보유자 없음 → 뻗은 뿌리는 부여되나 실효 대미지 0.
- **통합 (유저 지정)**: `["목단", "리틀 머메이드", "트리나", "프리바티", "라플라스 : 얼티밋 히어로"]`
  - 목단(B1 40s, 전격 AR) = `allies_code_weapon:전격:AR`의 유일 매칭 → `leftmost:1`도 목단.
  - 리틀 머메이드(B1 20s) = B1 보조 + 버쿨감 7.48(풀버스트 종료).
  - 프리바티(B3 40s)·라플라스 : 얼티밋 히어로(B3 40s) = 둘 다 버스트가 `■ 적 전체에게 [최종 공격력 N% 버스트 스킬 대미지]` → 뻗은 뿌리 실효 검증. 번갈아 사용해 매 사이클 AoE 버스트 존재.
  - B1×2 · B2×1 · B3×2 → 사이클 유효.

> 최좌측 선택 로직(후보 2명 이상)은 파싱 완료된 전격 AR 아군이 목단뿐이라 시뮬로는 검증 불가.
> 대신 `_code_weapon()`이 `parsed_nikke.json`만 읽는다는 점을 이용해 함수 직접 호출로 검증 완료

> 홍련·질·루피 : 윈터 쇼퍼 파싱 후 재검증 불필요.

### 표준 스쿼드 차이

`battle_start` 2건과 `burst_cast` 중 피스풀 트리 3·4, 머덜리 포레스트 3·4가 **전부 무발동**.
발동하는 건 머덜리 포레스트 1·2와 뻗은 뿌리뿐이며, 뻗은 뿌리는 수혜자가 없어 딜 변화 0.

## 스킬 간 상호작용

- **뻗은 뿌리(5s) → B3 AoE 버스트 대미지, 0.1초 간격으로 성립**
  - 경로: 트리나 `burst_cast`(t=3.10) → `burst_dmg_aoe_pct` 부여 → B3 캐릭 `burst_cast`(t=3.20)의 `burst_damage` 히트가 `all_allies` 버프를 참조
  - 시점: 버스트 순서가 B1→B2→B3로 고정이라 트리나(B2)가 항상 B3보다 앞선다. **B2 슬롯이 트리나여야만** 성립
  - 위험: ① 트리나 미발동 사이클엔 증폭 0 → 그 사이클 B3 딜 급락(정상). ② 유지 5초라 t>8.1의 지연 AoE 버스트에는 미적용
  - 배수가 lv10 +435.6%라 적용 여부가 스쿼드 총딜을 크게 흔든다 → 회귀 diff 판독 최우선 항목

- **목단의 `atk_dmg_pct`는 두 경로에서 합산된다**
  - 경로: 머덜리 포레스트 2(`all_allies`, +20.9) + 피스풀 트리 3(`leftmost 전격 AR`, +94.15) = +115.05
  - 시점: 둘 다 `burst_cast` 동일 프레임 → 순서 무관(독립 buff 합산)
  - 위험: leftmost target 구현 시 목단이 아닌 캐릭터에게 걸리면 이 합산이 깨진다 → 검증 필수

- **`hp_only_caster_based_pct`는 트리나 base HP 기준 — 순환 강화 없음**
  - 경로: 머덜리 포레스트가 트리나 자신의 최대 체력도 올리지만, 계산은 `시전자 base_hp × val%`(IMPL-STATUS L228)
  - 즉 머덜리 포레스트가 피스풀 트리의 부여량을 키우지 않는다. **키운다면 버그**
  - 스쿼드에 `atk_from_hp_pct` 보유 아군이 있으면 이 버프가 딜로 환산되지만, 통합 스쿼드 4명 모두 미보유 → 이번 검증에선 딜 무영향

- **`max_ammo_flat` +20은 재장전 완료 시점에 반영된다**
  - 경로: `_finish_reload()`에서 `max_ammo_pct`와 함께 적용(IMPL-STATUS L256)
  - 시점: t=3.10 부여 시 이미 장전된 탄창은 그대로. 목단이 그 후 재장전해야 60→80발이 된다
  - 위험: 버프 10초 안에 재장전이 없으면 장탄 증가가 한 번도 실효되지 않을 수 있다

## 유저 확인 사항

- Q: `전격 코드 소총 아군`의 '소총'은 어떤 무기 유형인가?
  - A: **AR(돌격소총)만**. (SR=`스나이퍼 라이플`, MG=`머신건`, SMG=`기관단총`, SG=`샷건`, RL=`로켓 런처`로 각각 별도 표기되므로 '소총'은 AR 전용)
- Q: 뻗은 뿌리 대상인 `대상 설명이 '적 전체에게'로 끝나는 버스트 스킬`에 레이븐의 `적 전체에게(파츠 포함)`도 포함되나?
  - A: **포함**. 괄호 부연은 무시하고 AoE 버스트로 판정. → IMPL-STATUS `burst_dmg_aoe_pct` 행에 기록(일반 규칙 승격)
- Q: '적 전체에게' clause 안에 버스트 스킬 대미지 외 **추가 대미지**가 있으면(이사벨 `타겟 마킹 2·3`) 그것도 증폭되나?
  - A: **버스트 스킬 대미지만**. `stat: burst_damage`인 항목만 증폭하고 같은 clause의 `bonus_damage`·`dot_damage`는 제외.
- Q: `스쿼드에서 가장 왼쪽에 위치한 전격 코드 소총 아군 1기` 해석은?
  - A: **스쿼드 입력 순서 기준 첫 매칭 1명**. 매칭 0명이면 무발동(트리나 본인은 RL이라 후보 아님).
- Q: 검증 스쿼드 구성은?
  - A: 표준 + 통합 1개. 통합은 `["목단", "리틀 머메이드", "트리나", "프리바티", "라플라스 : 얼티밋 히어로"]`.

### 텍스트만으로 확정된 항목

- `자신이 생존 상태일 때 한하여` → 사망 모델 없음 → condition 제거, `battle_start` + `duration: -1`. 선례: 아니스 : 스타 `스타 폴`
- `니케를 제외한 적이 1기 / 2기 이상` → 단일 보스 sim: 뻗은 뿌리 항상 참, 시든 뿌리 **영구 무발동**
- 스킬1 ②③ `아군 체력 30%/50% 이하` → 아군 피격 모델 없음 → 영구 거짓
- 스킬2 ③ `버스트 스킬 사용 시` → `burst_cast`(본인 발동 시에만)
- `[뻗은 뿌리를 시든 뿌리로 변경]` 블록은 Step 4 분류표에 없어 **스킵**. 두 버프 condition이 상호 배타라 동작 동일
