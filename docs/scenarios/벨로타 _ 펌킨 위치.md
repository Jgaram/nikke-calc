## 스킬 간 상호작용

- **스킬1 `유령 분장` → 스킬2 `유령의 장난`**: `self_state:유령 분장`으로 게이트된다. `유령 분장`이 풀버스트 시작 10초라 **부여·갱신은 풀버스트 창 안 명중에서만** 일어난다.
  - 그런데 디버프 10초 > 풀버스트 종료 → 다음 풀버스트 시작(2.5초)이라 **실측 업타임 97.9%, 사실상 상시**다. 게이트를 없앴다면 +0.03%(첫 3.8초 몫)뿐이다.
  - 풀버스트 시작 프레임의 명중 순서(모호 점 4)는 딜 영향 0으로 정리됐다 — 두 번째 풀버스트부터는 이전 디버프가 아직 살아 있다.
  - 위험: `유령 분장`은 「직접 피격 시 해제」라 보스 공격 패턴이 펌킨 위치를 때리면 창이 짧아진다. 은신이라 고르는 공격의 후보에서는 빠지므로, 깨는 것은 전체 공격류다.
- **우측 아군 공격력 ▲ 2종(#4 · #7)**: 이름이 달라 별개 버프로 겹친다. 둘 다 시전자 공격력 기준이라 **수령자가 누구든 같은 절대값**이 붙는다 — 공격력이 낮은 수령자일수록 상대 이득이 크다(크라운 +54% · 스노우 화이트 +25%).
- **우측 아군 지속 대미지 ▲ 2종(#6 · #8)**: DoT 히트에만 실린다. 변형 2(디젤 : 윈터 스위츠)에서 우측 효과 몫이 +26%로 가장 크다.
- **#7·8은 본인 버스트 사이클에만**(2사이클에 1번), #4·6은 매 사이클이다.
- **같은 스쿼드 배치가 B2 선점도 정한다**: 펌킨 위치를 B2 동료(크라운)보다 왼쪽에 두면 선점하고, 오른쪽에 두면 버스트를 한 번도 못 쓸 수 있다(변형 3 — 0회). 자리가 우측 대상과 버스트 순서를 함께 정하므로 배치가 두 번 효과를 낸다.

## 유저 확인 사항

- Q: RL `post_reload_delay` 실측값이 있는가?
  A: 없음 — 기본값 0 사용 (유저 확인 2026-10-08), `_exceptions` 미등록
- (자체 판단 · 선례 없음) **「자신의 우측 자리 아군 1기」 = 스쿼드 입력 순서 인덱스 +1** — 이 레포는 스쿼드 순서를 화면 왼쪽부터의 자리로 쓴다(GAMEPLAY §버스트 사용 순서와 배치 「유저가 화면 왼쪽부터 누르는 것과 같다」 · `allies_adjacent:N`). 맨 오른쪽이면 대상 없음(무발동)
- (자체 판단) **`유령 분장`** — 선례 바이퍼 `애교`(같은 `풀 버스트 타임 시작 시 자신에게` 문형)대로 `stealth` buff + `received_hit_count:1` 해제 instant
- (자체 판단) **「풀 차지 공격 명중 시」 / 「풀 차지 공격 시」** — `full_charge_hit` / `full_charge_fire`(PARSING §4-1). 빗나감 모델이 없어 지금은 횟수가 같다(±0.00%)
