## 이 캐릭터의 성격 — 직접 딜은 0, 간접 경로가 하나

효과 9종이 전부 방어·회복·엄폐물이다. 딜 계수가 하나도 없다.
그런데도 표준 스쿼드에서 **총딜을 6.38% 움직인다** — 애장품 1단계의 회복이 크라운의
힐 트리거를 매 풀차지마다 열기 때문이다(§상호작용). **크라운을 빼면 기여가 정확히 0.00%가 된다.**
검증은 총딜이 아니라 **L2 발동 목록**으로 하는 것이 원칙이고, 총딜은 이 간접 경로를 볼 때만 쓴다.

## 검증 스쿼드

- **표준 (B2 · 쿨 40s)**: `["리틀 머메이드", "베이", "크라운", "test_B3", "스노우 화이트 : 헤비암즈"]`
  - 실측: 총딜 **1,887,411,536** / 베이 **55,245,421**(2.9%, 전부 기본공격)
  - 풀버스트 **15회** · 간격 **12.55s** · 베이 버스트 **8회** · 풀차지 **127회**
  - 발동: `유 캔 두잇`·`유 캔 두잇 2` 각 **40회**(=8버스트 × 5명) · `유 캔 두잇 3` **127회** ·
    `치얼업 투게더 2` **14회** · `퍼스트 위너 2` **8회** · `퍼스트 위너 3` **40회**
  - **`치얼업 투게더` 0회** — target `self_cover`가 빈 리스트라 활성화 자체가 안 된다(보류 결정).
  - `치얼업 투게더 3`·`퍼스트 위너` **각 0회** — 엄폐물이 멀쩡하므로 정상이다.
    (`not_self_cover_alive` 구현 **전**에는 조건이 무시돼 각 15회·1회가 **오발동**했다.)
- **변형 1 (피격·엄폐물 경로)**: 표준 스쿼드 + 아래 합성 패턴 (비스킷 변형 2와 같은 모양, **coeff 50**)
  ```json
  { "_config": { "cover_hp": 100000 },
    "patterns": [
      {"id": "엄폐물·체력 압박(검증용)", "kind": "attack", "after": ["start"], "delay": 1.0,
       "until": {"time": 179.0},
       "spec": {"coeff": 50, "target": "all", "hits": 45, "interval": 3.0, "atk": 300000}}
  ]}
  ```
  - **세기를 비스킷 쪽(coeff 90)보다 낮춰야 한다.** 이 캐릭터는 아군은 전부 회복시키면서
    **자기만 회복하지 않는다**(`유 캔 두잇 3`가 `all_allies_excl_self`, 자기 힐은 애장품 2단계
    뿐인데 그 게이트가 「엄폐물 파괴」라 열리지 않는다). coeff 65면 **베이 혼자 쓰러진다.**
  - 실측(coeff 50): 총딜 **1,887,411,536** — 표준과 **한 자리도 다르지 않다.** 보스가 때려도
    새로 열리는 효과가 없다(트리거가 전부 `burst_cast`·`full_burst_end`·`full_charge_fire`).
  - 끝난 시점 체력: 베이 **34.4%**, 나머지 넷 **100%**. 엄폐물은 베이만 **790,596/790,596**로
    멀쩡하고 나머지는 130,000 중 18,000대까지 깎였다.
  - **기본 컨트롤로는 베이의 엄폐물이 한 번도 안 깎인다.** 엄폐는 재장전 때만 하는데
    이 캐릭터는 180초에 재장전이 두 번뿐이고, `퍼스트 위너 2`가 자기 엄폐물을
    130,000 → **790,596**(=기본 + 시전자 최종 최대 체력의 18%)으로 6배 키운 데다
    `치얼업 투게더 2`가 풀버스트마다 최대 체력의 2.88% × 5틱(≈528,000)을 다시 채운다.
    세기만 올리면 엄폐물이 아니라 **본인 체력**이 먼저 바닥난다(coeff 65에서 사망).
    → 엄폐물 파괴 경로는 **변형 2**가 연다.
- **변형 2 (엄폐물 파괴 경로 — `not_self_cover_alive` 포지티브 · 필수)**:
  표준 스쿼드 + **버스트 엄폐컨** + 아래 두 패턴
  ```json
  { "_config": { "cover_hp": 100000 },
    "_chars": { "베이": { "control": { "cover": { "policy": "own_full_burst", "extend": 5.0 } } } },
    "patterns": [
      {"id": "전체 압박(검증용)", "kind": "attack", "after": ["start"], "delay": 1.0,
       "until": {"time": 179.0},
       "spec": {"coeff": 50, "target": "all", "hits": 45, "interval": 3.0, "atk": 300000}},
      {"id": "베이 집중(검증용)", "kind": "attack", "after": ["start"], "delay": 2.0,
       "until": {"time": 179.0},
       "spec": {"coeff": 60, "target": "slot:2", "hits": 80, "interval": 2.0, "atk": 300000}}
  ]}
  ```
  - **버스트 엄폐컨(`own_full_burst` + `extend: 5`)이 이 변형의 핵심 조건**이다.
    베이를 자기 풀버스트 동안 엄폐물 뒤에 세워야 보스 공격이 **체력이 아니라 엄폐물로**
    들어가고, 그래야 엄폐물이 깎일 만큼 때려도 본인이 쓰러지지 않는다.
    `slot:2`(=베이 자리) 전용 포화는 남은 넷을 전멸시키지 않고 베이만 압박하기 위한 것이다.
  - 실측: 총딜 **1,814,644,180** · 풀버스트 **15회** · **전투불능 0명 · 전원 체력 100%로 종료**
  - 베이 엄폐물: **t=12.0 파괴 → t=28.2 부활(26,000) → t=64.0 다시 파괴, 이후 부활 없음**
  - `치얼업 투게더 3` **12회** · `퍼스트 위너` **1회** — 표준 스쿼드의 0회·0회와 정확히 대비된다.
  - **`퍼스트 위너`가 1회에서 멈춘다** — t=64.0에 다시 부서졌는데도 되살리지 않는다(`max_trigger: 1`).
  - 총딜이 표준보다 **−3.85%**인 것은 보스 피해 탓이 아니라 **엄폐컨으로 베이가 덜 쏘기**
    때문이다 — 풀차지 127회 → **51회**로 줄고, 그만큼 `유 캔 두잇 3`가 여는 크라운 연쇄도 약해진다.
    (집중 포화를 coeff 80으로 올려도 총딜은 한 자리도 안 바뀐다 — 보스 피해는 니케 딜에 닿지 않는다.)
- **변형 3 (애장품 0단계 대조)**: 표준 스쿼드, `favorite_stage: 0`
  - 실측: 총딜 **1,774,135,275**(표준 대비 **−5.99%**)
  - `유 캔 두잇 3`·`치얼업 투게더 3`·`퍼스트 위너` 세 항목이 **전부 사라진다** → 판본 조합이 올바르다.
  - 이 −5.99%는 전부 `유 캔 두잇 3` 몫이다(아래 ablation과 일치).

## 스킬 간 상호작용

- **이 캐릭터의 딜 기여는 전부 애장품 1단계 회복 ↔ 크라운 `로얄 에타이어 4`의 연쇄다.**
  - 경로: `유 캔 두잇 3`(풀차지마다 `heal_hp_pct`, **자신을 제외한 아군 전체**)
    → 회복을 받은 크라운에게 `event:heal_received`
    → 크라운 `로얄 에타이어 4`(아군 전체 `atk_dmg_pct` +20.99%)
  - 숫자: `로얄 에타이어 4` 발동 **55회 → 690회**. `유 캔 두잇 3`만 빼면 총딜 **−6.38%**
    (스노우 화이트 : 헤비암즈 −4.95% · 리틀 머메이드 −8.23% · test_B3 −8.63% · 크라운 −7.84%).
  - **크라운을 도라로 바꾸면 같은 효과의 기여가 0.00%다.** 스쿼드 의존이 100%다.
  - 오버힐에서도 `event:heal_received`가 나가는 규칙(`GAMEPLAY.md` §timing)이 이 경로를 성립시킨다 —
    기본 경로에서는 아군 체력이 늘 가득 차 있다.
  - **비스킷과 정반대다**: 비스킷의 회복은 화력형·본인에게만 가서 크라운을 비껴가므로 기여가 0이다
    (`docs/scenarios/비스킷.md` §상호작용).
- **애장품 2·3단계는 서로 배타가 아니라 「부활이 회복을 끊는」 관계다** (변형 2 실측).
  둘 다 「엄폐물이 파괴된 상태라면」이 게이트인데, `퍼스트 위너`(부활, 전투 중 1회)가 터지면
  그 순간부터 `치얼업 투게더 3`(버스트 1단계 진입 시 회복)의 조건이 닫힌다 — 다시 부서질 때까지다.
  실측에서는 t=12.0 파괴 → t=28.2 부활 → t=64.0 재파괴였고, `퍼스트 위너`가 `max_trigger: 1`로
  소진된 뒤에는 `치얼업 투게더 3`만 계속 열려 **12회** 발동했다.
- **`퍼스트 위너`와 `퍼스트 위너 2`는 같은 `burst_cast`에 걸리고 순서가 결과를 바꾼다.**
  원문 블록 순서대로 **부활이 먼저**다 — 부활 시점의 엄폐물 최대 체력을 기준으로 20%를 채우고,
  그 **직후** `퍼스트 위너 2`가 최대치를 올리면 `sync_cover_hp`가 늘어난 만큼 현재 체력에 얹는다.
  변형 2 실측(프레임 단위): `t=28.18 → 26,000 / max 130,000` → `t=28.20 → 686,596 / max 790,596`
  (= 26,000 + 660,596). **순서를 뒤집으면 20%의 기준이 790,596이 되어 158,119에서 시작**하고
  최종값도 달라진다. `GAMEPLAY.md` §효과 실행 순서의 「원문 블록 순서 = 실행 순서」가 가르는 자리다.
- **`퍼스트 위너 2`(엄폐물 최대 체력 ▲)는 자기 부활 조건을 스스로 닫는다.** 자기 엄폐물을
  130,000 → 790,596으로 6배 키우므로 같은 공격에도 안 부서지고, 그 결과 애장품 2·3단계가

### 포지티브를 만든 방법 — 버스트 엄폐컨

기본 컨트롤로는 베이의 엄폐물이 **한 번도 깎이지 않는다**. 엄폐는 재장전 때만 하는데
180초에 재장전이 두 번뿐이고, 세기만 올리면 엄폐물보다 본인 체력이 먼저 바닥난다.
**버스트 엄폐컨(`own_full_burst` + `extend: 5`)** 을 임시 조건으로 걸어 자기 풀버스트 동안
엄폐물 뒤에 세우자 보스 공격이 체력 대신 엄폐물로 들어갔고, 그제야 변형 2가 성립했다
(전원 체력 100%로 완주). 「엄폐컨을 걸어야 엄폐물이 깎인다」는 이 캐릭터만의 사정이 아니라
**엄폐물 관련 효과 전반의 검증 조건**이다 — 다음에 엄폐물 축을 건드릴 때 이 변형을 그대로 쓴다.

부수로 **동일 `burst_cast` 안의 실행 순서**가 숫자로 드러났다(위 §상호작용):
부활(26,000 = 130,000 × 20%)이 먼저 들어가고 그 **다음 프레임**에 `퍼스트 위너 2`가
최대치를 올리면서 686,596으로 함께 찬다. 원문 블록 순서대로 실행한 결과다.

코드 수준 판정도 함께 확인했다 — 비스킷 변형 2(엄폐물이 실제로 부서지는 실행)에서
`break_cover()` 직후와 `cover_revive` 이후를 직접 읽었다:

| 시점 | `_condition_ok(["not_self_cover_alive"])` | `_condition_ok(["self_cover_alive"])` |
|---|---|---|
| 엄폐물 파괴 직후 (크라운·비스킷·리틀 머메이드) | **True** | False |
| `cover_revive`로 되살아난 뒤 (전원) | **False** | True |

`_runtime_condition_ok`도 같은 값을 돌려준다 — 두 경로 모두 분기를 달았고
`_RUNTIME_COND_PREFIXES`에 등록해 매 프레임 재평가된다. 되살아나는 프레임에 판정이 뒤집히는
것은 `bm.revive_cover()`가 집계 캐시를 비우기 때문이다(`break_cover()`와 같은 규약).

**이 캐릭터의 자기 방어는 애장품 2·3단계에 몰려 있는데 그 게이트를 스스로 닫는다.**
`퍼스트 위너 2`가 자기 엄폐물을 6배로 키우고 `치얼업 투게더 2`가 계속 채우는 바람에
기본 컨트롤에서는 「엄폐물이 파괴된 상태」에 도달하지 않고, 그래서 자기 회복도 자기 부활도
열리지 않는다. 그 결과 **팀에서 베이만 체력이 34%까지 떨어진다** — 아군은 전부 회복시키면서
자기만 회복하지 않기 때문이다. 구현 전에는 조건이 무시돼 애장품 2단계 회복이 15회 공짜로
들어갔고, 그게 없어지자 coeff 65에서 베이가 쓰러졌다. 엄폐컨을 걸면(변형 2) 게이트가 열려
12회가 정상으로 들어오고 **체력 100%로 완주한다** — 이 캐릭터의 설계가 엄폐를 전제한다는 뜻이다.
