## 스킬 간 상호작용

- **버스트 → 스킬2 패널티 연쇄**: `하이 텐션` 해제 → `로우 텐션` → 기절. 원문 블록 순서 그대로다. 기절은 `event:로우 텐션`이라
  로우 텐션이 **붙은 직후** 같은 프레임에 평가되고(`self_state:로우 텐션`이 이미 참), 두 효과가 같은 20초로 함께 끝난다.
- **재버스트 갱신 = 패널티 회피**: 스카이 버스트 간격이 35s 미만이면 `하이 텐션`이 끊기지 않아 패널티가 영원히 0회다.
  간격을 가르는 것은 스카이가 아니라 **스쿼드의 사이클 프로필**이다 — 버쿨감 B1 동료(리틀 머메이드)와 쓰면 25.17s.
- **스킬1 면역 ↔ 스킬2 패널티**: `저항 정신`(해로운 효과 1개, 5s)이 `하이 텐션` 만료 순간 켜져 있으면 각 아군의 `로우 텐션`이 막히고,
  스카이 자신의 로우 텐션이 막히면 기절 조건도 거짓이라 **기절까지 사라진다**. 만료 직전 5초 안에 홀드가 끝나야 하고 전투 중 3회뿐이다.
  기본 레이어의 고정 시각 홀드는 만료 시각(스쿼드마다 다르다)을 맞히지 못한다 — 변형 2에서 2.02 · 77.38 · 153.88 모두 빗나갔다.
- **기절 → 홀드·버스트 차단**: 기절 중에는 차지도 못 하므로 그 구간의 홀드 지시가 무산되고 `관통 특화`가 끊긴다(변형 2: 42.02 ~ 77.38).
- **`Runway to hell` 캐스터 기준값**: 스카이 버스트 직후 풀버스트에는 `FLY! ROCK!`(공격력 50%)이 얹힌 공격력으로 20%를 준다.

## 유저 확인 사항
- Q1: SR의 `post_reload_delay` 실측값이 있는가?
  A: 기본값 0 (유저 답변 2026-11-26) — `_exceptions`에 등록하지 않는다.
- Q2: 같은 패치의 벨벳 · 스노우 화이트 : 헤비암즈 문구 변경(「풀 버스트 상태가 아니라면」 → 「풀 버스트 타임이 아니라면」, 수치 동일)을 재파싱하는가?
  A: 재파싱 안 함 (유저 답변 2026-11-26) — raw 갱신만 반영한다.
- Q3: 자기 기절(`기력 저하`)은 약 40초(조건부 유한 passive 규약)인가, 20초인가?
  A: **20초** (유저 답변 2026-11-26). `event:로우 텐션` + `self_state:로우 텐션`으로 옮겼다. 일반 규칙(에이드·치사토의 조건부 유한 passive)은 바꾸지 않았다 — `PARSING-CHARS.md` §캐릭터별 예외.
- Q4: 스카이에게 기본 홀드를 넣는가?
  A: **넣는다 — 38초 간격 시퀀스** (유저 답변 2026-11-26, 권장안 채택).
- (자체 판단) 「하이 텐션 **해제 시**」 → `event:state_end:하이 텐션`. 근거: 신데렐라 : 크리스탈 웨이브 「저격모드 해제 시」. `PARSING.md` §4-1에 매핑 행을 더했다(기존 행 의미 변경 없음).
