## 스킬 간 상호작용

- **`하이 텐션` 만료 → `로우 텐션` → `기력 저하`(자기 기절)** — 디메리트 사슬.
  - 경로: 스킬3 `하이 텐션`(35s) 만료 → `event:state_end:하이 텐션` → 스킬2 `로우 텐션`(아군 전체 harmful) → `self_state:로우 텐션` → 스킬2 `기력 저하`.
  - **끊는 길 둘**: ① 스카이 재사용 간격 < 35s(버쿨감·보조 B1) — 해제 전에 갱신돼 `state_end`가 안 나간다(표준이 이 경우). ② 해제 순간 `저항 정신`(스킬1) — harmful `로우 텐션`을 막아 `self_state:로우 텐션`이 거짓이 된다(변형 2).
  - 실행 순서: `로우 텐션`이 막히면 `기력 저하`는 조건 미충족으로 안 걸린다 — `로우 텐션`이 배열 앞이고, 조건은 `tick()`의 조건부 유한 passive 블록이 다음 판정에서 읽는다. 막힌 것은 4명 각자의 면역 1개씩이다(면역 개수는 니케 1인당).
- **`저항 정신`의 자기 조건** — `not_self_state:저항 정신`이라 5초 안에 다시 홀드해도 재부여되지 않고, 전투 중 3회로 끝난다. 개수(1개)는 첫 harmful에 소모된다. 기본 경로에는 막을 harmful이 `로우 텐션`뿐이다.
- **기절이 사이클을 멈춘다** — 기절 중 B1은 만료까지 재시도(`BurstController._try_use_stage`)라, 같은 단계 동료가 없으면 스쿼드 풀버스트가 기절 내내 끊긴다(변형 1: 15회 → 3회).
- **`하이 텐션` 3중첩** — 중첩 부여가 지속을 갱신하므로 재사용 간격 < 35s면 3중첩이 끝까지 유지된다(표준).

## 유저 확인 사항
- Q1: 스카이(SR)의 `post_reload_delay` 실측값? A: 기본값 0 사용 (2026-11-20).
- (자체 판단) `[하이 텐션 해제 시]` → `event:state_end:하이 텐션`. 근거: PARSING §4-1 `[상태명] 상태 종료 시`, 엔진이 만료·명시적 제거 둘 다 이 이벤트를 낸다(`IMPL-STATUS.md`). 선례 조회 0.5 이상 없음.
- (자체 판단) `[로우 텐션 : 시전자 기준 공격력 10% ▼]` → `atk_caster_based_pct` `fixed_value: -10` · harmful. 근거: 아군에게 거는 디메리트는 harmful(이사벨 `소닉 체이서 5`). harmful이라 `저항 정신`이 막는다 — 원문 설계(면역 ↔ 디버프)와 맞물린다.
- (자체 판단) `[저항 정신 : 해로운 효과 면역 1개] [전투 중 3회 발동]` → `debuff_immune_count` `fixed_value: 1` + `max_trigger: 3`. 근거: 에이드 `완벽한 메이드` · 클레이 `WAKE UP!`(개수), 나유타 `부동심`(전투 중 N회).
- (자체 판단) `[관통 특화]` → `pierce_enabled`(neutral). 근거: 스노우 화이트 : 헤비암즈 `어나더 화이트 관통특화`.
- (자체 판단) 벨벳 `나쁜 손버릇` · 스노우 화이트 : 헤비암즈 `세븐스 드워프 V+VI`의 CDN 문구 변경(「풀 버스트 **상태가** 아니라면」 → 「풀 버스트 **타임이** 아니라면」)은 같은 뜻이라 파싱 불변(`not_during_full_burst`). 수치 변경 없음, 두 캐릭터 parsecheck N~S ✓.
