## 스킬 간 상호작용

- **버스트 → 스킬2 패널티 연쇄**: `하이 텐션` 해제 → `로우 텐션` → 기절. 원문 블록 순서 그대로고, 기절은
  `self_state:로우 텐션` 조건부 passive라 로우 텐션이 **붙은 뒤의 tick**에 켜진다(변형 2: 38.00 → 38.02). 순서가 뒤집힐 여지가 없다.
- **재버스트 갱신 = 패널티 회피**: 스카이 버스트 간격이 35s 미만이면 `하이 텐션`이 끊기지 않아 패널티가 영원히 0회다.
  버쿨감 B1 동료(리틀 머메이드)와 쓰면 25.17s 간격이라 이 상태가 기본이다. 간격을 가르는 것은 스카이가 아니라 **스쿼드의 사이클 프로필**이다.
- **스킬1 면역 ↔ 스킬2 패널티**: `저항 정신`(해로운 효과 1개, 5s)이 `하이 텐션` 만료 순간 켜져 있으면 각 아군의 `로우 텐션`이 막히고,
  스카이 자신의 로우 텐션이 막히면 기절 조건도 거짓이라 **기절까지 사라진다**. 효과를 보려면 만료 직전 5초 안에 홀드가
  끝나야 하고, 전투 중 3회뿐이다. 홀드 시각이 고정 시퀀스면 만료 시각(스쿼드마다 다르다)을 맞히지 못한다 — 변형 2에서
  38.0~40.2 홀드는 38.02 기절에 걸려 판정 자체가 안 났다.
- **기절 → 홀드·버스트 차단**: 기절 중에는 차지도 못 하므로 `charge_hold:1`도 막힌다. `관통 특화` 40s 갱신이 기절 구간만큼 늦는다.
- **`Runway to hell` 캐스터 기준값**: 스카이 버스트 사이클에는 `FLY! ROCK!`(공격력 50%)이 얹힌 공격력으로 20%를 준다.

## 유저 확인 사항
- Q1: SR의 `post_reload_delay` 실측값이 있는가?
  A: 기본값 0 (유저 답변 2026-11-26) — `_exceptions`에 등록하지 않는다.
- Q2: 같은 패치의 벨벳 · 스노우 화이트 : 헤비암즈 문구 변경(「풀 버스트 상태가 아니라면」 → 「풀 버스트 타임이 아니라면」, 수치 동일)을 재파싱하는가?
  A: 재파싱 안 함 (유저 답변 2026-11-26) — raw 갱신만 반영한다.
- (자체 판단) 「하이 텐션 **해제 시**」 → `event:state_end:하이 텐션`. 근거: 신데렐라 : 크리스탈 웨이브 「저격모드 해제 시」. `PARSING.md` §4-1에 매핑 행을 더했다(기존 행 의미 변경 없음).
- (자체 판단) 시점 표기 없는 「로우 텐션 상태일 때 한하여 자신에게 … [20초 유지]」 → `passive` + `self_state:로우 텐션`. 근거: 밀크 : 블루밍 바니 `성질 내기`(같은 문형, `[지속]`), 유한 지속 규약은 에이드·치사토(`_is_cond_finite_passive`, 유저 결정 2026-09-15). **딜이 갈리는 자리라 단계 3 잔여 질문으로 올린다**(해석 선언 1).
- (자체 판단) `저항 정신`은 아군 디버프(`로우 텐션`)도 막는다 — `debuff_immune_count`가 harmful을 출처 무관하게 막는 현행 동작 그대로. 스킬 설계(면역 ↔ 패널티)와도 맞는다.
