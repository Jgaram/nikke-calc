# 캐릭터별 파싱 데이터 (현황 · 예외)

> `PARSING.md`(파싱 규칙 정본)에서 분리한 **캐릭터별 데이터**. 규칙 문서는 일반 규칙만 유지하고,
> 캐릭터가 늘 때마다 증가하는 현황·예외는 이 파일에 누적한다. `char-add` 단계 1~3이 참조.

## 현황 목록

파싱이 끝나면 `완료`, 온전히 안 된 경우 `진행 중`에 넣는다.
**아직 파싱하지 않은 캐릭터 목록과 배치 계획은 `미파싱_추가계획.txt`가 정본이다** —
이 문서는 끝난 것만 담으므로, 여기 없다고 로스터가 전부 끝난 것은 아니다.
`프리뷰`는 출시 전 카드 이미지로 파싱한 캐릭터다(`scraper/preview_skills.json`). 파싱이 끝나도
출시 후 정식 등록(char-add 단계 R)을 거쳐야 `완료`로 간다.
