# 캐릭터 별칭

유저가 프롬프트에서 쓰는 축약·통칭을 정식 명칭으로 해석하기 위한 문서.

**원칙**
- **Claude의 답변과 코드·데이터에는 반드시 정식 명칭만 쓴다.** 별칭은 *입력 해석 전용*이다.
- 정식 명칭의 정본은 `data/parsed_nikke.json` / `data/parsed_skills.json`의 키다. 이 문서와 어긋나면 JSON이 옳다.
- **별칭 표는 유저가 채운다.** Claude가 임의로 별칭을 지어 추가하지 않는다.
- 표에 없는 축약어가 나오면 추측해서 진행하지 말고 유저에게 확인한다. 확인된 별칭만 이 표에 추가한다.

## 해석 규칙 (표보다 먼저 적용)

1. **부제만 써도 된다** — `헤비암즈` → `스노우 화이트 : 헤비암즈`. 단 `레드 후드`는 예외(아래 §주의).
2. **기본 이름은 언제나 원본이다** — `신데렐라` → `신데렐라`(이격은 `수신데`), `아니스` → `아니스`.
   이격은 부제나 아래 별칭 표의 별칭으로만 부른다. 원본·이격이 함께 있는 계열은 아래 §주의 표에
   전부 올라와 있다(doclint 검사 F가 누락을 잡는다).
   2026-09-24 [21] 배치로 로스터 전원이 파싱되기 전에는 원본이 미파싱이면 기본 이름을 이격으로 읽었고
   (`마스트` → `마스트 : 로망틱 메이드`, `아니스` → `아니스 : 스타`), 별칭 표도 원본 이름을 이격의
   별칭으로 들고 있었다. **그 분기와 별칭은 전원 파싱과 함께 걷어냈다**(유저 지시 2026-09-24) —
   원본 이름을 이격의 별칭으로 다시 넣지 않는다.
3. **띄어쓰기·콜론 주변 공백은 무시** — `라피:레드후드` = `라피 : 레드 후드`.
4. **`(가칭)`이 붙은 이름은 별개 키다** — `레이`와 `레이 (가칭)`은 다른 캐릭터다(아래 §주의).
   가칭은 정식 명칭이 확정되면 스크래퍼가 키를 바꾸므로, 그때 이 문서도 같이 고친다.
5. **`(SR)`처럼 등급이 괄호로 붙은 이름은 동명이인의 개명 키다** — 이격이 아니다.
   게임에 이름이 똑같은 별개 캐릭터가 존재하면(`사쿠라` SSR / SR) 스크래퍼가 등급 높은
   쪽에 맨이름을 주고 나머지를 `사쿠라 (SR)`로 개명한다. 등급까지 같으면 `사쿠라 (836)`처럼
   resource_id로 떨어진다. 규칙의 정본은 `.agent/skills/char-scrape/SCRAPER.md §동명이인 처리`.
   맨이름은 **항상 등급이 높은 쪽**을 뜻하므로, 낮은 쪽을 쓰려면 접미사까지 그대로 친다.
