# bug-fix

calculator 버그 수정.

$ARGUMENTS: 대상 캐릭터 + 증상.

인자 없거나 캐릭터명만 있으면 작업 중단, 아래 정보 요청:
1. 발생 조건 (스쿼드 구성, 운용 방식)
2. 기대 동작 (예상 사이클, 버프 발동 여부)
3. 실제 동작

**충분:** `/bug-fix 라피 : 레드 후드 — 팀에 1버스트 없을 때 본인이 1버스트가 되는 조건에서, 버스트 쿨 20초 감소 효과가 발동하지 않음. 12.52초 간격 사이클이 나와야 정상인데 32초대로 나옴.`

**불충분 (진행 안 함):** `/bug-fix 신데렐라 딜 수치 이상`

---

## 시작 전

`context/CALCULATOR.md` 읽는다.

---

## 스쿼드 구성

`parsed_nikke.json`에서 대상 버스트 단계·쿨타임 확인 후 템플릿 선택:

```
B3:          ["리틀 머메이드", "크라운", TARGET, "test_B3"]
B1 (쿨 20s): [TARGET, "크라운", "신데렐라", "test_B3"]
B1 (쿨 40s): [TARGET, "리틀 머메이드", "크라운", "신데렐라", "test_B3"]
B2 (쿨 20s): ["리틀 머메이드", TARGET, "신데렐라", "test_B3"]
B2 (쿨 40s): ["리틀 머메이드", TARGET, "크라운", "신데렐라", "test_B3"]
```

---

## 재현 및 수정

1. `context/test.py` 스쿼드 수정 후 실행 (`python -m context.test`).
2. 버스트 사이클 간격이 **12.5초에서 5초 이상 벗어나면** — 중단. 유저에게 스쿼드 구성 확인. 응답 전까지 작업 금지.
3. 버프 스냅샷·히트 이벤트로 버그 재현.
4. 원인 파악·수정.
5. test.py 재실행 확인.

---

## 회귀 테스트

calculator 코드 수정 시 필수 (`python -m context.regression_test`).

- PASS: 완료
- FAIL: **재시도 없이 중단**. 실제 딜 수치 보고 후 지시 대기.

상세: `context/IMPL-STATUS.md` `### 운영` 섹션.
