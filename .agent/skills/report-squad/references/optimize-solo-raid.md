# 솔로레이드 N스쿼드 최적화·지정 편성

한 도구가 두 가지를 한다.

- **최적화**: 기존 `report-squad` 캐시의 후보 중 캐릭터가 겹치지 않는 정확히 N개 스쿼드를
  골라 평균 총딜 합이 최대인 해를 찾는다. 새 시뮬레이션은 하지 않는다.
- **지정 편성**: 사용자가 N×5명을 직접 지정하면 그 편성의 총딜을 낸다. 후보 캐시에 같은
  편성이 있으면 그 결과를 재사용하고, **없는 스쿼드만 새로 시뮬한다**.

두 모드는 한 스펙 안에서 탭으로 섞을 수 있다. 사용자가 최적화 없이 편성만 계산해 달라고
하면 최적화 variant를 넣지 않는다 — 그때는 최적해와 무관한 계산 보고서가 된다.

## 시작 조건

- 후보를 쓰려면 같은 랩쳐·전투 시간·기본 육성으로 계산된 후보 보고서가 있어야 한다.
- 후보 캐시는 `.report-work/<원본-슬러그>/result.data.json`에 있어야 한다.
- 최적화에서는 후보에 없는 스쿼드를 임의로 만들지 않는다. 새 편성은 사용자가 지정했을 때만
  (`pinned_squads`) 계산한다.
- 기본 육성이 다른 캐시는 한 최적화에 섞지 않는다.

## 스펙

`.report-work/<슬러그>/spec.json`:

```json
{
  "title": "작열 솔로레이드 5스쿼드 총딜 최적화",
  "sources": ["../fire-solo-decks/result.data.json"],
  "target": {
    "enemy": {"code": "풍압", "core_px": 0, "has_parts": false},
    "config": {"duration": 180.0}
  },
  "require_same_defaults": true,
  "squad_count": 5,
  "top_k": 10,
  "variants": [
    {"name": "전체"},
    {"name": "내 편성", "pinned_squads": [
      ["아니스 : 스타", "브리드 : 사일런트 트랙", "레이", "마스트 : 로망틱 메이드", "디젤 : 윈터 스위츠"],
      ["...", "...", "...", "...", "..."]
    ]}
  ]
}
```

`variants`에는 `exclude_members` 같은 후보 필터를 둘 수 있다. 사용자 요청 없이 제외 조건을
추가하지 않는다.

### `pinned_squads`

- 항목은 이름 배열이거나 `{"name", "members", "config", "chars", "defaults", "no_layer"}` dict다.
  뒤 네 키는 `report.py` 케이스와 같은 뜻이며, 하나라도 있으면 캐시를 쓰지 않고 새로 시뮬한다.
- **배열 순서가 버스트 우선순위다.** 캐시에 같은 5명이 있어도 순서가 다르면 다시 시뮬한다.
- 지정 편성 전체에 캐릭터가 겹치면 실행이 멈춘다.
- 스쿼드 수는 지정한 만큼이다 (`squad_count`는 최적화에만 쓴다).
- 새 시뮬은 **첫 후보 원본의 난수 모드·시드셋·반복 수·전역 육성/랩쳐 조건**을 그대로
  물려받는다. 기대값 모드(보고서 기본)로 뽑은 후보면 지정 스쿼드도 기대값 모드 1회로 돌아
  같은 기준에서 합산되고, `--sampled`로 뽑은 후보면 시드가 짝지어진다. 결과는 `.report-work/<슬러그>/pinned.data.json`에
  캐시되며, 계산기 코드·데이터가 바뀌면 자동으로 다시 돈다.
- `sources` 없이 `pinned_squads`만 두면 후보 없이 전부 새로 시뮬한다. 이때 난수 모드·시드·
  반복은 스펙의 `config.rng_mode`·`runs`(기본은 기대값 모드 1회), 육성·설정은 스펙의
  `defaults`·`config`·`enemy`를 쓴다.

## 실행과 보고

```bash
python .agent/skills/report-squad/scripts/optimize_solo_raid.py \
  .report-work/<슬러그>/spec.json
python .agent/skills/report-squad/scripts/optimize_solo_raid.py <스펙> --jobs 8
```

`--jobs`는 지정 편성의 신규 시뮬 병렬 수다 (0=자동). 시뮬 1회당 15~40초이므로 캐시에 없는
스쿼드가 많으면 미리 알린다.

결과는 `reports/<슬러그>.html`에 생긴다. 한 해는 초상화 5×N 블록 한 덩어리로 붙어 나오고,
각 줄 오른쪽에 스쿼드 총딜만 둔다. 운용·CV·FB는 블록 아래 각주로 내려간다.

답변에는 총딜 합과 1위 해의 스쿼드를 적고, 후보 원본·후보 수·제외 조건을 함께 밝힌다.
지정 편성이면 **재사용한 스쿼드 수와 새로 시뮬한 스쿼드 수**, 최적화 탭이 함께 있으면
최적해 대비 차이도 적는다. 원본 보고서의 기본 스펙 이탈도 그대로 이어서 보고한다.
