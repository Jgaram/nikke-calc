# 캐릭터 별칭

유저가 프롬프트에서 쓰는 축약·통칭을 정식 명칭으로 해석하기 위한 문서.

**원칙**
- **Claude의 답변과 코드·데이터에는 반드시 정식 명칭만 쓴다.** 별칭은 *입력 해석 전용*이다.
- 정식 명칭의 정본은 `data/parsed_nikke.json` / `data/parsed_skills.json`의 키다. 이 문서와 어긋나면 JSON이 옳다.
- **별칭 표는 유저가 채운다.** Claude가 임의로 별칭을 지어 추가하지 않는다.
- 표에 없는 축약어가 나오면 추측해서 진행하지 말고 유저에게 확인한다. 확인된 별칭만 이 표에 추가한다.

## 해석 규칙 (표보다 먼저 적용)

1. **부제만 써도 된다** — `헤비암즈` → `스노우 화이트 : 헤비암즈`. 단 `레드 후드`는 예외(아래 §주의).
2. **기본 이름은 원본의 파싱 여부로 갈린다** (`data/parsed_skills.json` 기준)

   | 상황 | 해석 | 예 |
   |---|---|---|
   | 원본이 파싱됨 | **원본** | `신데렐라` → `신데렐라` (이격은 `수신데`) |
   | 원본 미파싱 · 이격 1개 | **그 이격** | `마스트` → `마스트 : 로망틱 메이드` |
   | 원본 미파싱 · 이격 2개 이상 | **아래 별칭 표의 기본값** | `아니스` → `아니스 : 스타` |

   원본이 파싱된 계열은 아래 §주의 표에 전부 올라와 있다(doclint 검사 F가 누락을 잡는다).
   잘못 해석해 미파싱 원본으로 내려가면 `simulate()`가 에러로 끊는다(`timeline._check_names`) —
   조용히 틀리지는 않지만, 처음부터 맞게 변환하는 게 맞다.
3. **띄어쓰기·콜론 주변 공백은 무시** — `라피:레드후드` = `라피 : 레드 후드`.
4. **`(가칭)`이 붙은 이름은 별개 키다** — `레이`와 `레이 (가칭)`은 다른 캐릭터다(아래 §주의).
   가칭은 정식 명칭이 확정되면 스크래퍼가 키를 바꾸므로, 그때 이 문서도 같이 고친다.

## 주의: 헷갈리기 쉬운 쌍

정식 명칭끼리 충돌하는 경우. 아래는 별칭이 아니라 **정식 명칭 간 구분**이다.

| 입력 | 해석 | 비고 |
|---|---|---|
| `레드 후드` | **레드 후드** | 별개 캐릭터. `라피 : 레드 후드`가 아님 |
| `신데렐라` | 신데렐라 | ↔ `신데렐라 : 크리스탈 웨이브` |
| `스노우 화이트` | 스노우 화이트 | ↔ `스노우 화이트 : 헤비암즈` |
| `헬름` | 헬름 | ↔ `헬름 : 아쿠아마린` |
| `아르카나` | 아르카나 | ↔ `아르카나 : 포츈 메이트` |
| `맥스웰` | 맥스웰 | ↔ `맥스웰 : 오디너리 미케닉`(별칭 `풍스웰`). 원본은 철갑 SR 화력형, 이격은 풍압 지원형 |
| `아니스` | **아니스 : 스타** | 원본은 미파싱·미사용. 이격이 둘이라 자동 판별 불가 — 더 자주 쓰는 쪽으로 고정. `아니스 : 스파클링 서머`는 `수니스`로만 지칭 |
| `라플라스` | 라플라스 | ↔ `라플라스 : 얼티밋 히어로`. 원본은 철갑 RL 화력형(B3·쿨40), 이격은 풍압 RL 화력형. 둘 다 파싱 완료 |
| `레이` | 레이 | 작열 MG. 파싱 완료 |
| `레이 (가칭)` | 레이 (가칭) | 풍압 AR. 별개 캐릭터이며 `레이`의 이격이 아니다. 별칭 `풍레이`. 이쪽도 파싱 완료 |

## 큐브 별칭

정식 명칭의 정본은 `data/base_stat_tables/cube.json`의 키다(큐브 17종 + `공통`).
캐릭터와 같은 원칙 — 코드·데이터·답변에는 정식 명칭만 쓴다.
아래는 새로 지은 별칭이 아니라 2026-08-14 이전 `cube.json`이 키로 쓰던 이름을 옮긴 것이다.

| 정식 명칭 | 별칭 | 효과 |
|---|---|---|
| 렐릭 베어 큐브 | 재장 | 재장전 속도 ▲ |
| 택티컬 베어 큐브 | 탄충 | 10발 사격 시 탄환 충전 ▲ |
| 렐릭 비고르 큐브 | 체력 | 최대 체력 ▲ |
| 렐릭 부스트 큐브 | 차속 | 차지 속도 ▲ |
| 렐릭 디스트로이 큐브 | 파츠 | 파츠 대미지 ▲ |

`공통`은 큐브 이름이 아니라 **어떤 큐브를 껴도 붙는 두 번째 스킬**(안티 코드 HC ·
우월 코드 공격 대미지)의 키다. 17종 전부가 이 스킬을 공유한다.
