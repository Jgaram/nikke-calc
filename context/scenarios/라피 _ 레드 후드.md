## 스킬 간 상호작용

- **`전투 보조` self_state가 모든 모드 분기의 핵심 — full_burst_end 시점에 재평가**
  - 경로: full_burst_end → `no_burst1_ally` 평가 → 전투 보조 부여/해제 → 다음 사이클의 모든 `self_state:전투 보조` / `not_self_state:전투 보조` 조건부 효과 분기
  - 시점: full_burst_end 직후. 팀 B1 캐릭터 상태가 결정적.
  - 위험: 시뮬에서 사망 처리 없으므로 한 스쿼드 내 모드 고정.

- **`유탄` 스택 (적 단위 누적 → 풀버스트 진입 시 폭발 → 제거)**
  - 경로: 풀버스트 밖 매 hit_count:120 도달 → 부착형 유탄 4 → 유탄 +1 (적, harmful, max=∞) → full_burst_start 시 `유탄 폭발` (49.71 × stack) → 그 후 `유탄 제거`
  - 시점: full_burst_start. 폭발 → 제거 순서 (Q1).
  - 위험: 폭발 전 스택 수가 결정적. MG warmup·hit_count 정확 모델링 필요.

- **`계승되는 힘` (전투 보조 모드 본인 쿨 -20s) → 사이클 간격 12.5s 유지**
  - 경로: 전투 보조 활성 사이클의 burst_cast → 본인 쿨 -20s → 실효 12.5s 사이클 (Q2)
  - 위험: 변형 1에서 다른 캐릭터와 동일 사이클 간격 유지 확인.

- **`계승되는 힘 7` (trigger_count_reduce 60 절대값)**
  - 경로: 본인 B3 모드 burst_cast → 부착형 유탄 4 hit_count 120→60 (10s) → 풀버스트 중 발동 빈도 ~2배 → 즉발 폭발 빈도 ~2배
  - 시점: burst_cast 부여, 10s. 풀버스트와 정렬.

- **`계승되는 힘 6` (+421.2) + 부착형 유탄 2 (+150.72) projectile_attachment_dmg_pct 합산**
  - 경로: 변형 2 본인 burst_cast 시 부착형 유탄 4 대미지에 +421.2 추가 (10s) → 기본 +150.72와 합산 적용
  - 위험: 합산/곱 처리 차이가 결정적. `projectile_attachment_dmg_pct` 누적 방식 시뮬에서 확인.

- **`부착형 유탄` element_code_override (라피 단독 메카닉, Q6)**
  - 경로: battle_start → 본인 작열인데 **전격 적(=철갑 우월)에도 우월코드 대미지 적용** → 우월코드가 두 속성에 동시 적용
  - 위험: 시뮬에서 element 매치 체크가 이 캐릭터만 다중 코드 처리하는지 확인.

## 유저 확인 사항

- Q1: 유탄 폭발과 유탄 제거 동일 timing(full_burst_start) — 폭발이 제거보다 먼저 평가?
  - A: **맞음**. 폭발 → 제거 순서. 폭발이 누적 스택 수로 산정 후 제거.

- Q2: 전투 보조 모드 본인 실효 사이클 간격?
  - A: **실제 12.5초 사이클**. 다른 캐릭터와 동일.

- Q3: `trigger_count_reduce` 60 — 절대값 vs 비율?
  - A: **절대값**. hit_count 120 → 60.

- Q4: `full_burst_start` timing 본인 burst_cast 무관 트리거?
  - A: **그렇다**. 신데렐라 `burst_enter:3`과 동일.
  - → GAMEPLAY §트리거 발동 의미 `full_burst_start`에 일반 규칙 승격.

- Q5: `burst_stage_override:1` 동작?
  - A: **스쿼드에 기본 B1 캐릭터 없으면 본인이 B1으로 발동**. 라피 단독 메카닉.

- Q6: `element_code_override` 처리?
  - A: 작열(본인) + 전격(=철갑 우월 코드) 둘 다 우월코드 적용. 현재 본 캐릭터 단독.
