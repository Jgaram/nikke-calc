## 핵심 — 취기 중첩은 "거는 순간" 값으로 고정된다

`취기`는 **명중률 ▼ = polarity harmful, max_stack 3**이다. 그래서
**앵커 : 이노센트 메이드**의 `불가사리(모양) 오므라이스` 3회차
`[중첩 가능 해로운 효과 중첩량 1개 ▼]`(`debuff_stack_remove`, full_burst_start)의
**제거 대상이 된다.** 두 캐릭터를 같이 쓰면 매 풀버스트마다 취기가 1개씩 깎인다.

그런데 깎이는 시점이 마스트가 버프를 건 **뒤**라, 인게임에서는
**마스트의 버프는 3중첩 값으로 적용되고, 풀버스트 동안 취기 자체는 2중첩으로 진행된다.**

### 사이클 순서 (실측, 신데렐라 5인 스쿼드 seed=1, 3번째 풀버스트)

| t | 이벤트 | 취기 | 마스트 버프 |
|---|---|---|---|
| 28.067 | B1 진입 (아니스 : 스타) → `burst_enter:1` | 2 → **3** | — |
| 28.167 | 마스트 B2 사용 → `burst_cast` / `burst_enter:3` | 3 | 스피릿·로망3 **3중첩으로 고정** (시공증 60.18%) |
| 28.317 | 풀버스트 시작 → 앵커 오므라이스 3회차 발동 | 3 → **2** | 고정값 3 유지 |
| 28.32 ~ 38.32 | 풀버스트 진행 | **2** | 시공증 **60.18% 유지** |
| 38.317 | 풀버스트 종료 (취기 < 3이므로 숙취 미발동) | 2 | 만료 |

즉 **"취기 스택 수 = 2"와 "마스트 버프 = 3중첩 값"이 동시에 성립**하는 구간이 존재한다.
풀버스트 중 취기 스택만 보고 버프 값을 역산하면 틀린다.

> 앵커가 취기를 깎기 때문에 취기가 3에 머무는 시간이 매우 짧고,
> 결과적으로 `숙취`(최대 중첩 시 기절)가 거의 발동하지 않는다.
> 마스트 단독(앵커 없음) 조합에서는 취기가 3까지 쌓인 뒤 풀버스트 종료 시
> 해제 + 기절 10초가 걸리므로 사이클이 전혀 달라진다 — **앵커 동반 여부로 두 케이스를 나눠 검증할 것.**

## 구현 메모

`scaling: stack_count` + `scaling_ref` 버프는 **발동 시점의 참조 중첩을 고정**한다
(`BuffManager._capture_scaling_stack`, `ActiveBuff.scaling_stack`).
조회 시점에 실시간으로 읽으면 위 구간에서 마스트 버프가 3 → 2로 같이 내려앉아 딜이 과소평가된다.

단, `duration: -1`(지속) 버프는 게이지를 실시간 추종하는 쪽이 맞으므로 고정 대상에서 제외한다
(솔린 : 프로스트 티켓 `티켓 효과` 등 — 한 번 등록되고 갱신되지 않아 고정하면 초기값에 얼어붙는다).
