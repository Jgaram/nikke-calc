# 리틀 머메이드 검증 시나리오

## 기본 정보
- 버스트 단계: B1, 쿨다운 20초
- 무기: SMG, 기본 max_ammo = 120

## 검증 스쿼드
```python
squad = [make_char(n) for n in ["리틀 머메이드", "크라운", "test_B3", "스노우 화이트 : 헤비암즈"]]
```

## 타임라인 (equip_skills max_ammo_pct=120% 기준)
- 전투 시작: ammo = 264 (버프 반영 max_ammo)
- burst_cast 시 스킬3 `머메이드 레인 2` (ammo_charge_pct 33.26%, lv10) 발동
  - 충전량: round(264 × 0.3326) = 88발
  - ammo = min(현재ammo + 88, 264) → 264 초과 불가

## 체크리스트

- [x] 전투 시작 ammo = 264 (버프 반영, 기본 120 초과)
- [x] burst_cast 후 ammo ≤ 264 (최대 장탄 초과 없음)
- [x] 충전 후 ammo가 기본 max_ammo(120) 초과해도 정상 (buffed max_ammo = 264)

## 수정 내역

**버그**: `CharState.__init__`에서 `ammo = weapon["max_ammo"]`(기본값)으로 초기화되고, `bm.battle_start()` 이후 버프가 적용된 실질적 max_ammo로 갱신되지 않음. `ammo_charge_pct`가 버프 반영 max_ammo 기준으로 충전하여 기본 max_ammo를 초과하는 값이 됨.

**수정**: `bm.battle_start(0.0)` 직후 모든 CharState의 ammo를 `_full_ammo(bm, 0.0)`으로 재초기화.
