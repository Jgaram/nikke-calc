### 탄창 주기 (핵심 상수)

N발을 0.4s 간격으로 쏘고, **마지막 탄 뒤 다음 발이 나올 시각(+0.4s)에 재장전이 시작된다**
(`_tick_auto` — `ammo <= 0`을 다음 발사 시점에 확인). 그래서 한 바퀴는
`(N−1)×0.4 + 0.4 + 재장전 + 0.1667`이다:

| 상황 | 최대 장탄 | 재장전 | 탄창 주기 | 10초당 발수 |
|---|---|---|---|---|
| 무버프 · 무장비 (이론값) | 9 | 1.000s | 4.77s | ~19 |
| **하네스 기본 스펙 평시** (장비 옵션 최대장탄 +129.64% · 크라운 재장속) | **21** | 0.35s | 8.92s | ~23 |
| **하네스 기본 스펙 버스트 중** (`reload_time_fixed`) | 21 | 0.0167s(1프레임) | 8.58s | **24** |

> **장비 옵션이 최대 장탄을 9 → 21로 올린다** (`char_defaults.json` 주석 — 하네스 기본 스펙은
> 전 캐릭터에 최대장탄 +129.64%). 질에게 이건 중립이 아니다 — `매그넘탄`이 `[9발 유지]`라
> **한 탄창 21발 중 9발만 덮는다.** 아래 §매그넘탄 커버리지.

`event:full_reload`는 하네스 기본 스펙에서 180초에 **22회**(장탄 9발 기준이면 50회).
이 캐릭터의 패시브가 전부 여기 걸려 있어 탄창 주기가 곧 버프 주기다.

### `post_reload_delay` = 0.1667s (실측 역산, 2026-08-16)

유저 인게임 실측: **버스트 10초 구간의 기본공격 24발** ("25발이 아슬아슬하게 안 된다").
표준 스쿼드로 딜레이를 훑어 역산했다. **최대 장탄이 다르면 구간도 달라져** 두 스펙 모두에서 쟀다:

| `post_reload_delay` | 장탄 9발 스펙 | 하네스 기본 스펙 (장탄 21발) |
|---|---|---|
| 0 (무기군 기본값) | 25 | 25 |
| 0.10 | 25/24 혼재 | 25 |
| 0.15 | 24 | 25 |
| **0.1667** | **24** | **24** |
| 0.23 | 24 | 24 |
| 0.30 | 23 | 24 |
| 0.40 | 23 | 23 |

24발 구간이 각각 **0.11~0.23** / **0.16~0.35**이고 **교집합은 0.16~0.23**이다.
그 하단의 프레임 정수값인 **10프레임(0.1667s)** 을 `weapon_delays.json` `_exceptions.질`에
기록했다. 주의할 점 둘:
- 이 딜레이는 **버스트뿐 아니라 모든 재장전에** 붙는다. 비버스트 구간 발수 실측이 생기면
  구간을 더 좁힐 수 있다.
- AR에 `post_reload_delay`를 넣은 첫 사례다. 다른 AR도 같은 딜레이를 가질 가능성은 있지만
  **데이터가 질 하나뿐이라 무기군 기본값으로 일반화하지 않는다.**

### 매그넘탄 커버리지 — 오토 사격의 구조적 손실

`매그넘탄`은 `[9발 유지]`인데 하네스 기본 스펙의 최대 장탄은 **21발**이다. 재장전마다 9발분만
부여되므로 나머지 12발은 `normal_atk_dmg_pct` +30% 없이 나간다:

| | 값 |
|---|---|
| 180초 총 기본공격 | 438발 |
| 재장전 완료 | 22회 (탄창당 평균 19.9발) |
| **매그넘탄이 덮는 발수** | **207발 / 438발 = 47%** |

유저 확인(Q8)대로 **인게임에서는 9발째에 강제 재장전 컨트롤로 끊어** 매그넘탄을 다시 채운다.
계산기는 오토 사격만 모델링하므로 **아래 기준선은 컨트롤을 안 한 하한값**이다.
장탄을 올리는 큐브·장비 옵션이 질에게는 이득이 아니라 손해라는 점도 같은 이유다.

## 스킬 간 상호작용

- **`강제 재장전`(슈퍼 캅 3) → `매그넘탄`·`산성탄` 재점화**
  - 경로: `슈퍼 캅`(재장속 고정) → `슈퍼 캅 2`(탄 −100%) → `슈퍼 캅 3`(강제 재장전)
    → 1프레임 뒤 `event:full_reload` → 스킬1·2 블록1 재부여
  - 시점: 3.200 → 3.217. 풀버스트 시작(3.250) **직전**이라 풀버스트 전 구간을 만탄으로 연다.
  - 확정(Q3·Q4): 버스트는 탄을 버리는 손해가 아니라 **풀버스트 직전 만탄 리셋**이다.

- **`슈퍼 캅`(재장속 고정) → 풀버스트 구간 발사 횟수**
  - 탄창 주기 8.92s → **8.58s**, 10초에 **24발**(딜레이 0이면 25발).
  - 장탄 9발 스펙에서는 주기 4.12s → 3.78s로 효과가 훨씬 크다. **장탄이 클수록
    재장속 고정의 값어치가 떨어진다** — 재장전 자체를 덜 하기 때문.
  - 위험: `reload_time_fixed`는 **복수면 최대값**(`IMPL-STATUS.md`). 다른 고정형 재장전
    버프와 겹치면 0.0004가 덮인다. 표준 스쿼드엔 없지만 조합 검증 시 확인.

- **`산성탄 2` DoT — 재부여가 위상을 리셋한다 (딜에 직결)**
  - `max_stack: 1` + type 2 위상(Q6)이라, 재장전마다 다음 틱이 **부여 +1.0s로 밀린다.**
  - 실측: 180초에 DoT **165틱** (연속 유지였다면 ~176틱). 재장전이 잦을수록 손실이 커진다
    — 장탄 9발 스펙에서는 재장전 50회에 158틱까지 떨어진다.
  - `GAMEPLAY.md` §값 산정 — DoT는 **틱이 들어가는 순간의 버프**로 계산된다.
    실측에서 풀버스트 밖 481,714 ↔ 안 1,278,855 (평균)로 갈린다.
  - DoT가 질 딜의 **43.3%** 를 차지한다 — 기본공격(56.7%)에 육박하는 주력이다.

- **버스트 방무 3중 구조**
  - `슈퍼 캅 6`(`armor_break_enabled`, 일반공격 → 방무 전환) × `매그넘탄 2`
    (`armor_break_dmg_pct` +34.99, ⑤항) × `슈퍼 캅 5`(`atk_dmg_pct` +75, ⑤항).
  - `armor_break_enabled`가 없으면 `armor_break_dmg_pct`는 **일반공격에 한 톨도 안 실린다**
    (`is_armor_break_damage=True` 히트에만 가산 — `IMPL-STATUS.md`). 둘은 한 몸이다.
  - 셋 다 `burst_cast` 기준이라 풀버스트 종료보다 0.05s 먼저 끊긴다.

## 유저 확인 사항

- Q1: `산성탄`의 "최대 장탄 재장전 완료 **이후 첫발에 한하여**" — 전투 시작 시 부여분도
  똑같이 "첫발"에서 소비되는가?
  **A: 붙는다.** `battle_start` 부여분도 동일하게 첫 발에서 소비된다.
- Q2: `산성탄` DoT는 재장전마다 새로 부여되는데 **병존 누적**인가 **갱신**인가?
  **A: 갱신 — 항상 1개만 유지.** `max_stack: 1`.
  *(일반 규칙 승격 — `GAMEPLAY.md` §버프 스택)*
- Q3: 버스트의 `[탄환 100% 제거]` + `[강제 재장전]` 완료가 `최대 장탄 재장전 완료`로
  인정되어 `매그넘탄`·`산성탄`이 재부여되는가?
  **A: 인정된다.** *(일반 규칙 승격 — `GAMEPLAY.md` §timing `event:full_reload`)*
- Q4: `[재장전 속도 99.96% 증가 상태로 고정]`의 재장전 시간은?
  **A: `1.0 × (1 − 0.9996) = 0.0004초`.** 니케의 "속도 N% 증가"는 시간에 `×(1 − N/100)`이며
  계산기(`timeline.py:1321`)도 이미 이 식이다.
  *(일반 규칙 승격 — `GAMEPLAY.md` §값 산정)*
- Q5: `reload_time_fixed`가 레벨별 값을 못 쓰는 건 스킬 설계가 아니라 구현 한계인가?
  **A: 구현 한계다.** "고정"은 *다른 버프를 안 받는다*는 뜻이지 *레벨과 무관하다*는 뜻이 아니다.
  → `IMPL-STATUS.md` ⚠️로 내리고 단계 4에서 `values` 지원을 넣는다.
- Q6: `산성탄 2` DoT의 첫 틱 위상은 type 1인가 type 2인가?
  **A: type 2 확정** (부여 +1.0s부터). 재장전마다 위상이 리셋돼 틱이 밀리는 현행 동작이 맞다.
- Q7: `매그넘탄 2`(방무 대미지 ▲)는 버스트로 일반공격이 방무로 바뀌어야만 실리는가?
  **A: 맞다.** 버스트를 써야 평타가 방무 대미지가 되고, 그때 방무 대미지 버프도 함께 받는다.
  → `슈퍼 캅 6` 없이 `매그넘탄 2`만 있는 구간은 딜 기여 0이 정상이다.
- Q8: 아군 장탄 증가 버프로 최대 장탄이 9발을 넘으면 `매그넘탄`(9발 유지) 초과분은?
  **A: 버프를 못 받는다 — 오토로 두면 실제로 손해다.** 인게임에서는 9발째에 **강제 재장전
  컨트롤**로 끊어 매그넘탄을 다시 채우는 운용이 필요하다. 계산기는 오토 사격만 모델링하므로
  장탄 버프가 있는 조합의 질 딜은 **컨트롤을 안 한 하한값**으로 읽어야 한다.
