(`--no-burst 치사토` 실측으로 경계 동작 확인 완료).

## 스킬 간 상호작용

- **`초감각 3`(`armor_break_dmg_pct`) → 방무 판정 히트에만 실효**
  - 경로: `armor_break_dmg_pct` → DealForm ⑤에서 `is_armor_break_damage=True` 히트에만 가산
  - 실효 대상 둘: ① `방어 관통 사격 2`(항상 방무) ② 버스트 후 10초 구간의 **일반공격**(`armor_break_enabled` 활성 시에만)
  - 위험: `armor_break_enabled` 미구현 시 ②가 통째로 빠진다 — 적 방어력 0 처리와 +48.62% 가산이 동시 누락

- **`긴급 충전`(게이지) → `초감각 2/3/4` 유지**
  - 경로: `gauge_charge` 100 → `gauge_above:` 조건 재평가 → 임계 버프 유지
  - 시점: `duration: -1` + `gauge_above:` 는 `buff_manager._has_runtime_cond` 대상이라 **매 프레임 재평가**된다 (유한 duration 버프는 래치라 해당 없음)

- **`긴급 충전 2` + `초감각 2` — 같은 `atk_pct` 가산 합**
  - 버스트 후 10초 구간: +73.16 + 53.69 = **+126.85** (곱이 아니라 합)

- **동일 timing(`burst_cast`) 실행 순서**: `긴급 충전`(gauge_charge) → `긴급 충전 2`(atk_pct) → `방어 관통 사격`(armor_break_enabled).
  배열 순서는 스킬3 → 스킬2 역순이 아니라 `source` 순(스킬2가 앞)이지만, **세 효과가 서로의 조건을 읽지 않아** 순서 무관하다.
  게이지를 읽는 건 `passive` + 런타임 재평가 항목(`초감각 2/3/4`)뿐이고, 이들은 프레임 종료 후 `get_buffs()` 시점에 평가된다.

- **순환 없음**: 게이지 충전 → 임계 버프 → 딜 방향의 단방향. 딜이 게이지를 되돌리지 않는다.

## 유저 확인 사항

- Q1: 초감각 임계 버프(`≥70 공격력▲` / `≥55 방무딜▲` / `≥25 명중률▲`)는 게이지가 임계 아래로
  떨어지면 **해제되는가**? 텍스트는 `[지속] [해제 불가]`인데 조건이 `~% 이상일 때 한하여`다.
  A: **맞음.** 게이지가 임계 아래로 내려가면 해당 버프는 해제된다. `[해제 불가]`는 버프 해제 면역.
  → **GAMEPLAY.md §condition에 일반 규칙으로 승격 완료.**
  → 코드 실측 확인: `duration: -1` + `gauge_above:` 조합이 이미 매 프레임 재평가된다. 경계는 **이상(≥)** 포함.
- Q2: `[하위 효과 중복 적용]` = 게이지 100%면 무적·ATK·방무딜·명중률 **4개 전부 동시 적용**이 맞나?
  A: **맞음.** 100%면 4개 전부 동시 적용.
- Q3: `2초 마다 [초감각 1% ▼]` 첫 틱은 t=2인가 t=0인가?
  A: **맞음. t=2.** (GAMEPLAY §효과 실행 순서 — `tick_interval` 첫 발동은 등록+interval)
- Q4: `일반 공격 48회 명중 시` 카운터 — a) 조건 없는 상시 카운터가 맞나? b) 발사 = 명중으로 세는 게 맞나?
  A: **둘 다 맞음.** 조건 없는 상시 카운터이고, 발사 = 명중으로 센다.
- Q5: `명중률 {2}% ▲`(`accuracy_pct`)는 집계만 되고 DPS 계산 미사용(⚠️)이다.
  A: **그렇게 둔다.** 명중률이 딜에 기여하는 특별 상황은 따로 있지만
  (`context/scenarios/명중률 탄착군.md` — 탄착군→코어히트율),
  치사토 구현에서는 신경 쓰지 않는다.
  → **단계 4 검증 중 정정**: "DPS 미사용"은 정확하지 않다. `timeline._core_hit_prob()`가
  `accuracy_pct`를 탄착군 직경 산출에 이미 쓰고 있어, **코어 보유 적(`core_px > 0`)에서는
  딜에 반영된다** (기본 보스는 `core_px = 0`이라 무발동). `IMPL-STATUS.md` 해당 행도 함께 정정했다.
- Q6: 버스트의 `초감각 100% 충전`은 set to max인가 +100 가산 후 cap인가?
  A: **set to max** (최대치까지 채움). cap이 100이라 `gauge_charge fixed_value: 100`과 결과 동일.
