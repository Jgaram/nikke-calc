## 스킬 간 상호작용

- **`매터 시그마 2·3`은 본인 버스트의 *다음* 사이클에 붙는다**
  - 경로: `full_burst_end` + `burst_casted` → `매터 시그마` 재부여 → 다음 `full_burst_start`에서 `self_state:매터 시그마` 통과 → 버프 부여 후 `매터 시그마 해제`
  - 시점: 마나 버스트 주기(2사이클)와 소비 주기(1사이클)가 어긋나 **버스트 사이클에는 버프가 없고, 그 다음 사이클에 버프만 있다**
  - **배치는 이 캐릭터에서 거의 영향이 없다** (실측): 마나를 test_B3 뒤로 밀어도 버스트 7회·시그마 버프 8회로 앞에 뒀을 때(8회·8회)와 거의 같다. B3는 쿨이 최소 40초라 앞사람이 슬롯을 독점할 수 없기 때문이다 — 독점이 성립하는 건 B2 20초처럼 쿨이 짧은 단계다(GAMEPLAY §버스트 사용 순서와 배치)
- **`매터 시그마 해제`가 같은 프레임의 `매터 시그마 2·3`을 죽이지 않는다**
  - 근거: `_has_runtime_cond()`는 유한 duration 버프를 재평가 대상에서 제외한다(`expires != inf → False`). `self_state:`가 런타임 조건이어도 10초 버프는 끝까지 간다
  - 위험: 이 규칙이 바뀌면 마나의 주 버프가 **0초**가 된다 → 회귀 시 최우선 확인 항목
- **`매터 시그마`(재부여 항목)의 name 중복이 메카닉의 전제다**
  - 경로: `self_state:매터 시그마`·`remove_named_buff`가 이름 문자열 정확 매칭(`_has_self_state()`)
  - 위험: Step 7의 ` 2` suffix를 붙이면 재부여가 상태로 인식되지 않아 사이클 1 이후 버프가 사라진다
- **`페이탈 에러!`(버프)와 `페이탈 에러! 2`(DoT)는 같은 `burst_cast`에서 이 순서로 발동한다**
  - 경로: `dot_dmg_pct +52.8` → 같은 시전의 DoT 틱 전부 증폭 (원문 블록 순서 = 실행 순서)
  - 위험: 배열을 뒤집으면 첫 틱이 증폭을 놓친다
- **DoT 위상과 풀버스트 경계** (유형 미확인 — 현행 구현 사용)
  - 버스트 시전(t=3.200)과 풀버스트 진입(t=3.250)이 0.05초 차이라 위상이 곧 딜이다
  - 현행 `_dot_timers`는 type 2(+interval) 위상이고 **10틱 전부 들어온다**(실측: 오프셋 +1.0~+10.0, t=4.20~13.20). 풀버스트(3.25~13.25s) 안에 전부 든다
    - GAMEPLAY §효과 실행 순서에는 "만료 프레임 틱 누락"이 적혀 있지만 1초 간격 10초에서는 재현되지 않았다. 별건으로 확인할 것
  - type 1이었다면 첫 틱이 t=3.200 — 풀버스트 밖이라 시그마 버프를 못 받는다
  - 주기 틱 유형이 정리되면 마나 baseline도 함께 바뀐다

## 유저 확인 사항

- Q1: 매터 시그마 재부여 조건 "풀 버스트 타임 종료 시 직전에 자신이 버스트 스킬을 사용 했다면"은 **그 풀버스트 사이클에서 본인이 B3 버스트를 시전했을 때**로 읽으면 되나?
  A: 맞음 (Q2 답변에 포함). → `timing: full_burst_end` + `condition: burst_casted`
- Q2: 그 결과 "본인이 버스트를 쓴 사이클의 **다음** 풀버스트에서만 공격력·공격 대미지 버프를 받는다"는 해석이 맞나?
  A: **맞음.** 버프는 한 사이클 지연되어 붙는다. 캐릭터 한정 위상 규칙이라 GAMEPLAY 승격 대상 아님.
- Q3: `burst_charge_speed_pct`가 🚫(버스트 게이지 모델 단순화로 보류)인데 상태로만 등록하고 수치는 no-op으로 둘까?
  A: **맞음.** `매터 시그마`는 `self_state:` 판정용 명명 상태로만 살린다. 마나 본인 버스트 주기는 40s 쿨(+버쿨감) 그대로.
- Q4: `차지 시간 0.18초 ▼`는 절대값 감소인데 계산기에 해당 stat이 없다. 신규 stat으로 구현할까?
  A: **신규 stat.** 단계 2에서 `charge_time_flat`으로 확정 (음수 = 감소). `charge_time_caster_based`(시전자 기준 환산)와 별도 키.
- Q5: 버스트 DoT의 첫 틱 위상은 type 1인가 type 2인가?
  A: **모름 — 기존 구현대로.** 현행 `_dot_timers`(type 2 위상, 만료 프레임 틱 누락 → 실질 9틱)를 그대로 쓴다. 마나는 GAMEPLAY §효과 실행 순서 표에 **미확인**으로 남는다.
- Q6 (미질의 · 기본값으로 진행): `allies_top_base_charge_time:N` 세부 — (a) "기본"은 `parsed_nikke["charge_time"]`(버프 제외 무기 표기), (b) 차지 무기 아군이 없으면 빈 리스트 → 무발동, (c) 동률이면 스쿼드 입력 순서.
- Q7 (미질의 · 기본값으로 진행): 회복·부활·`매터 감마 해제`는 파싱만 하고 보스 sim에서는 무발동. `아군 전투불능`이 영구 무발동이므로 **매터 감마는 전투 내내 해제되지 않는다**.
