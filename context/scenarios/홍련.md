### 변형 1 상세

버스트 구성: 목단 B1(쿨 40s, `열혈` 로 실질 20s) / 트리나 B2(20s) / 홍련·프리바티·수니스 B3(각 40s)
→ B3 3명이 사이클마다 돌아가며 발동, 홍련 버스트는 대략 3사이클에 1회.

**트리나 버프 대상 — 홍련 전용이 아닌 항목이 있다.** 목단도 `전격 / AR`이라 코드+무기 조건에 함께 걸린다:

| 트리나 효과 | target | 홍련 | 목단 | 비고 |
|---|---|---|---|---|
| 피스풀 트리 (`hp_only_caster_based_pct`) | `allies_code_weapon:전격:AR` | ✅ | **✅ 받음** | 전격 AR 전원 |
| 머덜리 포레스트 3·4 (`accuracy_pct` / `max_ammo_flat`) | `allies_code_weapon:전격:AR` | ✅ | **✅ 받음** | 전격 AR 전원 |
| 피스풀 트리 2 (`invincible`) | `allies_code_weapon_leftmost:전격:AR:1` | ✅ | ❌ | 배치 순서 의존 |
| 피스풀 트리 3·4 (`atk_dmg_pct` / `reload_speed_pct`) | `allies_code_weapon_leftmost:전격:AR:1` | ✅ | ❌ | **홍련 전용은 이 두 개뿐** |
| 머덜리 포레스트 1·2, 뻗은 뿌리 | `all_allies` | ✅ | ✅ | 전원 |

→ "트리나 버프가 홍련한테만" 성립하는 것은 `_leftmost:1` 계열뿐이고, 그것도 **홍련이 목단보다 왼쪽에
배치될 때만**이다. 위 스쿼드 순서(홍련 2번째, 목단 5번째)가 그 조건을 만족한다.

**HP 수렴 — 트리나는 양방향으로 홍련의 `hp_pct`를 움직인다**:
- ↓ `피스풀 트리` / `머덜리 포레스트`의 `hp_only_caster_based_pct`는 **최대 체력만** 올려
  현재 체력을 그대로 둔다 → 부여 즉시 `hp_pct`가 떨어진다 (`GAMEPLAY.md` §condition `self_hp_above:N`).
  즉 t=0 `battle_start` 시점부터 홍련은 이미 100% 미만에서 시작하고, 임계 도달이 표준 스쿼드보다 빠르다.
- ↑ `네이처 그레이스` 3종이 회복 — `full_burst_end` 전체 회복(`heal_hp_pct`) + `full_charge_hit` 시
  저체력(`ally_hp_below:50` / `:30`) 아군 회복.
  자해와 회복이 맞물려 **HP가 어느 값에 수렴하는지**가 이 스쿼드의 관찰 대상이며,
  수렴값이 60%·50% 임계 위/아래 어디냐가 곧 `검신합일 2`·`홍련일섬`의 가동률이다.

사격 모델 — **무기 표기값으로 계산하면 안 된다** (2026-08-16 실측으로 정정).
기본 스펙(`context/spec.py`)의 장비 옵션에 **최대 장탄 +129.64%** 가 있어 20발이 아니라 약 45발이고,
크라운 `원 포 올`·리틀 머메이드의 재장전 속도 버프까지 겹쳐 실효 발사율이 **10.5발/s**다

## 스킬 간 상호작용

- **`육참골단 2`의 자해가 `검신합일 2`·`홍련일섬`의 발동 조건을 만든다 (단방향 램프)**
  - 경로: `current_hp_reduce` → `state["hp_pct"]` 하락 → `self_hp_below:60` / `self_hp_below:50` 충족
  - 시점: 자해 누적이 임계를 넘는 시각이 곧 버프 시작 시각. **딜 총량이 자해 속도에 직접 비례**한다
  - 위험: 자해를 정액으로 구현하면 임계 도달이 5~9초 빨라지고, 홍련 버스트(40s 주기)와의 위상이
    어긋나 `홍련일섬`이 사이클 하나를 통째로 앞당겨 받는다 → **딜 과대**

- **`육참골단`(버프)과 `육참골단 2`(자해)는 같은 `hit_count:10` 프레임에서 순서가 고정이다**
  - 원문 블록 서술 순서가 곧 실행 순서(일반 규칙) → `atk_pct` 부여 후 체력 감소
  - 임계를 넘는 proc에서는 같은 프레임에 `self_hp_below` 재판정이 걸린다 (체크리스트 항목)

- **트리나의 `hp_only_caster_based_pct`가 임계 도달을 앞당긴다** (변형 1)
  - 경로: 최대 체력만 증가 → 현재 체력 불변 → `hp_pct` 즉시 하락 → 조기 충족
  - 시점: `battle_start`(피스풀 트리) + 트리나 `burst_cast`(머덜리 포레스트)마다 추가 하락
  - 상쇄: `네이처 그레이스` 회복이 반대로 밀어 올린다 → 두 힘의 균형점이 곧 버프 가동률

- **`육참골단` 스택은 사격이 이어지는 한 만료되지 않는다**
  - 스택 부여가 지속시간을 갱신하는 일반 규칙(`GAMEPLAY.md` §버프 스택). proc 간격 ~2s < 지속 5s
  - 재장전 2.3s도 5초 안이라 탄창을 넘겨 스택이 유지된다 → 정상 사격 중에는 사실상 5중첩 상시

## 유저 확인 사항

- **Q1. 스킬1 `[현재 체력 4.01% ▼]`의 기준은?**
  - **A: 현재 체력 비례. 그래서 0이 되지 않는다.** (`hp ×= (1 − 0.0401)`)
  - ⚠️ **일반 규칙 — 계산기 수정 필요**: 현행 `handle_current_hp_reduce`
    ([`timeline.py:1947`](../../calculator/timeline.py))는 `hp -= base_hp × val/100` 으로
    **기본 최대 체력 기준 정액 차감**이다. 같은 원문 표기(`[현재 체력 1% ▼]`)를 쓰는
    **그레이브 `라이터즈 스포일러`도 동일 경로**라 이 수정은 그레이브에도 소급된다.
  - → `GAMEPLAY.md` §값 산정으로 승격 완료. **단계 4에서 구현.**

- **Q2. HP 0 도달 시 처리** — Q1이 비례로 확정되어 문제 자체가 소멸. HP는 0에 수렴만 한다.

- **Q3. 스킬3 1블록 `자신의 체력이 50% 이하라면` 의 평가 시점은?**
  - **A: 버스트 발동 시점 1회 평가(래치).** 홍련 스킬은 발동 즉시 10초 버프를 박아두고 끝나는 형태다.
    부여 후 조건이 깨져도 버프는 유지된다. (스킬2 `[지속]`의 상시 재판정과 대비)
  - **현행 구현이 이미 이대로다** (2026-08-16 확인). `buff_manager._has_runtime_cond()`가
    `expires != math.inf`면 무조건 `False`를 반환한다 — `_RUNTIME_COND_PREFIXES`에 등록된
    조건이라도 **유한 지속 버프에는 재판정이 걸리지 않는다.** 재판정은 `duration: -1`에만 적용된다.
  - 그래서 이 캐릭터의 두 조건이 자연히 갈린다: `홍련일섬`(`[10초 유지]`)은 래치,
    `검신합일 2`(`[지속]`)는 재판정. 추가 구현 없이 원문 의미와 일치한다.

- **Q4. 스킬2 1블록 `피격 시 30% 확률로 [최종 공격력 138.24% 추가 대미지]`**
  - **A: 파싱만 하고 무발동으로 둔다.** `received_hit_count:N`은 `_timing_match` 분기만 있고
    `notify` 호출처가 없다([`IMPL-STATUS.md:440`](../IMPL-STATUS.md)) — 아군 피격 모델 부재.
    엄폐물 피격·`enemy_count_above:N`과 같은 클래스. 체크리스트에 네거티브 항목으로 둔다.

- **Q5. 추가 검증 스쿼드**
  - **A: `["트리나", "홍련", "프리바티", "아니스 : 스파클링 서머", "목단"]`.**
    검증 목표 두 가지 — (1) 트리나 버프가 홍련에게만 들어가는지(목단은 안 받는지),
    (2) 자해 + 트리나 회복이 맞물린 상태에서 HP가 어느 수준으로 유지되는지.
  - 조사 결과 **목단도 전격 AR**이라 `allies_code_weapon:전격:AR` 계열은 목단도 받는다.
    홍련 전용은 `_leftmost:1` 계열뿐 — 상세는 §검증 스쿼드 표.

**HP 유지 수준**: 자해와 트리나 회복이 맞물려 **28.6~39.5%에서 균형**을 이룬다.
표준 스쿼드처럼 0으로 흐르지 않지만 **60%·50% 임계는 초반(t≈3s)에 넘고 이후 영구 충족**이라,
`검신합일 2`·`홍련일섬`은 사실상 상시 가동이다. 홍련 딜 비중이 33.3% → 42.4%로 오르는 이유.

> **참고**: 이 수렴 구간은 instant target 해석 수정(`_resolve_targets` 위임) 이후 값이다.
> 수정 전에는 트리나 `네이처 그레이스 2·3`(`allies_lowest_hp:2`)이 시전자로 폴백해
> 홍련에게 저체력 회복이 들어가지 않았고, 수렴 구간이 12.7~19.1%로 낮았다.
