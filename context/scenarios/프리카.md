# 프리카 동작 시나리오

> 모드: 보강

## 기본 정보
- 버스트 단계: B2
- 본인 쿨다운: 40s (단, 앵콜 발동마다 +21s 증가 → 사실상 1회만 발동)
- 무기 유형: SR (풀차지형, charge_time 1.0s)
- 작성 사이클 수: 2 (40s) + 앵콜 루프

프리카는 **민트와 같은 "무대 시스템"(무대 파트 보컬/댄스 · 퍼포먼스 · 떼창 · 앵콜)을 공유**한다. 단독으로는 본인 버스트의 퍼포먼스 버프만 제공하지만, 민트와 함께일 때 앵콜 엔진이 작동해 민트를 보컬 상태에 고정시키고 퍼포먼스를 무한 연장한다.

## 스킬 간 상호작용

- **앵콜(스킬2 4종)은 `event:떼창` + `self_state:퍼포먼스` 두 조건 동시 충족 시에만 발동**
  - 경로: 민트 burst_cast → "떼창" buff 활성 → buff_manager.notify("event:떼창") → 프리카 스킬2 조건 평가 → self_state:퍼포먼스 확인
  - 시점: 떼창 활성화 프레임에 프리카 "퍼포먼스" buff가 _active에 있어야 함
  - 위험: 프리카 퍼포먼스가 끊기면(앵콜 미발동으로 연장 안 됨) 앵콜 중단 → 민트 보컬 고정 해제 → 민트 댄스↔보컬 토글 복귀

- **앵콜 ②(`named_buff_duration_extend`)와 ④(`burst_cooldown_reduce`)가 루프를 자기지속화**
  - ②: "퍼포먼스" buff._end_t += 21s → 다음 민트 버스트 때도 `self_state:퍼포먼스` 유지 → 앵콜 조건 유지
  - ④: 프리카 burst_ready_at += 21s → 프리카 재버스트 불가 → B2 슬롯 민트 전담
  - **첫 프리카 버스트가 "점화", 이후 민트 버스트가 엔진을 계속 돌림**

- **앵콜 ①(민트 보컬 고정) → 민트 보컬 게이트 효과 발현**
  - "무대 파트 : 보컬" buff 활성 → 민트 `self_state:무대 파트 : 보컬` 조건 → 민트 스킬1/2 보컬측 버프(딜버프) 상시 발현
  - 댄스 차례여도 프리카가 덮어쓰므로 민트는 사실상 보컬 상태만 유지

- **스킬1 #4/#5(`passive + self_state:퍼포먼스`)는 프리카 퍼포먼스에 직접 종속**
  - 경로: 스킬3 burst_cast → "퍼포먼스" buff 활성 → passive 조건 충족 → pierce_enabled·outgoing_heal_pct 활성
  - 위험: 퍼포먼스 만료(앵콜 연장 실패) 시 pierce_enabled 비활성

## 유저 확인 사항
- Q: 검증 스쿼드 구성은?
  A: `["아니스 : 스타", "프리카", "민트", "신데렐라", "앨리스"]`. 풀버스트 첫 사이클엔 프리카가 버스트, 이후엔 프리카 쿨이 계속 증가하면서 민트만 버스트 사용.
- Q: 앵콜 효과4 "버스트 스킬 재사용 시간 21초 ▲"의 의미는?
  A: **쿨다운 증가(+21s)**. 본인 버스트 재사용이 21초씩 늦춰짐.
- Q: 스킬3 퍼포먼스가 프리카 본인에게도 적용되는가?
  A: **예, 본인 포함**. 버스트 즉시 본인 퍼포먼스 ON → 스킬1 #4/#5 / 스킬2 앵콜의 self_state:퍼포먼스 조건 활성.
- Q: 앵콜 효과1이 민트를 보컬에 고정시키는가?
  A: 보컬 게이지로 만든다고 생각하면 됨. 전투 중 프리카가 제거되어 민트 혼자 남으면 민트는 버스트마다 댄스↔보컬 교대. **프리카가 있으면 민트가 댄스 차례여도 프리카 스킬 효과로 즉시 보컬로 바뀜 → 사실상 보컬 상태만 유지**.
- Q: 앵콜 효과2 "퍼포먼스 유지시간 +21초"는 버프인가 instant인가?
  A: **instant**. `named_buff_duration_extend`로 파싱. buff_end_t에 직접 더하는 방식이므로 누적/갱신 구분 없음.
