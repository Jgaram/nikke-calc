# SG 재장전 동작 시나리오

> 캐릭터별 시나리오가 아니라 SG 무기군 전체에 적용되는 재장전 메커니즘 시나리오.
> 60fps 인게임 영상 검증 (2026-08-23).

## 동작 규칙

- 탄을 비운 자동 사격은 마지막 발 0.2초 뒤 재장전을 시작한다 (`reload_start_delay`).
- 재장전 완료 0.2초 뒤부터 사격할 수 있다 (`post_reload_delay`). 이 값은 원래 발사 간격에
  가산하지 않고, 두 시각 중 늦은 쪽을 쓴다.
- 클립식 전체 재장전의 중간 클립에는 `post_reload_delay`를 붙이지 않는다.
- 미리 엄폐해 시작한 재장전에는 `reload_start_delay`를 붙이지 않는다.

```text
다음 발 = max(마지막 발 + 1 / fire_rate,
              마지막 발 + 0.2 + reload_time + 0.2)
```

## 영상 검증

탄창 숫자가 장전 결과로 바뀐 첫 프레임부터 첫 발로 1 감소한 첫 프레임까지 측정했다.

| 캐릭터 | 방식 | 대표 구간 | 결과 |
|---|---|---|---|
| 드레이크 | 클립식, 전체 | 11.967→12.167 / 23.567→23.767 | 0.200s |
| 드레이크 | 클립식, 원클립 | 반복 4회 | 모두 12프레임 |
| 소다 : 트윙클링 바니 | 클립식, 원클립 | 8.867→9.067 / 20.000→20.200 | 0.200s |
| 페퍼 | 클립식, 원클립 | 9.583→9.783 / 12.633→12.833 | 0.200s |
| 누아르 | 클립식, 전체·원클립 | 5.333→5.533 / 26.350→26.550 | 0.200s |
| 레오나 | 비클립식, 전체 | 15.483→15.683 / 22.650→22.850 | 0.200s |
| 나가 | 비클립식, 전체 | 11.783→11.983 | 0.200s |
| 도로시 : 세렌디피티 | 비클립식, 전체 | 11.200→11.400 | 0.200s |

나가는 마지막 발 10.083초→장전 결과 11.783초로, 재장전 시간 1.5초보다 0.2초 길었다.
따라서 자동 탄 소진의 장전 시작 지연도 0.2초로 둔다.

아니스 : 스파클링 서머는 풀버스트 중 1발 탄창·사실상 즉시 재장전 상태에서
17.433→18.100→18.767초로 반복됐다. 각 40프레임(0.667초)이므로 재장전 전후 0.2초는
SG의 기본 발사 간격 안에서 겹친다. 촬영 조건은 스킬 10/10/10이다.

센티 RL은 비교 표본으로만 촬영했다. 차지 시간이 첫 발 구간에 함께 들어가므로 SG 값을
RL이나 다른 무기군에 일반화하지 않는다.
