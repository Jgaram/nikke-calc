# 마르차나 : 마린 스터디 동작 시나리오

> 모드: 보강 (parsed_skills 반영)

## 기본 정보
- 버스트 단계: B3
- 본인 쿨다운: 40s (펭군 스파이럴)
- 무기 유형: AR (60발, 재장전 1.0s, 계수 13.65%, 코어 200%)
- 속성 코드: 철갑 (→ 전격에 우월)
- 작성 사이클 수: 2 (본인 버스트 사이클 + 미사용 사이클)

## 핵심 전제 (설계 의도)
킷 전체가 **전격 코드 적** 전제 (Q1 확정):
- 철갑 → 전격 우월 → factor⑦(우월 코드) 활성. `element_bonus_pct` 버프(펭군 긴급 출동 2 / 펭군 스파이럴)가 factor⑦에 가산.
- 버스트의 `고위험 대상: def_pct▼`는 **전격 적**에만 부여. 이머전시 휘슬 block C(bonus_damage)는 `target_state:고위험 대상` 조건.

→ 검증 sim은 반드시 **`enemy={"code":"전격"}`**. 기본 적 `code=None`이면 factor⑦·고위험 계열이 꺼져 저평가.

## 검증 스쿼드
- **주 스쿼드 (미란다 조합, 유저 지정)**: `["미란다", "리틀 머메이드", "크라운", "마르차나 : 마린 스터디", "test_B3"]`
  - 적 설정: **`enemy={"code": "전격"}`** (필수)
  - 리틀 머메이드는 버쿨감 공급용(미란다 단독 B1이면 사이클이 미란다 쿨 20s에 묶임 → 리틀 머메이드 추가로 표준 12.53s 복원). **미란다는 반드시 마르차나보다 앞 순서**(full_burst_start 버프→대미지 순서 보장).
  - 버스트 체인: B1(미란다/리틀 머메이드) → B2 크라운 → B3(마르차나/test_B3). 40s 쿨이라 마르차나는 **~2사이클(≈25s)에 1회** 버스트, 나머지는 test_B3가 B3 채움.
  - 목적: **미란다의 full_burst_start·burst_cast 버프가 마르차나에게 적용된 상태에서 마르차나의 full_burst_start `경계 대상 지정` 대미지가 계산되는지** (같은 타이밍 버프→대미지 순서).
  - 전제: 마르차나가 미란다 제외 최고 공격력 아군이어야 `크리티컬! 4`(crit_rate, `allies_top_atk_excl:1`)·`파워 업!`(atk_pct, `allies_top_atk_excl:2`)를 수령. (실측: 8회 경계 대상 지정 전부 미란다 4버프 활성 확인됨)
- **참고 대조 (엄밀 네거티브)**: `enemy={"code": "수냉"}` — 철갑이 우월 아님(factor⑦ off) + 고위험 대상 `target_code:전격` 불일치로 block C off. **`code=None`은 target_code가 wildcard 통과라 고위험/block C가 안 꺼지므로 쓰지 않는다.**

## 스킬 간 상호작용

- **미란다 full_burst_start 버프 → 마르차나 full_burst_start bonus_damage** (유저 지정 핵심 검증)
  - 경로: 미란다 크리티컬!(crit_dmg, all_allies) / 크리티컬! 4(crit_rate, allies_top_atk_excl:1) → 마르차나 factor③ → 경계 대상 지정(bonus_damage) 계산에 반영
  - 시점: **동일 프레임(full_burst_start)**. 미란다 버프 등록이 마르차나 bonus_damage 계산보다 먼저여야 함. 스쿼드 순서상 미란다(index0)가 마르차나(index2)보다 먼저 notify → 정상 기대. **impl에서 반드시 확인** (Phase B #5).
  - 위험: 만약 캐릭터별로 (버프+대미지)를 순차 처리하고 버프 제공자가 뒤 순서면 대미지가 버프를 놓침. 미란다 조합으로 이 순서 보장 검증.
- **미란다 burst_cast atk_pct(파워 업!) → 마르차나 최종공격력 → 경계 대상 지정 스케일**
  - 경로: 파워 업!(atk_pct, allies_top_atk_excl:2) → 마르차나 ② → bonus_damage(최종공격력 비례) 증폭
  - 시점: burst_cast(진입 전)라 full_burst_start 시 이미 활성. 마르차나가 최고딜러(excl 미란다)일 때만 수령.
- **버스트(펭군 스파이럴) 고위험 부여 → 이머전시 휘슬 block C 게이팅**
  - 경로: 고위험 대상(def_pct, 전격적, 20s) → 이머전시 휘슬(target_state:고위험 대상, 20발마다 bonus_damage)
  - 위험: 비전격 적/버스트 전 구간 완전 무발동.
- **우월 코드 공격 대미지 누적 → factor⑦**
  - 경로: 펭군 긴급 출동 2(패시브 +12.06%, 지속) + 펭군 스파이럴(버스트 +30.97%, 10s) → factor⑦ element_bonus (전격 적일 때만 켜짐).
- **휘슬 스택 → 본인 공격력 상시**
  - battle_start 5중첩 → 5초마다 +1 → 9 유지. 소비(랩쳐≥6)는 보스전 없음.

## 유저 확인 사항 (확정)
- Q1: 타깃 **전격 코드 고정**. 비전격은 네거티브 확인용.
- Q2: 단일 보스 = 랩쳐 1기 → `enemy_count_below:N` 항상 참, `enemy_count_above:N` 항상 거짓(펭군 긴급 AoE 무발동), "랩쳐 등장"=battle_start 1회, "사망" 무발동. (GAMEPLAY §트리거 발동 의미 승격됨)
- Q3: 휘슬 = battle_start 5중첩, 캡 9, 5초마다 +1. `max_stack:9` + `buff_stack_add`로 표현.
- Q4: 경계 대상 지정 = 본인 버스트 사이클 full_burst_start 1회, 대상=보스. block B(사망 재지정) 스킵. 경계 효과2(적 공격력▼)는 참고 유지.
- Q5: block C 히트카운트 = 본인 일반공격만(`hit_count:N` 기존 동작). 코어히트 포함, 버스트/스킬 딜 제외. (GAMEPLAY 승격됨)
