## 스킬 간 상호작용

- **피튜니아 3 → 아이리스 2 (핵심 루프)**
  - 경로: `burst_enter:2` → `hp_only_caster_based_pct` +15.01(2s) → 인접 아군 hp_pct 100 → 약 86.9 →
    2초 뒤 만료로 최대치 원복 → **100% 재도달** → `event:adjacent_hp_max` → `armor_break_dmg_pct` 30.97 (10s)
  - 시점: B2 진입 +2.0s (또는 회복으로 더 일찍)
  - `max_hp_only_pct`·`hp_only_caster_based_pct`의 활성/만료 후 `sync_hp`에서 hp_pct 100%
    재도달 전이를 감지해 notify한다.
- **피튜니아 3 → 아이리스 → 아이리스 3**
  - 같은 86.9% 하락이 `event:adjacent_hp_below:90`도 만족 → 보호막 → `event:shield_applied` → atk 45.12
  - 보호막 적용 대상 중 플로라가 포함되므로 플로라 자신의 `event:shield_applied`가 발동한다.
  - 현재 아군 피격 모델이 없어 보호막은 10초 지속시간 동안 소모되지 않는다.
- **시크릿 가든(회복) ↔ 피튜니아 3 (동일 timing 실행 순서)** — *구현 후 실측으로 해소*
  - `burst_enter:2`와 `burst_cast`가 사실상 같은 프레임. 회복이 최대치 증가분을 즉시 메우면
    아이리스 2가 2초 앞당겨 발동한다
  - **실측(2026-08-02, 표준 스쿼드)**: 회복량(시전자 최대체력 10.45%)이 최대치 증가분(15.01%)보다 작아
    hp_pct가 86.95 → 96%까지만 오른다. **플로라 단독으로는 만피 복귀가 불가능**하고 항상
    피튜니아 3 만료(+2.0s) 경로로 발동한다
  - **단, 스쿼드에 추가 힐러가 있으면 2초 안에 만피가 채워져 앞당겨질 수 있다** (미검증 — 필요 시 힐러 포함 스쿼드로 확인)
  - 어느 쪽이든 아이리스 2의 발동 **시점만** 바뀌고 발동 여부는 바뀌지 않는다
- **아이리스 2 ↔ 시크릿 가든 2 중첩**
  - 둘 다 `armor_break_dmg_pct`, 서로 다른 name → **동시 활성 시 합산**(30.97 + 42.39). 갱신 아님

## 유저 확인 사항

- **Q1. 아이리스 발동 가능성** (아군 피해 모델 없음)
  - **A: 피해 모델은 없지만 「최대 체력만 증가」 개념은 있다. 피튜니아 3(2초)로 hp_pct가 100% 아래로
    내려가고, 2초 후 만료되면(또는 그 사이 힐로) 다시 100%에 도달한다 → 아이리스 2는 매 사이클 정상 발동.**
    보호막(아이리스·아이리스 3)은 보호막 적용 상태와 적용 이벤트까지 구현한다.
- **Q2. `[N 중첩]` 표기**
  - **A: 일반 표기법으로 "최대 N중첩"을 뜻한다. 1중첩에서 시작해 누적.** → `max_stack: 5`
- **Q3. 「일반 공격 100회 공격 시」**
  - **A: 일반적인 문법 — 100회마다 반복 발동.** → `hit_count:100`, 지속은 `-1`(영구)
- **Q4. 애장품 포함 여부**
  - **A: 계산기는 애장품 3단계만 다룬다.** 애장품 3단계 템플릿이 정본, 단계 태그 필드 없음
    (`PARSING.md` 파싱 범위 노트에 일반 규칙으로 승격)
- **Q5. 「자신의 양 옆 아군」**
  - **A: 기존 `allies_adjacent:N`으로 해결** (신규 구현 불필요). 「자신과 양 옆 아군 2기」 = `allies_adjacent:2`
