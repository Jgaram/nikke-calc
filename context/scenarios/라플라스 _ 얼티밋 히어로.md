## 스킬 간 상호작용

- **`일렉트릭 파워 풀 풀 차지 2`의 값은 `오버 에너지 단계 1~4` 누적에 비례해 커진다** *(핵심 순환 강화)*
  - `max_hp_only_pct` 누적 → `effective_max_hp` → `atk_from_hp_pct` = `effective_max_hp × 4.05%` → `atk_flat`
  - 실측 누적값 **0 → 2.0 → 5.0 → 12.0 → 22.5** (하위 중복 적용 정상)

- **`예열`(스택) → 모드 진입 게이팅** — 같은 프레임에 최대치 판정 → 모드 진입 → `예열` 해제.
  `… 4`(`remove_named_buff`)가 먼저 실행되면 뒤 항목의 condition이 깨져 모드가 영원히 안 열린다.

- **모드(weapon_change) → `오버 에너지` 게이팅** — `self_state:일렉트릭 파워 풀 풀 차지`.
  실측: 충전 시점이 **전부 모드 구간 안**(위반 0건).

- **모드 → `… 3`(관통)** — `passive` + `self_state`(runtime 재판정)라 모드 구간과 **0프레임 오차로 일치**.
  `duration_bullets`로 세면 부여 트리거 `full_charge_hit`가 bullet-bound라 그 1발이 즉시 차감되어 **항상 1발 일찍 죽는다**.

- **모드 종료 → `… 5`(`ammo_charge_pct −100`) → 재장전 → 루프 재시작**
  - SMG 모드에는 `full_charge_hit`가 없어 모드 중 `예열`이 재축적되지 않는다 → 모드 안에서 모드 재발동 없음
  - **타임라인은 장탄 원복을 끝낸 뒤에 `end_weapon_change()`를 부른다.** 순서가 뒤집히면 원복이 `−100`을 덮어써 재장전이 사라진다

- **`오버 에너지 단계` → `회생전력활용무장 : 묠니르 3` 스케일링**
  - `scaling:stack_count` → **단계 수만큼 히트**. 실측 히트수 **1 / 2 / 3 / 4 / 4 / 4 / 4** (첫 버스트는 단계 0이라 미발동)

- **최대 장탄 수 버프 → 모드 지속 → 전 계통** — `max_ammo_buff_applies`가 켜져 있어 장탄 버프가
  최대 장탄과 `duration_bullets`(= "모든 탄환 발사 시") 양쪽에 반영된다. 실측 120발 → 168발.

## 유저 확인 사항

- **Q1. 무기 변경의 실제 사격 방식** → **A: SMG, 초당 20발.**
  - `(사용 무기 변경 시 최대 장탄 수 효과 갱신)` = **변경 무기의 최대 장탄이 최대 장탄 수 버프의 영향을 받는다**. 신데렐라 : 크리스탈 웨이브와 이 캐릭터만 보유.
  - 무기 변경 상태에서 **탄환 충전 효과는 받지 않는다** (일반 규칙 → GAMEPLAY 승격).
  - **무기 변경 상태에서 재장전을 하지 않는다**(스킬 미기재). 모든 탄환 발사 = 모드 종료라 계산 무관.
- **Q2. `weapon_delays.json` 예외** → **A: `post_fire_delay: 0`.** (등록 완료)
- **Q3. 예열 5중첩 → 무기 변경 시점** → **A: 즉시.** 5중첩째 차지 속도는 쓰이지 않는다.
- **Q4. `atk_from_hp_pct` 재평가 시점** → **A: 실시간 재계산.**
- **Q5. `일반 공격 12회` 카운트 기준** → **A: 모드 밖 공격도 포함**해 누적. 효과만 `self_state`로 게이팅.
- **Q6. 단계 상한 / `하위 효과 중복 적용`** → **A: 합산 맞음**(4단계 = +22.5%). 4단계 이후 100% 재도달해도 추가 효과 없음 → `gauge_max: 4`.
- **Q7. `탄환 100% 제거` 대상** → **A: 맞음** — 기본 무기 탄창을 0으로 만들어 강제 재장전.
- **Q8. `관통 특화`** → **A: 딜에 영향 있음** (`pierce_enabled` → `is_pierce_damage`).
- **Q9. `조준선에 가장 가까운 적 1기`** → **A: 단일 보스 = 보스 확정** (`enemies_nearest:1`).
- **Q10. `적 전체에게`** → **A: 각 적에게 온전히** (`damage` + `all_enemies`).
