# 일레그 : 붐 앤 쇼크 동작 시나리오

> 모드: 즉석 (bug-fix 시 빙의 메카닉 한정 작성)

## 기본 정보
- 버스트 단계: B3
- 무기 유형: MG (max_ammo 300, reload 2.5s)
- 속성: 수냉
- 메카닉 핵심: **빙의** 마커가 6초 주기로 무작위 적 1기에 부여 → 활성 상태에서 아군 누적 100발 소비 시 유령 게이지 +1, 빙의 해제. 게이지 13 cap + 빙의 활성 시 S2 데미지 동시 발동.

## 검증 스쿼드

- 운용: 일레그는 사이클 1~13 미발동, 14번째 풀버스트에서 본인 B3 사용
