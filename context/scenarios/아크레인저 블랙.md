## 스킬 간 상호작용

- **`변신`(#8) 생명주기가 코레더 DoT(#3)를 통째로 좌우**
  - 경로: 배터리 100 → #8 활성 → `event:변신` → #3 등록. 배터리 0 → #13이 #8을 `remove_named_buff` → `event:state_end:변신` → #4가 #3 제거.
  - 위험: 런타임 조건 불충족은 버프를 `_active`에서 **제거하지 않는다** — 값만 빠지고 상태는 남는다. 그래서 #8은 런타임 조건을 갖지 않고 #13이 명시 제거한다.

- **배터리는 게이지이자 지속시간 타이머**
  - 배터리 N% → 변신 잔여 0.2N초. 별도 duration 없음. 활성화는 `gauge_eq:100` **래치**, 해제는 #13의 명시 `remove_named_buff`.
  - **영구 버프에 런타임 조건을 붙이면 안 되는 이유**: `_active`에 남은 채 조건이 다시 참이 되면 트리거 없이 재점화된다 → 파츠 파괴 1회(배터리 50%)만으로 변신이 켜졌다. 실제로 이 함정을 밟고 고쳤다.
  - cap 100 공통(Q2) → 변신 중 잔여 50% 초과에서 #6(+50)을 쓰면 초과분이 버려진다. **변신 직후 버스트 재사용은 손해**.

- **동일 timing(`burst_cast`) 내 실행 순서 — 배열 순서가 곧 결과**
  - `#6 → #7 → #8 → #9 → #10 → #11 → #12`, 그리고 #13은 **배열 맨 끝**. 하나라도 뒤집히면:
    - #8이 #7보다 앞 → 배터리 100 미달로 변신 안 걸림
    - #8이 #10보다 뒤 → `gauge_eq:100`이 깨져 변신 안 걸림
    - #6이 #8보다 뒤 → 긴급 변신 직후 `self_state:변신`이 참이 되어 +50이 잘못 실행 → 변신 20초
  - #12가 #11보다 뒤지만 DoT 첫 틱이 +1초라 **모든 틱에 적용**된다(GAMEPLAY §효과 실행 순서 승격 항목).

- **`dot_dmg_pct` 3종의 중첩 창**: #12(버스트 10s) + #5(풀버스트 10s) + #2(30타 5s) = 최대 272.93%.
  버스트 직후 ~5초가 피크. #2는 30타마다 재부여되며 유한 지속이라 사격이 끊기면 빠진다.

## 유저 확인 사항

- **Q1. 파츠 파괴 배터리 충전을 어떻게 다룰까?**
  **A: (a)와 (c) 둘 다 테스트 가능하게 구현.** 기본은 무발동(a), 파괴 주기를 지정하면 그 주기로 `event:part_destroy` 발생(c).
  → `/char-impl`에서 config 스위치 신설 + `context/sim.py`·UI 노출 필요.

- **Q2. 배터리 cap이 버스트 충전에도 적용되나?**
  **A: 동일한 게이지이므로 동일한 cap 100%.** → #6/#7에도 `gauge_max: 100` 재선언(파츠 파괴 OFF에서는 #1이 실행되지 않아 cap 미등록이 되기 때문).

- **Q3. 비변신 버스트의 실효 배터리 = 50%(변신 10초)?** **A: 맞음.** #7 → #8 → #10 순서로 재현.

- **Q4. 변신 재진입 시 코레더 DoT 재등록?**
  **A: 재등록 확정** (유저 확인 + 실측). `event:변신` 트리거이므로 변신할 때마다 다시 깔리고, 이전 장판은 `event:state_end:변신` → #4가 이미 제거한 상태다.
  실측(표준 스쿼드 60초): 변신 3회 → #3 등록 3회 / #4 해제 2회(3회차는 종료 시점까지 유지 중), 변신 구간 밖 틱 **0회**.

- **Q5. "변신 상태 적용 중 적 등장 시"는 무발동?** **A: 맞음.** #3의 `event:enemy_spawn` 경로는 t=0 1회뿐이고 그때는 비변신 → 영구 무발동. 네거티브 항목.

- **Q6. 일반 공격 30회 카운트가 변신 여부와 무관하게 누적?** (미답 — 현 해석 유지) #2에 condition 없음. 일반 규칙(카운터는 condition과 무관하게 진행)대로 상시 누적.

- **Q7. DoT 첫 틱 시점?** **A: 등록 +`tick_interval`(1초 뒤).** `_dot_timers[id(eff)] = (caster, t + tick_interval, expires)`. 미하라 : 본딩 체인·디젤 : 윈터 스위츠·브래디·레이븐과 동일. → **GAMEPLAY.md §효과 실행 순서에 일반 규칙으로 승격 완료.**

- **Q8. 변형 2(풍압 AR 아군 포함) 스쿼드를 추가할까?** (미답)
