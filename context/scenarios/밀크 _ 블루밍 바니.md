## 컨트롤 모델 (이 캐릭터의 핵심)

밀크는 **컨트롤이 곧 스킬 가동**이다. 컨트롤이 없으면 항목 2~7·9가 통째로 죽고
버스트 주기 분배딜(10번)만 남는다.

### 판정 산술

```
차지 시작 → +1.0s 풀차지 도달 → +0.5s 유지 → charge_hold:0.5 판정 (1회)
                                              └ 이 순간 면역이면 부끄러움 없음
```

- **판정은 풀차지 +0.5초 그 순간 1회뿐이다.** 계속 들고 있어도 재판정하지 않는다
  → 버스트 중에 홀드를 시작하면, **버스트가 끝난 뒤에도 부끄러움이 걸리지 않는다**(유저 확인).
- 반대로 **버스트 종료 1.3초 전에 차지를 시작**하면 판정 시각은 종료 +0.2초라
  면역이 이미 풀려 **부끄러움이 발동한다**. 차지 시작 시점이 1.5초 창을 어디에 놓느냐의 문제다.

### 실전 조작 (유저 서술)

| 구간 | 조작 | 이유 |
|---|---|---|
| 평시(비버스트) | **톡톡이** | 논차지 연사로 발수를 벌고, 그 사이 부끄러움 재장전이 끼기도 한다 |
| 풀버스트 중 | 톡톡이 + **가끔 풀차지 1발** | `관통 특화`(6초)를 켜 두어야 `pierce_dmg_pct`가 실린다. 6초 안에 최소 1발 |
| 버스트 종료 직전 | **종료 1.3초 전부터 차지** | 판정이 면역 해제 직후에 떨어져 부끄러움 발동 |
| 비버스트 / 타 B3 버스트 사이클 | 아무 때나 차지해 부끄러움 발동 | 면역이 없으므로 판정이 그냥 통과 |

**부끄러움을 켜는 대가**: 그 풀차지 샷은 **취소**되고(발사 없음), 탄창 전소 + 3.0초 재장전.
얻는 것은 `atk_pct` +118.7%(40초) + `pierce_dmg_pct` +64.7%(부끄러움 유지되는 한 영구).

### 계산기 표현 (구현 완료)

| 필요한 것 | 구현 |
|---|---|
| `charge_hold:N` 트리거 발동 | `CharState._notify_charge_hold()` — `_charge_full_t`로 유지 시간 측정, **차지당 1회** 판정 |
| 버스트 종료 직후에 판정 떨어뜨리기 | 홀드 정책 **`charge_hold_after_fb`** — `판정 = 풀버스트 종료 + lead`, 차지 시작을 역산. 의도한 차지가 시작될 때만 홀드를 건다 |
| 톡톡이 중 `관통 특화` 유지 | **`tap_fire.full_charge_interval`** — N초마다 한 발을 풀차지로. 밀크는 6초 버프라 **5.5** |

```bash
python -m context.sim "리틀 머메이드,크라운,밀크 : 블루밍 바니,test_B3" --seed 42 \
  --tap "밀크 : 블루밍 바니:4.0:0.03:5.5" \
  --hold-ctrl "밀크 : 블루밍 바니:charge_hold_after_fb:0.1"
```

**남은 한계**: 풀차지 시점이 **고정 간격**이다. 유저 실전 패턴("본인 버스트 6초 남았을 때 /
부끄러움 종료 직후 풀차지 → 4초 톡톡이 → 다시 풀차지")처럼 사이클 이벤트에 시점을 붙이는
표현은 아직 없다 (`CONTROL.md §미구현·보류`).

## 스킬 간 상호작용

- **1번 `pierce_enabled` → 9·12번 `pierce_dmg_pct`**
  - 경로: `pierce_enabled`가 켜져야 일반 공격 hit이 `is_pierce_damage`로 판정되고
    (`timeline.py:501,625`) 그때만 `pierce_dmg_pct`가 ②에 가산된다 (`damage.py:201`).
  - 위험: **톡톡이(논차지)는 1번을 갱신하지 않는다.** 풀버스트 6초를 넘기기 전에 풀차지 1발을
    섞지 않으면 관통 버프 182.3%(9+12)가 통째로 죽는다. 유저가 "한 번씩 풀차지샷"이라고 한 이유.
  - 부끄러움 발동 프레임의 샷은 취소되므로 그 발로는 1번이 갱신되지 않는다. 이어지는
    3.0초 재장전 동안 6초 타이머가 계속 흐른다 — 재장전 후 첫 발까지 끊길 수 있다.

- **7번 마커 → 9번 `pierce_dmg_pct` (런타임 재평가)**
  - `self_state:`는 `_RUNTIME_COND_PREFIXES`라 마커가 사라지는 프레임에 9번도 즉시 0이 된다.
    14번(마커 제거)이 곧 9번 해제다.

- **11번 면역 → 2~7번 차단, 14·15번 → 기존 상태 해제**
  - 차단은 condition(`not_self_state:구경났냐 짜식들아!!`), 해제는 `remove_named_buff` 2개.
    `debuff_immune:[name]` 코드 경로는 harmful 버프만 걸러서 neutral 마커를 막지 못한다.
  - 결과: 버스트 진입 순간 밀크는 **+118.7%/+64.7%를 잃고 +220%/+117.64%를 얻는다**(교체).

- **7번 영구 마커 → 2~6번 재발동 봉쇄**
  - `not_self_state:부끄러움`이라 마커가 살아 있는 한 다시 걸 수 없다. ATK(40초)만 먼저
    만료되는 구간이 생긴다. **버스트로 마커를 지우는 것이 유일한 리셋**이다.

- **3·4·5번의 배열 순서**
  - `reload_time_fixed`(4)가 `force_reload`(5)보다 **앞**이어야 그 재장전이 3.0초가 된다.
    `_start_reload`가 진입 시점에 `_fixed_reload_time()`을 읽기 때문.

## 유저 확인 사항

- Q1: `부끄러움` 지속 시간 → **영구.** 버스트 `부끄러움 면역`으로만 사라진다.
- Q2: 부끄러움 발동 시 풀차지 샷 → **취소된다.** 그 발로 `관통 특화`도 부여되지 않는다.
- Q3: 실전 운용 → 아래 Q9로 확장 확정.
- Q4: `atk_pct` 40초 → **갱신된다.** 실전에선 버스트로 지워진 뒤 다시 켜는 운용.
- Q5: 면역 → **기존 부끄러움을 해제한다.**
- Q6: 버스트 10초 주기 분배딜 → **5회.** 마지막 틱이 버스트 종료 순간에 들어간다.
- Q7: `재장전 속도 50% 감소 상태로 고정` → **3.0초**(기본 2.0 + 1.0), 다른 재장전 버프 무시.
- Q8: `[재장전 1회 적용]` → **그 1회만.** 다음 재장전부터 평시 속도.
- Q9: 컨트롤 상세 →
  - `charge_hold:0.5` **판정은 풀차지 +0.5초 1회뿐**. 버스트 중에 홀드를 시작하면 계속 들고
    있어도 부끄러움이 걸리지 않는다.
  - **버스트 종료 1.3초 전 차지 시작** → 판정 시각(1.5초 후)에 면역이 풀려 발동.
  - 평시는 **톡톡이**, 풀버스트 중에는 `관통 특화` 유지용 **풀차지 1발**을 섞는다.
  - 비버스트 구간은 오토 사격 또는 부끄러움 재장전 대기.
- Q10: 주기 공격(틱)의 첫 발동 시점 → **캐릭터마다 두 유형**이 있다.
  - **type 1 — 발동과 동시에 첫 틱**: 미하라 : 본딩 체인 · 에이다 · 아크레인저 블랙
  - **type 2 — 발동 후 interval부터**: 디젤 : 윈터 스위츠 · **밀크 : 블루밍 바니**
  - 회수는 양쪽 같다 (2초/10초 = 5회, 1초/10초 = 10회). 다른 것은 **위상**이다 —
    type 1은 첫 틱이 풀버스트 시작 전에 들어갈 수 있고, type 2는 첫 틱부터 풀버스트 안이다.
  - **계산기 수정 필요** (아래 §미해결).

## 주기 틱 두 유형 (해결 — 별건으로 처리 완료)

`tick_start` 필드로 두 유형을 구분하고 만료 프레임 틱을 살렸다. 밀크의 `성질 내기 2`는
`every:2s`(전역 격자)에서 **`burst_cast` + `tick_interval: 2.0` + `duration: 10.0`**(type 2)으로
옮겨 발동 기준 위상으로 맞췄다 — 버스트 +2·4·6·8·10초에 **5회**, 마지막 틱도 버스트 버프를
받는다(4.13M, 고치기 전 1.47M). 상세·영향 범위는 `GAMEPLAY.md §효과 실행 순서`와
`HARNESS.md §이력 2026-08-07`.

**에이다 `섬광 수류탄 투척`은 이 수정에 포함되지 않았다** — `every:2s` 경로라 위상이 여전히
전투 시작 기준 전역 격자다. 게다가 발동 간격을 2초 → 1초로 줄이는 `effect_interval`이
**미구현**이라(코드에 핸들러 없음) 인게임 10회 대신 5회만 나간다. 별도 과제다.
