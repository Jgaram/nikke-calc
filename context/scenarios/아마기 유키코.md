## 스킬 간 상호작용

- **`1more` → `페르소나 : 코노하나사쿠야 2` / `추격`**
  - 경로: `1more` 활성 → `event:1more` → 두 효과 트리거
  - 위험: `event:{name}`이 **스쿼드 전체 브로드캐스트**([buff_manager.py:1880-1882](../../calculator/buff_manager.py#L1880-L1882)).
    변형 1에서 마코토가 `1more`을 얻을 때도 유키코의 `event:1more`가 발동해 400.31 분배와 `추격` 부여가
    한 사이클에 2번 일어난다. 단계 4에서 **`1more`은 본인 한정, `추격`은 수령자 기준**으로 스코프를 나눠야 한다
- **`추격` → 마코토 `페르소나 : 요한나 3`**
  - 경로: `추격`(`atk_caster_based_pct` 80.25, 25s)이 마코토에게 부여 → 수령 순간 `event:추격` → 548.99 분배
  - 시점: 25초 지속이라 마코토가 버스트를 쓰지 않는 사이클까지 걸친다
- **마코토 `배턴 터치` → 유키코**: 마코토 `1more`마다 `atk_caster_based_pct` 35.2 1스택(최대 3).
  유키코의 일반 공격·분배 대미지 전부를 스케일링한다
- **`화염 부스터`(`split_dmg_pct` 90.01) → `마하라기다인` + `페르소나 : 코노하나사쿠야 2`**: 둘 다 factor⑥에서 이 배수를 탄다
- **`메디아` ↔ `메디아라마`**: 별개 instant 2건. `화염 부스터` 유지 중에는 3초마다 두 번 회복

- Q1. `1more` 획득 경로가 자기 버스트의 "풍압 코드 적이 있다면" 뿐인가?

- Q2. "1more 적용 시" 트리거는 `[1more]`이 붙는 순간 1회인가?
  A. **붙는 순간 1회.**
- Q3. `[추격]`은 유키코가 부여하는 버프이고, 마코토의 "추격 적용 시"가 그 수령 순간인가?
  A. **맞다.**
- Q4. **페르소나 상태** = 스킬1 `[페르소나 – X]` 보유 상태인가?
  A. **맞다.** → `persona_state` 마커 stat으로 구현.
- Q5. `[메디아]`와 `[메디아라마]`가 동시에 도는가, 대체인가?
  A. **각각 동시에 돈다** (별개 회복원).
- Q6. 스킬2 효과3 `수냉 코드 적으로부터 받는 대미지 17.95%▼` — 적 코드를 풍압으로 두면 항상 무효인데 그대로 두나?
  A. (미답 — 텍스트대로 `received_dmg_pct` + `target_code:수냉`으로 등록. 검증 스쿼드에서는 자연히 미발동)
- Q7. "분배 대미지 90.01%▲"가 버스트 1258.79%와 스킬1 400.31% 양쪽에 다 걸리나?
  A. **맞다.**
- Q8. `[추격: 시전자 기준 공격력 80.25%▲]`가 캐스터 기준 버프인가?

- Q9. MG 연사속도(초기·최대·예열 발수)
