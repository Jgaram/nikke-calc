## 스킬 간 상호작용

- **`럭키챰` → 아군 전원의 `atk_flat`**
  - 경로: `state["base_stats"]["누아르"]["atk"] × 14.08%`가 각 아군의 `atk_flat`에 가산
    ([buff_manager.py:2267](calculator/buff_manager.py#L2267)).
  - 시점 쟁점 없음 — **버프 제외 기본 공격력** 기준이라 부여 시점/재평가 구분이 결과를 바꾸지 않는다(Q2).
  - 단 `self_hp_above:70`은 `_RUNTIME_COND_PREFIXES`에 있어 **매 조회 시 재평가**된다.
    `max_hp_only_pct` 계열이 걸려 `hp_pct`가 70 밑으로 내려가면 **아군 전체 공격력 버프가 통째로 꺼진다**(Q1).
  - 위험: `atk_pct`로 오파싱하면 아군 각자의 공격력에 14.08%가 곱해져 딜이 크게 과대해진다.
- **`래빗 트윈즈 B`(장탄 +5) → `래빗 트윈즈 B 2`(충전 39.88%) 실행 순서**
  - 배열이 B → B 2 순서이고, 충전은 **증가된 최대치 기준**이어야 한다(Q4).
  - **구현 결함 1**: `_effective_max_ammo()`가 `max_ammo_pct`만 읽고 `max_ammo_flat`을 더하지 않는다
    ([timeline.py:1771-1773](calculator/timeline.py#L1771-L1773)). 재장전 경로의 `CharState._full_ammo()`는
    더한다([timeline.py:1239-1242](calculator/timeline.py#L1239-L1242)) — 두 경로가 어긋나 있다.
    실측에서 t=15.783 충전이 8발(=20×39.88%)이었다. 수정 후 기대치는 10발(=25×39.88%)이고 상한도 25다.
  - **구현 결함 2**: `래빗 트윈즈 B` 만료 시 초과 잔탄 캡이 없다(Q5). 잔탄은 발사로만 줄고 만료 재평가 경로가
    아예 없어, 최대치가 25 → 20으로 돌아와도 21~25발을 그대로 쏜다 → 사격 횟수 과대.
  - 두 결함은 **반대 방향**이다(1은 과소, 2는 과대). 한쪽만 고치면 총딜이 한 방향으로 치우치므로 함께 고친다.
- **`피날레 2·3`(SG 10s)와 `피날레 4·5`(전체 30s)의 stat 중복**
  - 양쪽에 걸리는 아군(=SG를 든 777 동료)은 값을 **합산**받는다(Q6): 명중률 25.54 / 저지 부위 42.59.
  - 지속이 10s·30s로 달라 **별개 항목으로 유지**해야 한다. 합치면 만료 시각이 틀어진다.
- **`피날레`(AoE 버스트 딜)와 뒤따르는 버프들의 순서**
  - 원문 블록 순서가 딜 → 버프이고 뒤 블록이 전부 아군 버프라 딜에 영향이 없다 — 순서 쟁점 없음.
  - `all_enemies` + `burst_damage` 조합이므로 `burst_dmg_aoe_pct` 증폭 대상(`is_aoe_burst`)이 된다.

## 유저 확인 사항

- Q1. **`자신의 체력이 70% 이상이라면`** — 보스 sim은 아군 피격 모델이 없어 항상 100%이므로
  이 조건은 사실상 **항상 참**으로 봐도 되는가?
  **A: 아니다. 상수화하지 말고 조건으로 구현해야 한다** — `최대 체력만 증가`(`max_hp_only_pct`,
  현재 체력 유지) 효과가 걸리면 `hp_pct`가 70% 밑으로 내려가 **발동이 꺼질 수 있다.**
  → `self_hp_above:70`. 이미 `_RUNTIME_COND_PREFIXES`에 있어 런타임 재평가되므로 추가 구현은 불필요.
  **일반 규칙 → `GAMEPLAY.md §condition` 승격 완료.**
- Q2. **`시전자 기준 공격력 ▲`의 캐스터 값 산정 시점**
  **A: 시전자 기준 공격력은 버프를 제외한 기본 공격력 기준이므로 시점 문제가 없다.**
  구현도 `state["base_stats"][시전자]["atk"]`를 읽어 일치한다.
  **일반 규칙 → `GAMEPLAY.md §값 산정` 승격 완료.**
- Q3. **`피날레 4·5` 30초 지속 vs 쿨 40초**
  **A: 실전에서는 보통 버스트 쿨타임 감소 니케를 함께 편성하므로 잘 끊기지 않는다.**
  → 예비 실측에서 재사용 간격 25.07s(표준)·26.0s(변형 2)로 실제로 끊기지 않음을 확인.
- Q4. **스킬2 실행 순서**
  **A: 최대 장탄 증가 반영 후 충전된다.** → 충전량·상한 모두 증가된 최대치 기준.
  **일반 규칙 → `GAMEPLAY.md §효과 실행 순서` 승격 완료.**
- Q5. **`최대 장탄 수 5발 ▲` 만료 시점**
  **A: 만료되면 초과 잔탄은 잘린다.** 현재 계산기는 만료 시 잔탄 재평가가 없어 미구현
  → 단계 4 신규 구현. **일반 규칙 → `GAMEPLAY.md §무기 메카닉` 승격 완료.**
- Q6. **`피날레 2·3`과 `4·5`의 중첩** **A: 합산된다.**
  **일반 규칙 → `GAMEPLAY.md §값 산정` 승격 완료.**
- Q7. **명중률·저지 부위의 딜 기여**
  **A(최종, 2026-08-11): `intercept_dmg_pct`는 구현하지 않고 조건을 언제나 미달성으로 둔다.**
  (단계 3 시점의 "구현한다" 답을, DealForm 진입 방식 3안을 제시한 뒤 이 결론으로 확정)
  → `IMPL-STATUS` 상태를 ❌ → 🚫로 바꿔 "지원 계획 없음"을 명시. 파싱은 그대로 두고
  시뮬 딜 기여 0을 네거티브 항목으로 검증한다.
  `accuracy_pct`도 기존대로 — 기본 보스 `core_px = 0`에서 무발동(네거티브 유지).
- Q8. **블랑 시나리오 영향** **A: 갱신한다.** `블랑.md` 변형 1의 "클린 대조" 서술과 블랑 baseline을
  단계 4에서 함께 고친다.
