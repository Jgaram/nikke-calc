## 스킬 간 상호작용

- **버스트 딜의 대부분이 `히어로 비전` 5중첩 게이트에 걸려 있다**
  - 경로: `히어로 비전`(`full_charge_hit`, `explosion_range`, max_stack 5) → `self_stack_above:히어로 비전:5` → `라플라스 버스터 3`(방무 전환) + `라플라스 버스터 4`(매 발 방무 딜)
  - 시점: 두 조건 모두 **runtime 재판정**(`_RUNTIME_COND_PREFIXES`에 `self_state:`·`self_stack_above:` 등록) → 모드 구간·중첩 상태와 오차 없이 일치.
  - **위험 — 첫 사이클은 구조적으로 미충족**: RL 발사 주기가 1.383s라 t=3.2 버스트 시점에 중첩이 2뿐이다. 5중첩 도달은 t≈6.6이므로 **1회차 버스트만 방무가 통째로 빠진다.** 실측에서 `라플라스 버스터 4` 첫 발동이 28.267s(2회차 버스트)로 확인됐다. 이건 버그가 아니라 정상 동작이다.
- **모드가 스킬1·스킬2 공급을 동시에 끊는다**
  - 경로: SMG 모드(차지 표기 없음) → 10초 동안 `full_charge_hit` 0회 → `히어로 비전` 갱신·`히어로 봄버` 딜 모두 정지 (GAMEPLAY §무기 메카닉)
  - 결과: 스킬1은 15초 지속이라 모드 10초를 넘겨 생존한다(실측 27.95 부여 → 42.95 만료 vs 모드 28.27~38.23). 스킬2는 모드 동안 완전 정지 — 이건 기회비용일 뿐 버그가 아니다.
- **`라플라스 버스터 2·3`은 `duration: -1` 영구 등록이고 게이팅만 runtime이다**
  - `passive` + `self_state` 패턴(라플라스 : 얼티밋 히어로 `일렉트릭 파워 풀 풀 차지 3`와 동일). 버프 스냅샷에 t=3.25부터 "영구"로 보이지만 조건이 거짓인 동안 효과가 실리지 않는 게 정상이다.
  - **검증 시 "스냅샷에 떠 있다 = 적용 중"으로 읽으면 안 된다.** 실제 적용 여부는 히트의 방무 판정으로 확인한다.
- **동일 timing(`burst_cast`) 실행 순서**: `라플라스 버스터`(무기 변경) → 나머지. `2·3`은 `passive`라 배치 순서에 무관하고, `4`는 `hit_count:1`이라 모드 진입 후에만 돈다. **스택을 소비하는 항목이 없어 순서가 결과를 바꾸지 않는다** — 얼티밋 히어로(`예열` 해제 순서가 결정적)와 다른 점.

## 유저 확인 사항

- Q1. **무기 변경 무기의 스펙** — 원문에 무기 유형·연사(rpm)·장탄이 없다.
  - A: **SMG, 초당 24발.** 애장품 3단계 기준 유지 10초 → **총 240발**.
  - → SMG 무기군 기본값이 24/s라 `weapon_delays.json` `_weapon_change` 오버라이드가 필요 없다(실측 20/s여서 오버라이드를 둔 얼티밋 히어로와 반대). 지속이 시간 기반이므로 `max_ammo: -1`.

- Q2. **버스트 ②(방어력 무시 11.9%)의 발동 횟수** — 시전 시 1회인가, 매 발마다인가.
  - A: **매 발마다.** → `hit_count:1` + 모드·중첩 게이팅으로 파싱. 실측 사이클당 240회.

- Q3. **작업 기준** — 애장품 반영 여부.
  - A: **애장품 3단계 기준.** (`PARSING.md` 애장품 규칙과 일치)

- Q4. **`first_damage_coeff` 신규 필드 승인** — `최초 대미지` / `일반 대미지` 2단 계수를 담을 자리가 기존 weapon_change 스키마에 없었다.
  - A: **승인.** `PARSING.md` §2 필드 표·§7-13, `IMPL-STATUS.md` damage stat 테이블에 등록 완료. 구현은 단계 4.

- Q5. **중첩 미달 버스트가 실전에서 유의미한가** (게임플레이).
  - A: **선버로 쓰면 중첩이 덜 찬 채로 쓰이고, 후버로 쓰면 괜찮다.** → 검증 스쿼드에 후버 변형을 추가했다. 실측상 후버가 버스트 1회 적은데도 딜이 7.3% 높다 — 중첩 미달 버스트 하나의 손실이 버스트 한 번보다 크다.

- Q6. **파츠 보유 보스를 검증 대상으로 볼 것인가** (게임플레이).
  - A: **둘 다 본다.** → 기본 보스가 정본이고 `enemy={"has_parts": True}`를 병행 관찰한다. 파츠 보스에서 `히어로 봄버 2`가 전 히트(1789회)에 붙어 딜이 23.8% 오른다.

- Q7. **특별한 컨트롤 운용이 있는가** (게임플레이).
  - A: **없다 — 자동이 맞다.** `data/char_defaults.json` 등록 없음. 톡톡이·버스트 엄폐컨·장전컨 모두 기본 전략으로 두지 않는다.

- Q8. **관통 특화** — 계산 반영 여부.
  - A: `pierce_enabled` 버프로 걸어 뒀다(`라플라스 버스터 2`). 관통 대미지 증가 버퍼가 있는 스쿼드에서는 실제로 딜에 실린다. 별도 검증은 하지 않는다(유저 판단).
