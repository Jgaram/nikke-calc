## 스킬 간 상호작용

- **`제압 개시 2`(`armor_break_enabled`)가 두 `armor_break_dmg_pct`의 실효 스위치**
  - 경로: 일반공격이 방무 판정이 되어야 `전투 보정 2`(+35.05)·`전장 통제 3`(+140.49)가 DealForm ⑤에 실린다
  - 실효 구간: 버스트 후 **10초뿐**. 그 밖에서 두 버프는 타키나 본인 딜에 기여 0
  - 실측(표준, 제거 ablation): `전투 보정 2` 제거 시 스쿼드 총딜 **−58.6M(−4.20%)**

- **`전장 통제 3`은 표준 스쿼드에서도 크게 실효한다 — `all_allies`는 시전자 본인 포함**
  - 초안에서 "표준 스쿼드에는 방무 딜러가 없어 기여 0"으로 적었던 것은 **틀렸다.**
    타키나 본인이 `all_allies`에 들어가고, 본인 버스트 10초가 방무 구간이라 스스로 수혜자다
  - 실측 제거 ablation — 표준: 타키나 **−150.1M**(본인 딜 409.3M → 259.1M, **−36.7%**),
    리틀 머메이드·test_B3·스노우 화이트 : 헤비암즈는 **정확히 Δ0**(방무 히트 없음)
  - 변형 1: 타키나 −147.8M + 치사토 **−196.5M** → 스쿼드 −344.3M(−27.4%).
    치사토는 상시 방무 히트가 있어 타키나 방무 구간 밖에서도 계속 수혜

- **15초 주기(스킬2) ↔ 12.533초 사이클(버스트)의 맥놀이 — 이 캐릭터의 핵심 특성**
  - 두 주기가 어긋나 방무 구간과 `전장 통제 3` 창(10s)의 겹침이 사이클마다 변한다
  - 실측 겹침률: 0% → 93.7 → 81.5 → 56.8 → 50.0 → 50.0 → 67.2 → 91.8 → 83.5 → 58.8 →
    50.0 → 50.2 → 65.0 → 89.7 → 0%. **합계 88.82s / 150s = 59.2%**
  - 즉 방무 구간의 **40%는 +140.49%를 못 받는다**. 사이클 간격을 바꾸는 버프(크라운 등)를
    넣으면 이 비율이 통째로 달라지므로, 딜 비교 시 스쿼드를 고정해야 한다
  - 1회차 버스트(t=3.1)는 스킬2 첫 발동(t=15) 전이라 **항상 0%**다

- **`전투 보정`(ATK +80.04, 5s)은 방무 구간과 2.62s 겹친다**
  - `full_burst_end`(t=13.25) 발동 → 5초 유지, 다음 타키나 버스트는 2.38s 뒤(t=15.63)
  - 초안에서 "거의 겹치지 않는 평타용"으로 적었으나 실제로는 **방무 구간 앞 2.62s에 얹힌다**

- **`제압 개시 3`(적 `받는 대미지` +6.04)은 방무 구간 내내 상시 유지**
  - 변경 무기 발사 간격 0.4s ≪ 지속 5s → 매 히트가 갱신. 실측 발동 **354회**
  - 실측 제거 ablation: 표준 −73.9M(−5.30%). 스쿼드 전원의 딜에 실린다(적 디버프)

- **순환 없음**: 버프·디버프 → 딜 단방향.

## 유저 확인 사항

- **Q1: 스킬2 `전장 통제`의 발동 트리거는?** CDN 원문에 트리거 문구가 없고 `skill_cooltime_list`도
  비어 있다(roledata 원본 직접 확인 — 스크래핑 누락 아님).
  **A: 전투 시작 후 15초, 이후 15초 간격 자동 발동** → `every:15s`.
- **Q2: 버스트 `제압 개시`의 변경 무기 스펙은?** 원문에 계수·유지 10초만 있고 무기 종류·장탄·
  연사·펠릿·차지가 전부 없다.
  **A: SG · 10초간 25발 · 펠릿 1개 · 장탄 수 무한** → `weapon_type: "SG"`, `max_ammo: -1`,
  `weapon_delays.json`에 `fire_rate: 2.5` · `pellets: 1` 고정.
- **Q3: 버스트③ `명중 대상에게 [받는 대미지 ▲][5초]`는 명중마다 갱신인가?**
  A: 단일 보스 sim에서는 대상이 1기라 사실상 방무 구간 내내 유지된다. `hit_count:1`로 매 히트 갱신.
- **Q4: 스킬1① `전투 시작 시와 풀 버스트 타임 종료 시`를 두 항목으로 나누나?**
  A: **아니다.** `PARSING.md §4-1` 복합 트리거 규칙대로 **한 항목의 timing 배열**에 둘 다 넣는다
  (`["battle_start", "full_burst_end"]`). 초안의 "둘로 분리" 계획을 정정했다.
- **Q5: 스킬2 `기절`은 무시해도 되는가?**
  A: 보스 행동 모델이 없어 딜 무관. 단 `stun`은 `bm.is_stunned()`로 **아군에게 걸리면**
  일반공격·버스트를 막는 구현이 있다 — 여기서는 `all_enemies` 대상이라 아군에 영향 없음. 네거티브 항목.

일반 규칙 승격: **없음.** Q1·Q2는 타키나 고유(원문 결손) → `PARSING-CHARS.md §캐릭터별 예외`에 기록.
Q4는 `PARSING.md §4-1`에 이미 있는 규칙이라 추가 없음.
