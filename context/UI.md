# UI — 시뮬레이터 디버깅 대시보드

## 목적

유저가 인게임 동작을 보면서 시뮬레이터 출력과 직접 비교할 수 있는 디버깅 도구.  
**1차: 메커니즘 검증** (버프 타이밍, 히트 이벤트 확인) / **2차: 조합 비교, DPS 최적화**

---

## 실행

`run.bat` 더블클릭 또는 `streamlit run app.py`.  
브라우저 `http://localhost:8501`. 코드 수정 후 Streamlit 자동 재시작 → **F5**로 확인 (`Ctrl+Shift+R`로 강제 새로고침).

`parsed_skills.json` / `parsed_nikke.json` 변경 시 `app.py`가 자동 감지해 관련 모듈을 리로드한다.

---

## 화면 구성

**상단 expander — 팀 구성** (`team_panel.py`)  
결과가 없으면 자동으로 펼쳐짐. 캐릭터 5명 + 개별 스탯(레벨·친밀도·콘솔·장비·큐브·컬렉션) + 시뮬 시간 + 버스트 설정. "▶ 시뮬 실행" 누르면 `simulate()` 호출 → `session_state["result"]`에 저장 후 `st.rerun()`.

**탭 1 — 버스트 & 대미지** (`burst_panel.py`)
- 버스트 타임라인: 풀버스트 단위 행 (시작/종료 시각, 참여 캐릭터 이미지, 구간 딜량), expander에 스킬별 히트 집계 표
- 대미지 분석: 캐릭터별 스택 막대 차트(스킬명 색상 구분), 버스트 사이클별 누적 딜량 차트

**탭 2 — 버프 타임라인** (`buff_panel.py`)
- 대상 캐릭터(또는 "타겟 랩쳐") 선택 → Gantt 차트
- 풀버스트 시작/종료 시점 점선 표시

**탭 3 — 히트 추적** (`hit_panel.py`)
- 캐릭터 선택 → 스킬별 집계(총딜·히트수·비율·최빈값·lv10 계수)
- 스킬·시간 범위 필터 → 히트 이벤트 목록

## 버프 타임라인 표시 규칙

레이블 형식: `[시전자] 버프명 (stat 값%)`  
- stat·value는 `BuffEvent.stat`, `BuffEvent.value` 필드에서 읽는다
- 장비·소장품·큐브 계열 버프명: `장비 옵션` / `소장품:공통` / `소장품:{무기군}` / `큐브:{큐브명}`  
- stat suffix를 버프명에 포함하지 않는다 (stat 필드로 분리)
- 장비·소장품 버프는 회색(`#666666`)으로 표시

## 이미지 관련 금지 사항

**이미지가 표시되지 않거나 깨져 보이면 Claude가 임의로 재다운로드하거나 교체하는 것을 절대 금지한다.**

이미지는 유저가 직접 관리한다. 이미지 문제 발생 시 Claude가 할 일:
1. `ui/image_utils.py`의 캐릭터명 → 파일명 변환 규칙 확인 (` : ` → `_` 등)
2. `image/` 폴더에 해당 파일 존재 여부 확인
3. 위 두 가지를 유저에게 보고하고 판단을 맡긴다

재다운로드가 필요하면 유저가 `scraper/download_images.py`를 직접 실행한다.
