# NIKKE Damage Calculator

승리의 여신: 니케 5인 스쿼드의 실시간 전투와 DPS를 계산합니다.

## 알아두실 점

취미로 만드는 개인 프로젝트입니다. 다음을 감안하고 사용해 주세요.

**계산 결과는 참고용입니다.** 버그나 잘못된 계산이 있을 수 있고, 게임 메커니즘 중
아직 확인하지 못한 부분도 남아 있습니다. 이상한 값이 나오면 제보해 주시면 큰 도움이 됩니다.

**업데이트 주기를 약속하지 않습니다.** 신규 캐릭터가 출시되어도 개인 사정에 따라
한동안 반영되지 않을 수 있습니다.

**그래서 처음부터 가져가서 쓰시라고 열어두었습니다.** 안정적인 운영이나 빠른 대응이
필요하시다면 이쪽 업데이트를 기다리는 것보다 직접 고쳐 쓰시는 편이 확실합니다.
라이선스를 아래와 같이 고른 이유이기도 합니다.

캐릭터 추가가 이 프로젝트에서 가장 손이 많이 가는 작업인데, 그 절차는
[`.agent/skills/char-add/`](.agent/skills/char-add/)에 정리해 두었습니다. 니케 스킬
메커니즘을 어느 정도 알고 코딩 에이전트를 다뤄본 분이라면 누구든 하실 수 있습니다.
